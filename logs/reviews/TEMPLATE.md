# AI Reviewer 审查报告模板

> 使用方式：审查 Agent 在**全新会话**中，接收「待审 diff + 本模板 + 宪章相关章节」，
> 按此结构填写后保存为 `logs/reviews/REV-<任务ID>.md`。
> Reviewer 不接收 Writer 的过程叙述（宪章第四十二章）。

---

## REV-<TASK-ID> — <日期>

- **审查对象**: commit hash / 文件清单
- **对应写作任务**: TASK-ID
- **内容级别**: L1 / L2 / L3（宪章第四十三章）

### 发现的问题

| #   | 严重度                  | 位置              | 问题描述 | 建议 |
| --- | ----------------------- | ----------------- | -------- | ---- |
| 1   | BLOCKER / MAJOR / MINOR | file:line 或 章节 | ……       | ……   |

严重度定义：

- **BLOCKER**：事实错误、伪造来源、编造答案、违反任务范围——必须修复才能合并
- **MAJOR**：无依据的重要 Claim、术语不一致、缺失出处、结构不符规范
- **MINOR**：措辞、排版、风格问题

### 规范符合性

- [ ] 零基础假设成立（无未解释的前置概念）
- [ ] 术语首现标注英文
- [ ] 双链与状态表已更新
- [ ] frontmatter 含 last_verified
- [ ] L2 内容：每题有出处，待验证项已标记
- [ ] 构建通过（npx quartz build 无断链警告）

### 总体结论

**PASS / REVISE / REJECT** — 一句话理由。
