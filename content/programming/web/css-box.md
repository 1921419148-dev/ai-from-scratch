## 生活场景切入

每个可见元素都可以理解为内容、内边距、边框和外边距四层盒子。先把它看成解决具体问题的工具，不需要一次记住所有语法。

## 核心概念

**width** 是本课的核心。阅读代码时，先找输入，再看处理规则，最后确认输出。遇到陌生符号时逐行运行，比死记定义更有效。

## 分步任务

1. 先运行默认代码，确认输出与代码的对应关系。
2. 改变 padding 与 margin，比较哪个会扩大背景区域。
3. 再运行一次，直到页面显示“检查通过”。
4. 用一句自己的话解释修改前后为什么不同。

## 常见错误

> [!warning] 先检查这一点
> 默认 content-box 下，实际占用宽度不只等于 width。

## 挑战题

不看默认示例，从空白开始写出一个更贴近你自己学习生活的版本。完成后刷新页面，确认代码仍能恢复。

> [!question]- 参考思路
> 先写出最小可运行版本，再一次只增加一个条件、字段或界面元素。每次修改后都运行，出错范围就会很小。
