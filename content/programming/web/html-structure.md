## 生活场景切入

HTML 描述内容是什么，浏览器据此建立页面结构。先把它看成解决具体问题的工具，不需要一次记住所有语法。

## 核心概念

**元素** 是本课的核心。阅读代码时，先找输入，再看处理规则，最后确认输出。遇到陌生符号时逐行运行，比死记定义更有效。

## 分步任务

1. 先运行默认代码，确认输出与代码的对应关系。
2. 加入一个二级标题和两段正文。
3. 再运行一次，直到页面显示“检查通过”。
4. 用一句自己的话解释修改前后为什么不同。

## 常见错误

> [!warning] 先检查这一点
> 标签应正确闭合，并保持清楚的缩进。

## 挑战题

不看默认示例，从空白开始写出一个更贴近你自己学习生活的版本。完成后刷新页面，确认代码仍能恢复。

> [!question]- 参考思路
> 先写出最小可运行版本，再一次只增加一个条件、字段或界面元素。每次修改后都运行，出错范围就会很小。
