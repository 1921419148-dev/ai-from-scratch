## 生活场景切入

Node.js 让 JavaScript 离开网页，在电脑上访问文件、网络和系统能力。先把它看成解决具体问题的工具，不需要一次记住所有语法。

## 核心概念

**运行脚本** 是本课的核心。阅读代码时，先找输入，再看处理规则，最后确认输出。遇到陌生符号时逐行运行，比死记定义更有效。

## 常见错误

> [!warning] 先检查这一点
> 浏览器代码不能直接假设拥有 Node 的 fs 等模块。

## 挑战题

不看默认示例，从空白开始写出一个更贴近你自己学习生活的版本。完成后刷新页面，确认代码仍能恢复。

> [!question]- 参考思路
> 先写出最小可运行版本，再一次只增加一个条件、字段或界面元素。每次修改后都运行，出错范围就会很小。
