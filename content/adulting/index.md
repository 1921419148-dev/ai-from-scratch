# Adulting

青年大学习是一份面向大学生和初入社会者的独立中文知识库。它不替你做决定，而是帮你看清问题、找到可靠入口，并把下一步变成能执行的小任务。

## 六条成长路线

| 路线                                | 适合解决的问题                           |
| ----------------------------------- | ---------------------------------------- |
| [学业研究](/adulting/academic)      | 学术检索、论文写作、专业选择与继续深造   |
| [校园生活](/adulting/campus)        | 入学适应、课程、资助、人际关系与校园资源 |
| [数字技能](/adulting/digital)       | 电脑基础、搜索、隐私、密码与数字工具     |
| [健康安全](/adulting/health-safety) | 医保、心理支持、日常健康与风险识别       |
| [职业成长](/adulting/career)        | 实习求职、能力规划与长期发展             |
| [生活办事](/adulting/life-services) | 银行、出行、证件、优惠与常见事务         |

## 怎么使用

1. 从眼前最具体的问题进入，不必按顺序读完。
2. 先看页面的核验日期、适用地区和风险等级。
3. L2、L3 内容以页面列出的主管部门或服务方最新说明为准。
4. 把办理通知、提交材料和处理结果留档，方便后续核对。
