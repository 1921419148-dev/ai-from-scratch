## 生活场景切入

背 token 这个词时你在想什么？「令牌？代币？符号？」——如果靠中文译名硬记，永远隔着一层。

但如果你知道 **token 源自拉丁语 signum（标记）→ 古英语 tácen（标志、信物）**——中世纪分手时掰一半硬币给对方作信物就叫 token——再看它的技术含义「文本的最小切片、身份验证的通行证」，会发现**所有义项都是同一个内核：『可交换的最小凭据』**。

这就是词源学习法的威力：**术语不是随机代号，是隐喻的结晶。理解隐喻，术语自己会解释自己。**

## 词 1：token —— 可交换的最小凭据

```text
词源链：拉丁 signum（记号）→ 古英语 tācen（标志/信物）→ 现代双义
```

| 义项 | 场景                  | 共同内核           |
| ---- | --------------------- | ------------------ |
| 信物 | 情侣对戒、纪念币      | 有意义的凭证       |
| 代币 | 游戏币、地铁token     | 可流通的最小单位   |
| 词元 | NLP1 的分词产物       | 文本的最小处理单位 |
| 令牌 | 登录 credential token | 身份凭证           |

四个义项共享一个抽象结构：**系统内可计数、可交换、有语义的最小单元**。GPT 按 token 计费（NLP7）、登录按 token 鉴权——同一个词，同一个理。

## 词 2：embed —— 嵌进去，成为一体

```text
词源：em-（使进入）+ bed（床）→ 「嵌入床里」→ 深深固定其中
```

字面画面：把宝石**嵌进**戒指托。技术含义完美继承：

- **embedding（词嵌入，NLP2）**：把一个词「嵌进」高维空间的一个坐标点——不是贴标签，而是让它成为空间的居民
- **embedded system（嵌入式系统）**：计算机「嵌进」设备内部
- **socially embedded（社会嵌入式）**：社会学里行为「嵌于」关系网络

**辨析钩子**：embed 与 label 的区别就是「嵌进去」与「贴上去」的区别——标签可撕，嵌入不可分。词向量不是给词挂个编号牌，而是给它一个在语义空间中的**家**。

## 词 3：fine-tune —— 微调一台精密仪器

```text
词源：fine（精细）+ tune（调音）
tune 的本义：给钢琴/收音机调音——在大体正确的基础上微调到精准
```

画面感：钢琴调音师不会重造钢琴，只拧几颗弦钮让音准到位。

技术含义严丝合缝（DL10）：预训练模型=一架出厂的琴，你的领域数据=演出曲目，fine-tuning=只微调部分旋钮适配曲目而非重造乐器。对比 retrain（重训）/ train from scratch（从零训练），fine-tune 的 fine 就是在强调「**保留主体、只动微末**」——这也是为什么 LoRA 只动旁路小矩阵的精神被叫作 parameter-**efficient** fine-tuning：连 fine 都要更省。

## 词 4：gradient —— 斜坡，以及「沿坡而下」的一切

```text
词源：拉丁 gradi（行走、迈步）→ gradus（步/级）→ gradient（上升/下降的坡度）
同族词：grade（年级/坡度）、gradual（逐步的）、progress（前进）、degrade（降级）
```

本义就是**山坡的陡峭程度**。M7 把梯度下降比作下山完全不是比喻而是直译：

```text
gradient = 坡度（每走一步升高多少）→ 函数在某点的导数向量
gradient descent = 沿坡下行 → 沿负导数方向更新参数
```

记住词根 gradi（迈步），这一族词全部通顺：gradient descent 是「顺坡迈步」，gradient ascent 是「爬坡」（最大化问题用），graduated response 是「逐步升级的反应」。

## 词 5：attention —— 注意力，心理学词汇的直接移植

```text
词源：拉丁 attendere（ad 向 + tendere 伸）→ 「把精神伸向……」
同族词：tend（倾向）、tension（张力）、extend（伸展）
```

DL8 的注意力机制借的是认知科学术语：人类的注意力本来就是「在有限处理容量下选择性地聚焦部分输入」。Q/K/V 三件套就是这个心理过程的数学化：

```text
Query = 我此刻关心什么（注意力焦点）
Key   = 每个候选的特征标签
Value = 被选中后实际获取的内容
```

有趣的是这个词的迁移链条：哲学→心理学（selective attention）→神经网络（Bahdanau 2014 首次引入）→统治一切（Transformer）。**AI 大量借用认知科学的词汇**：memory（记忆）、forgetting gate（遗忘门）、attention（注意力）——因为 AI 研究者就是在用「心智」的隐喻为机器建模。

## 自测一下

> [!question]- 1. 「API rate limit exceeded: you have used up all your tokens.」这里的 token 是 NLP 分词义还是鉴权义？
> 是**鉴权义**：API 访问凭据（配额计费单位常兼两义——OpenAI 类平台确实按 NLP 义的 token 数计费，但 rate limit 报错里的 tokens 通常指请求凭据/配额点数）。
> 判断方法：看上下文有没有「文本长度/字数」相关语义。这也演示了 token 多义性的真实困扰——专业交流中必要时会说 language tokens / auth tokens 消歧。

> [!question]- 2. 为什么「把公司 logo 嵌进网页页眉」用 embed 不用 insert？
> embed 强调**成为宿主的一部分**（内联资源，随页面加载渲染）；insert 只是放置动作（可以是外部链接引用）。HTML 术语严格区分了两者：`<embed>` 标签的内容是文档的一部分，`<a>` 链接只是指针。
> 这与 NLP2 的辨析同构：词向量是把词「嵌入」语义空间成为居民（embed），而不是给词发一张外部的编号卡（label/insert）。**隐喻的一致性跨领域保持了术语边界的稳定**。

> [!question]- 3. 从词源角度解释：为什么「微调大模型」的行业共识是用小学习率？（DL10 已给出工程答案，这里要语言答案）
> 语言证据：fine-tune 的 tune 本义是调音——调音师的全部技艺在于「极小的拧动产生准确音高」，大拧叫修理（repair/rebuild）不叫调音。
> 行业术语沿用了这个隐含承诺：说 fine-tune 就默认了「动作幅度小、保留主体」。若用大学习率破坏性更新，你做的事情在英语世界里应该叫 retraining 或 distillation from scratch——术语用错，往往意味着流程设计也错了。**术语纪律反映工程纪律**。

> [!question]- 4. attention/memory/gate 这批认知科学词汇大量进入 AI 术语库，你觉得这种借用是好是坏？
> 开放题，两面都要看到：
> 好处——① 隐喻自带直觉，降低学习门槛（本课五词全是证据）；② 提供研究灵感框架（「遗忘门」直接启发缓解梯度消失的设计）。
> 坏处——③ 隐喻会过度承诺：模型的「attention」与人脑注意力的机制差异巨大，术语让人误以为「像人一样理解」；④ 认知科学术语本身未定型，借用时可能带入争议。
> 平衡观点：隐喻是必要的学习脚手架，但要定期提醒自己「地图不是疆域」——这正是 G8 安全课「不过度拟人化」原则的语言学根基。
