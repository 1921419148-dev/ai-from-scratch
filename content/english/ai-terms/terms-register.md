> [!abstract] 本课将学到
>
> - **语域（Register）**概念：同一意思在不同文体中的不同外衣
> - 学术英语五大高频动词的「新闻版替身」
> - 论文腔的句法特征：名词化、被动语态、长定语
> - 双向技能：读论文时自动「降维翻译」，写邮件时避免「论文腔入侵」

## 生活场景切入

同一个发现，两种说法：

```text
新闻版：Scientists found a new way to make AI training much cheaper.
论文版：We propose a novel methodology that substantially reduces the
        computational overhead associated with model training.
```

意思几乎一样，但用词、句式、语气完全不同。这不是「论文故意装深沉」——**学术语域的存在有功能理由**：精确、去个人化、可复现。但代价是它成了一道阅读壁垒。

本课给你一张「双向翻译表」：读论文时把大词降维回小词理解，写作时知道何时该升维、何时不该。

## 概念 1：语域 Register —— 语言的着装规范

```text
Register（语域）= 根据场合选择的语言变体

同义链条（正式度递增）：
get → obtain → acquire → procure
show → demonstrate → substantiate → corroborate
new → novel → unprecedented → paradigm-shifting（吹牛警戒线）
use → utilize → employ → leverage（商务黑话警戒线）
```

三条铁律：

1. **没有更好的词，只有更合适的词**——utilize 不是 use 的升级版，是另一个语域的选择
2. **语域错位比语法错误更扎眼**——求职信里写 "I wanna help you guys do cool stuff" 直接出局
3. **读比写重要**：你需要能秒懂所有语域（读论文），但主动产出只需掌握两三个（技术博客/日常邮件）

## 概念 2：五大高频替换对 —— 论文动词的降维翻译

| 论文动词                          | 新闻/口语替身            | 论文里为什么用它                                      |
| --------------------------------- | ------------------------ | ----------------------------------------------------- |
| **utilize**                       | use                      | 强调「作为工具利用」；但滥用严重，多数场景 use 更诚实 |
| **demonstrate**                   | show / prove             | 实验证明义；show 在顶会标题也常见                     |
| **substantially / significantly** | a lot / by half          | significantly 有统计学专义（p<0.05），泛用时是重灾区  |
| **propose**                       | come up with / introduce | 提出新方法的标准动词，几乎无替身——必背                |
| **leverage**                      | use（again!）            | 「杠杆式利用」，商务黑话浓度最高，论文中已泛滥        |

**实战换算演示**：

```text
论文：This paper leverages a novel attention mechanism to substantially
      mitigate the vanishing gradient problem.
新闻：The team uses a new attention design that largely fixes the
      vanishing-gradient problem.
你脑内：他们设计了个新注意力结构，基本解决了梯度消失。
```

三句话信息等价。**读论文的核心技巧就是实时做右侧的降维**——把名词化拆回动词、把大词换回小词，理解速度立涨。

## 概念 3：名词化（Nominalization）—— 论文最大的读障

学术英语最爱把动作变成抽象名词：

```text
动词版（易读）：We implemented the model and it converged quickly.
名词版（论文腔）：The implementation of the model achieved rapid convergence.
```

识别技巧：看到 `-tion / -ment / -ance` 结尾的大名词，先问「谁在做什么」把它还原成动词句：

| 名词化                         | 还原为                  |
| ------------------------------ | ----------------------- |
| the implementation of X        | (we) implemented X      |
| achieve convergence            | converge                |
| provides an improvement over X | improves on X / beats X |
| is indicative of               | indicates               |

一句话里堆三四个抽象名词（典型如 "utilization of the optimization of…"）就是著名的「论文黑话塔」。**拆塔是理解，不搭塔是美德**——好的学术写作指南（如 Nature 的写作课）都在教作者少犯这个毛病。

### 被动语态的正确打开方式

```text
论文：The dataset was curated and annotated by three experts.
     （去个人化：强调流程而非人）
口语：Three experts cleaned up and labeled the data.
```

被动不是错的，是语域工具。判断标准：**施动者重要吗？** 不重要（方法学流程）→ 被动；重要（谁负责、谁发现）→ 主动。全篇被动的论文读起来像机器生成——现在这真的是个需要担心的问题了。

## 概念 4：双向实战 —— 两段互译

**论文原文 → 新闻化改写**：

```text
原：Notably, our approach demonstrates substantial performance gains across
    multiple benchmarks, suggesting the efficacy of the proposed method.

新闻化：Their method beats existing ones on several standard tests,
        which suggests the idea works.
```

逐个替换点：Notably→删（填充词）；demonstrates…gains→beats；substantial→具体化或删；benchmarks→standard tests；suggesting the efficacy of→which suggests … works。

**口语想法 → 学术化改写**（写课程作业时用）：

```text
口语：Our model didn't overfit because we used way more data.
学术：Overfitting was mitigated by expanding the training corpus.
     （overfit/mitigate/corpus 三个术语各就各位，因果用被动呈现）
```

注意学术化≠加废话——只升级必要的词与句式，砍掉 way more 这类模糊量词换成可验证表述。

## 自测一下

> [!question]- 1. 把这句论文腔降维成人话："The utilization of data augmentation techniques facilitates the mitigation of overfitting."
> 「用数据增强技术能缓解过拟合。」
> 三连拆解：utilization of→用；facilitates→帮助/让……更容易（其实整句就是 helps reduce）；mitigation of overfitting→缓解过拟合。
> 原句 11 词表达了一个 8 词就能说清的意思——这正是名词化被诟病的原因：**膨胀但不增加信息**。

> [!question]- 2. significantly 在论文里有哪两层含义？为什么「显著提升」不能乱写？
> 层一（日常）：幅度可观地；层二（统计）：通过了显著性检验（p<0.05，M10/M9 的假设检验框架）。
> 危险在于混淆：若你的实验没做统计检验，写 "significantly improved" 是学术表述失当（审稿人会要求补检验）；此时应写 "substantially/substantially improved" 或给出具体数字。
> 一字之差，一个是修辞、一个是可证伪的科学声明——**论文英语里每个副词都可能承担举证责任**。

> [!question]- 3. 为什么 propose 几乎没有同义词能替代？它承载了论文的什么结构性信息？
> propose 精确标记了「本文的贡献起点」：在此之前是世界现状，之后是你的方法——它是论文叙事的分水岭动词。
> 替代词各有副作用：introduce 太弱（可以只是介绍）、present 不含「新颖性声明」、develop 暗示已完成工程实现。而 propose = 「在此正式提出（待验证的新方案）」，与摘要里的 "We propose…"、引言末的 "Our contributions are…" 形成固定呼应。
> 读论文技巧：**定位到 propose 就找到了作者的核心主张**，全文的一切实验都是为了支撑这一个动词的宾语。

> [!question]- 4. 给同学的邮件开头写了 "This correspondence aims to elucidate the utilization of our proposed framework."——有什么问题？怎么改？
> 三重语域错位：① correspondence/elucidate/utilization 是论文级大词，邮件里显得迂阔滑稽；② aims to elucidate 的去个人化腔调在人际沟通里冷漠生硬；③ 整句零信息（没说清要讲什么）。
> 改：「Hi, I'd like to walk you through how to use our new tool.」——邮件语域追求清晰+温度，与论文语域的目标（精确+去个人化）方向相反。
> 元教训：**语域能力 = 同一意思的多版本产出能力 + 场合判断力**。只会一档开车的司机不是好司机。
