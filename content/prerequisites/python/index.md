## 浏览器练习与本机项目

标准 Python、NumPy 和 Pandas 在浏览器内真实执行。Git 使用浏览器虚拟文件系统。自动化、爬虫和聊天机器人采用双轨教学：先在本站完成安全练习，再按讲义在本机访问文件或网络；任何 API Key 都不得写入网页或 Git。
