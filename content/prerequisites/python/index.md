> [!abstract] 本板块解决
> Python 是 AI 领域使用最广泛的编程语言，语法接近自然语言，最适合零基础入门。本板块带你从安装环境开始，一路学到能独立完成数据分析小项目。

## 学习顺序

| #   | 课程                          | 学它干什么用              | 状态 |
| --- | ----------------------------- | ------------------------- | ---- |
| P1  | 安装你的第一个编程环境        | 让电脑跑起来第一行代码    | 🚧   |
| P2  | 变量与数据类型                | 程序如何「记住」东西      | 🚧   |
| P3  | 列表、字典：装数据的容器      | 组织批量数据              | 🚧   |
| P4  | 条件判断与循环                | 让程序学会选择和重复      | 🚧   |
| P5  | 函数：把重复的事打包          | 写可复用的代码            | 🚧   |
| P6  | 类与对象初识                  | 理解 PyTorch 的写法基础   | 🚧   |
| P7  | NumPy：数字的瑞士军刀         | **AI 数值计算的事实标准** | 🚧   |
| P8  | Pandas：像 Excel 一样处理表格 | 数据清洗与准备            | 🚧   |
| P9  | Matplotlib：让数据开口说话    | 可视化训练过程            | 🚧   |
| P10 | 实战：分析一份真实数据集      | 综合运用                  | 🚧   |

> [!tip] 编程学习心法
>
> - **一定要动手敲代码**，看懂 ≠ 会写
> - 报错不可怕，错误信息是程序在跟你说话
> - 每天写 30 分钟，胜过周末突击 5 小时
