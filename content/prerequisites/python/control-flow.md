> [!abstract] 本课将学到
>
> - **条件判断（if）**：程序的分岔路口——满足什么条件走哪条路
> - **循环（for / while）**：自动流水线——把重复的事交给电脑
> - **缩进（Indentation）**：Python 用空格表示「谁属于谁」，这是它最著名的规矩
> - 亲手玩：单步追踪器，看着程序一行行走岔路、转圈圈

## 生活场景切入

你每天的生活其实全是「条件 + 循环」：

```text
如果（下雨）：
    带伞
否则：
    戴墨镜

对 每一个 工作日：
    闹钟响 → 起床 → 上班
```

第一段是**条件判断**：看情况选一条路。第二段是**循环**：同样的事重复做。

计算机最擅长的恰恰是这两件事：不知疲倦地重复、精确无误地判断。你写的第一个 AI 训练代码，核心就是这两样东西的组合：

```text
重复 100 轮：                      ← 循环
    如果 这轮预测错了：             ← 条件
        调整参数
```

## 核心概念拆解

### 概念 1：if / elif / else —— 分岔路口

```python
score = 86

if score >= 90:
    print("优秀！")
elif score >= 60:
    print("及格，继续加油")
else:
    print("要补考了……")
```

读法：「如果分数 ≥ 90 打印优秀；**否则如果**（elif = else if 的缩写）≥ 60 打印及格；都不满足就走 else」。三个要点：

1. 条件后面必须有冒号 `:`（新手忘得最多的符号）
2. **缩进的行才属于这个 if**（见概念 3）
3. 条件从上往下逐个检查，命中一个就跳过剩下的

常用的比较与逻辑运算：

| 写法   | 含义       | 写法   | 含义           |
| ------ | ---------- | ------ | -------------- |
| `==`   | 等于       | `and`  | 并且（都要真） |
| `!=`   | 不等于     | `or`   | 或者（有一个真）|
| `>` `<` `>=` `<=` | 大小比较 | `not` | 取反 |

再次强调：`=` 是赋值，`==` 才是比较。写错的话 Python 会直接报错提醒你。

### 概念 2：for 循环 —— 「对每一个……」

```python
scores = [88, 92, 75, 60]

for s in scores:
    print(s)
```

两行就把列表里每个成绩都打印了。读法特别像中文：**「对 scores 里的每一个 s，打印 s」**。列表有 4 个元素，循环体就跑 4 遍。

配合上节课的容器，立刻能干点正事：

```python
scores = [88, 92, 75, 60]
passed = 0

for s in scores:
    if s >= 60:
        passed = passed + 1     # 及格一人，计数加一

print(passed)        # 3
```

这就是「循环 + 条件」的经典组合：**遍历每个元素，按条件分类处理**。数据统计、清洗、筛选，底层都是这个模式。

想按次数重复时用 `range()`：

```python
for i in range(3):
    print("第", i, "轮")

# 输出：第 0 轮 / 第 1 轮 / 第 2 轮   ← 又从 0 开始！range(3) 是 0,1,2
```

### 概念 3：while 循环 —— 「只要……就一直」

`for` 是「数着个数重复」，`while` 是「满足条件就一直重复」：

```python
count = 3
while count > 0:
    print(count)
    count = count - 1      # 别忘了改条件里的变量！

print("发射！🚀")
```

> [!warning] 死循环：while 的头号事故
> 如果循环体里忘了让条件最终变假（比如忘了 `count = count - 1`），程序会永远转下去，俗称死循环。网页突然卡死、风扇狂转，多半就是它。真实训练代码里也有同款 bug：损失不再下降但停不下来，烧掉一晚上电费。

### 概念 4：缩进 —— Python 的门规

其他语言用花括号 `{ }` 圈住「哪些行属于 if」，Python 直接用**缩进**（行首空格）：

```python
if score >= 60:
    print("过了")          # 缩进 4 格 → 属于 if
    print("恭喜")          # 缩进 4 格 → 也属于 if
print("这行总是执行")       # 没缩进 → 不属于 if，在它外面
```

规矩只有一条：**同一层级对齐，层级内统一缩进 4 格**。编辑器的 Tab 键会自动帮你做对。

| 英文            | 中文       | 一句话记忆                                     |
| --------------- | ---------- | ---------------------------------------------- |
| Condition       | 条件       | if 后面那个真假表达式                          |
| Indentation     | 缩进       | Python 用它表示代码的从属关系                  |
| Loop / Iterate  | 循环 / 迭代 | iterate 一遍遍地过                            |
| for each … in … | 对每一个…  | Python for 循环的直译，读起来就像英文句子      |
| Range           | 范围       | `range(n)` 生成 0 到 n-1                       |
| Infinite Loop   | 死循环     | while 条件永远为真的事故                       |

| Break / Continue | 跳出/跳过 | break 提前结束整个循环；continue 跳过本轮      |

## 自测一下

> [!question]- 1. 下面的代码打印什么？
>
> ```python
> x = 7
> if x > 10:
>     print("A")
> elif x > 5:
>     print("B")
> elif x > 6:
>     print("C")
> else:
>     print("D")
> ```
>
> 只打印 **B**。x=7 满足 `x > 5`，进入 elif 打印 B 后**整条链直接结束**，后面的 `x > 6` 明明也成立却永远不会被检查。条件分支是「多选一」：从上到下找到第一个成立的就收工。想让 C 也有机会，就得把它们写成独立的两个 if。

> [!question]- 2. `range(1, 5)` 会产生哪几个数字？想循环 5 次、且 i 从 1 数到 5，怎么写？
> 产生 `1, 2, 3, 4`——含头不含尾，和切片 `[1:4]` 一个脾气。想要 1 到 5 得写 `range(1, 6)`。「含头不含尾」的好处：`range(a, b)` 加 `range(b, c)` 正好无缝拼起来，不会重复数 b。

> [!question]- 3. 把下面 while 循环改成 for 循环，并说说哪种场景更适合哪个。
>
> ```python
> i = 0
> while i < 5:
>     print(i)
>     i += 1
> ```
>
> 改成：`for i in range(5): print(i)`。规律很清晰：**知道要重复几次用 for**（遍历列表、跑固定轮数）；**不知道几次、只知道「什么时候该停」用 while**（比如「一直训练直到损失小于 0.01」——训练前没人知道要几步）。

> [!question]- 4. 训练模型时「epoch 循环里套 batch 循环」（先固定轮数、每轮再分小批过数据）用的是本课哪两个知识点？写出骨架。
> **嵌套循环**：外层 for 控制轮数（epoch），内层 for 遍历每轮的数据批次（batch）。骨架：
>
> ```python
> for epoch in range(50):          # 外层：完整过 50 遍数据
>     for batch in batches:        # 内层：这一遍里每次取一小批
>         if loss(batch) > 目标:    # 条件判断参与其中
>             调整参数()
> ```
>
> 你以后写的每一个训练脚本，最外层几乎都是这两层循环——P9 可视化时画的损失曲线，横轴就是外层循环的 epoch 编号。
