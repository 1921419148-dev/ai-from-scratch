## 生活场景切入

回想一下你怎么学会用微信的：下载 App → 打开 → 发第一条消息。学编程一模一样：

| 学微信            | 学 Python                        |
| ----------------- | -------------------------------- |
| 下载安装微信      | 安装 Python 解释器               |
| 打开聊天窗口      | 打开代码编辑器                   |
| 打出第一条「在吗」 | 敲下第一行 `print("Hello, AI!")` |
| 对方回复          | 屏幕上出现运行结果               |

很多人卡在第一步就放弃了，因为网上教程一上来就是一堆名词：PATH、虚拟环境、命令行……别慌。这一课只做一件事：**让你屏幕上出现第一行运行结果**。其他花活以后再说。

## 核心概念拆解

### 概念 1：Python 程序的两个角色

写代码、跑代码，其实是两件事，由两个软件完成：

```mermaid
flowchart LR
    A["✍️ 你写的代码<br/>hello.py"] --> B["🗣️ 解释器 Interpreter<br/>逐行翻译成电脑动作"]
    B --> C["📺 结果<br/>屏幕输出"]
```

- **解释器（Interpreter）**：一个「翻译官」程序。Python 代码它一行一行读、一行一行执行。你从 [python.org](https://www.python.org/downloads/) 下载安装的就是它。
- **编辑器（Editor）**：你打字的地方，比如免费的 **VS Code**。它像「带自动纠错的记事本」，会把代码染上颜色、提示错字。

> [!tip] 名词恐慌急救包
> 网上还会看到 IDE、终端 Terminal、命令行、Jupyter……先全部无视。它们都是工具的花样变体，等你需要时自然会遇到。现在只需要：**解释器 + 编辑器 = 能跑代码**。

### 概念 2：三条上手路线

| 路线                     | 适合谁                       | 要做的事                                       |
| ------------------------ | ---------------------------- | ---------------------------------------------- |
| ① 本机安装（推荐）       | 打算认真学的你               | 装 Python + VS Code，一次搞定终身受用           |
| ② 在线笔记本             | 电脑装不了 / 只想先试试      | 打开浏览器用 Google Colab，什么都不用装         |
| ③ 手机浏览器             | 此刻只有手机                 | 能看懂课程代码，动手体验有限                    |

**路线① 安装步骤**（以 Windows 为例，Mac 类似）：

1. 打开 [python.org/downloads](https://www.python.org/downloads/)，点黄色大按钮下载（官网会自动推荐最新稳定版；本站课程在 Python 3.13 下验证通过，更新的版本同样适用）
2. 运行安装包，**务必勾选底部的「Add python.exe to PATH」**（把 Python 加入系统路径——不勾的话，电脑找不到你装的 Python 在哪）
3. 点 Install Now，等待完成
4. 再去 [code.visualstudio.com](https://code.visualstudio.com/) 下载安装 VS Code，并在它的扩展商店里搜「Python」装上官方扩展

**路线② 零安装**：打开 [colab.research.google.com](https://colab.research.google.com)，新建一个笔记本，直接在格子里敲代码、按 ▶ 运行。AI 圈做实验特别爱用它。

### 概念 3：第一行代码

安装好之后，新建一个文件 `hello.py`，输入：

```python
print("Hello, AI!")
```

保存，然后点编辑器右上角的 ▶ 运行按钮（或在终端里输入 `python hello.py`）。你会看到：

```text
Hello, AI!
```

拆开看这一行：

- `print()` 是 Python 自带的**函数（Function）**——一个现成的工具，作用是「把括号里的东西显示到屏幕上」（虽然叫 print，「打印」，但它不碰打印机 😄）
- `"Hello, AI!"` 两边带引号，说明它是一段**文字（String，字符串）**
- 这行的意思：「把这段文字显示出来」

恭喜——你和全世界程序员用了同一个仪式入门。

## 自测一下

> [!question]- 1. 解释器和编辑器分别负责什么？只用其中一个能跑代码吗？
> 编辑器负责「写」，解释器负责「翻译执行」。只有编辑器：能写不能跑（等于写了信没寄）。只有解释器：其实能跑！在终端里输入 `python` 会进入交互模式，直接敲一行执行一行——只是不方便写长代码。所以两者配合最舒服。

> [!question]- 2. 安装 Python 时那个「Add python.exe to PATH」勾选框是干嘛的？
> 它告诉操作系统「Python 装在了哪里」。勾上之后，你在任何位置打开终端输入 `python` 都能找到它；不勾的话终端会说「无法识别的命令」。相当于给新同事录入通讯录——不录，喊破喉咙他也听不见。

> [!question]- 3. `print("Hello, AI!")` 里如果忘了写引号，写成 `print(Hello, AI!)` 会怎样？
> 会报错（SyntaxError）。没有引号的 `Hello` 会被 Python 当成一个「变量名」去找，找不到就报错。记住：**引号包起来的才是文字，不带引号的是给变量、函数用的名字**——这是下一课的主题。

> [!question]- 4. 完全不想在电脑上装任何东西，现在就想试试 Python，有什么办法？
> 用浏览器打开 Google Colab（colab.research.google.com），新建笔记本即可在线写代码、在线运行，免费。代价是需要网络，且和本机环境略有差异。作为「先试试水」完全够用，以后认真学了再装本机环境也不迟。
