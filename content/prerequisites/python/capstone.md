## 核心概念拆解：标准五步流程

### 第 0 步：拿到并认识数据

我们使用一份模拟生成的学生数据（100 名学生的 `学习时长`、`出勤率`、`成绩`），生成方式完全公开、可复现：

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(seed=42)          # 固定种子：任何人重跑结果一致
n = 100

hours = rng.uniform(1, 10, n).round(1)        # 每周学习时长 1~10 小时
attendance = np.clip(rng.normal(0.85, 0.08, n), 0.5, 1.0).round(2)
# 成绩 = 时长的真实效应 + 出勤效应 + 噪声（模拟现实的不完美）
score = (40 + hours * 4.2 + attendance * 25
         + rng.normal(0, 6, n)).clip(0, 100).round(1)

df = pd.DataFrame({"时长": hours, "出勤率": attendance, "成绩": score})
df.to_csv("students.csv", index=False)
```

> [!note] 为什么用模拟数据？
> 因为它「参数已知」：我们亲手把「每小时值 4.2 分」埋进数据里。分析结束后回头对照——你的结论找到这个真相了吗？这是自学统计学最干净的练习场。（真实公开数据集推荐 Kaggle 的 Titanic / 房价数据，P10 之后可自行挑战。）

### 第 1 步：体检（Pandas）

```python
print(df.head())

```

关键输出：

```text
   时长   出勤率    成绩
count  100.00  100.00  100.00     ← 没有缺失（三列都是 100）
mean    5.38    0.85   83.35
std     2.46    0.08   11.01
min     1.10    0.68   59.10       ← 成绩最低 59.1，没有离谱的 0 或负数

```

体检结论：无缺失、无异常值、范围合理。**可以放心进入下一步**。

### 第 2 步：可视化初探（Matplotlib）

先画散点图看关系：

```python
import matplotlib.pyplot as plt

plt.scatter(df["时长"], df["成绩"], alpha=0.6)
plt.xlabel("每周学习时长"); plt.ylabel("成绩")
plt.title("时长 vs 成绩")
plt.show()
```

点云从左下往右上爬升——肉眼可见的正相关。但「正相关」有多强？下一步量化。

### 第 3 步：量化关系（NumPy 上场）

用**相关系数（Correlation Coefficient）**给「关系的强弱」打分（−1 到 1）：

```python
r = np.corrcoef(df["时长"], df["成绩"])[0, 1]
print(f"相关系数 r = {r:.3f}")

slope, intercept = np.polyfit(df["时长"], df["成绩"], 1)
print(f"拟合直线: 成绩 ≈ {intercept:.1f} + {slope:.2f} × 时长")
```

实测输出：

```text
相关系数 r = 0.828
拟合直线: 成绩 ≈ 63.4 + 3.71 × 时长
```

读法：r ≈ 0.83 是相当强的正相关；斜率 3.71 ≈ **每周多学 1 小时，平均多考约 3.7 分**。

### 第 4 步：把结论画出来

```python
xs = np.linspace(df["时长"].min(), df["时长"].max(), 50)
plt.scatter(df["时长"], df["成绩"], alpha=0.6, label="学生")
plt.plot(xs, intercept + slope * xs, color="red", linewidth=2,
         label=f"趋势线: +{slope:.1f}分/小时")
plt.xlabel("每周学习时长"); plt.ylabel("成绩")
plt.legend(); plt.show()
```

一条红线穿过点云中心——这就是 ML2《线性回归》要做的事，你已经提前手工做了一遍！

### 第 5 步：诚实地下结论

> [!important] 本课最重要的一块告示牌
> 我们发现了强相关，但这**不能证明**「多学习导致高成绩」。也许是爱学习的同学本来就坐得住（出勤率同时影响两者）。统计学的铁律：**相关 ≠ 因果（Correlation ≠ Causation）**。
>
> 完整的结论应该写成：「在本份数据中，学习时长与成绩呈强正相关（r≈0.83）；在控制其他因素前，不宜直接断言因果。」——把不确定的部分明说出来，恰恰是专业的标志。

## 自测一下

> [!question]- 1. 五步流程里，为什么「体检」要排在最前面？
> 因为后续每一步都建立在「数据是干净的」假设上。没体检就分析，等于蒙眼开车：缺失值会让统计悄悄失真、异常值能把均值拖偏、类型错误让整列数字变文字。花 5 分钟体检，避免后面几小时返工——以及最糟的情况：基于脏数据得出漂亮却错误的结论。

> [!question]- 2. r = −0.9 和 r = 0.3，哪个关系更强？
> **r = −0.9 更强**。符号只管方向（负 = 一涨一跌），绝对值才管强弱：|−0.9| 远大于 |0.3|。「气温越高、羽绒服销量越低」是极强的负相关——比「学习时长和成绩 r=0.3 的弱正相关」紧密得多。新手常犯的错就是看到负号以为「关系弱」。

> [!question]- 3. 我们的拟合斜率是 3.71，而生成数据时埋的真实值是 4.2。为什么不完全一致？差多少算「正常」？
> 因为真实效应被两层东西盖住了：出勤率的干扰和随机噪声（σ=6 分）。样本有限时，估计值永远在真值附近晃动——这次偏低约 12%，换个种子可能偏高。**只要差距在噪声允许范围内就算正常**；想更精确要么加大样本量，要么降低噪声。理解「估计 ≠ 真值」，就理解了所有统计报告为什么要附误差范围。

> [!question]- 4. 「相关不等于因果」，请构造一个生活例子说明混淆两者的荒谬结论。
> 经典例子：冰淇淋销量与溺水人数高度正相关——难道该禁售冰淇淋？真相是第三者「夏天高温」同时推高了两者。同理，「做习题多的学生成绩好」也可能是「学习动机强」同时在推高两者。识别方法：问一句「有没有别的因素同时影响这两件事？」——这个问题能帮你识破大半新闻里的统计把戏。
