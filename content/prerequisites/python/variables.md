## 生活场景切入

快递驿站怎么管理包裹？每个包裹上贴一张面单：**取件码 + 内容**。

```text
A-1001 → 一个纸箱
B-2002 → 一袋水果
C-3003 → 一封信
```

店员不需要记住「那个装书的箱子放在哪」，只需要看面单。变量就是编程世界的面单：

```python
box = "一箱书"      # 名字叫 box 的变量，装着一段文字
age = 25            # 名字叫 age 的变量，装着一个数字
```

以后程序里所有地方写 `box`，Python 都会自动替你换成「一箱书」。**名字是给人看的，内容才是程序真正记着的**。

## 核心概念拆解

### 概念 1：赋值——`=` 的真正含义

在数学里 `x = 5` 是一句「陈述」：x 等于 5。在 Python 里，`x = 5` 是一个**动作**：

```python
x = 5          # 把 5 装进名叫 x 的盒子
x = x + 1      # 把盒子里现有的 5 拿出来加 1，再装回去 → 现在 x 是 6
```

第二行在数学课上会得零分（x 不可能等于 x+1），但在编程里天经地义。读法要改过来：

| 符号 | 数学里的意思 | Python 里的意思                        |
| ---- | ------------ | -------------------------------------- |
| `=`  | 两边相等     | **把右边的值装进左边的名字**（叫赋值） |
| `==` | （不存在）   | 判断两边是否相等（下一课讲）           |

### 概念 2：四大基本类型

数据有不同的种类，就像盒子有不同形状。Python 里最常用的四种：

| 类型名 | 英文  | 长相示例        | 用途                     |
| ------ | ----- | --------------- | ------------------------ |
| 整数   | int   | `42`, `-7`      | 计数、年龄、循环次数     |
| 浮点数 | float | `3.14`, `-0.5`  | 带小数的测量值、概率     |
| 字符串 | str   | `"猫"`, `'AI'`  | 文字：名字、句子、提示语 |
| 布尔值 | bool  | `True`, `False` | 对/错判断，只有这两个值  |

用自带的 `type()` 函数可以随时查看一个值的类型：

```python
print(type(42))        # <class 'int'>
print(type("42"))      # <class 'str'>   ← 加了引号就变成文字！
print(type(3.14))      # <class 'float'>
print(type(True))      # <class 'bool'>
```

> [!warning] 新手第一大坑：`"42"` 和 `42` 不是一回事
> 带引号的是**字符串**（两个字符「4」「2」并排），不带引号的是**数字**（能加减乘除）。`"42" + 1` 会直接报错——文字和数字没法相加。这个坑 AI 圈也天天踩：从文件里读出来的数字默认都是字符串，要先转换才能计算。

### 概念 3：变量可以随用随换

变量的「变」字名副其实——同一个名字可以随时装入新值，甚至新类型：

```python
message = "你好"
print(message)      # 你好

message = "Hello"
print(message)      # Hello   ← 旧值被覆盖了

message = 100       # 甚至可以换成数字（Python 不管你）
print(message)      # 100
```

Python 是**动态类型**语言：不要求提前声明「这个变量只能装整数」。自由，但也意味着你要自己心里有数。

### 概念 4：AI 代码里的变量长什么样？

看一段真实的机器学习代码（现在只需看变量名）：

```python
learning_rate = 0.01     # float —— 学习率
epochs = 50              # int    —— 训练轮数
model_name = "my_first_model"  # str —— 模型名
is_trained = False       # bool   —— 训练了吗？
```

发现了吗？好代码的变量名**见名知意**。`lr`、`x2`、`abc123` 这种名字也能跑，但三个月后你自己都看不懂。

## 本章英文小词典

| 英文           | 中文       | 一句话记忆                                   |
| -------------- | ---------- | -------------------------------------------- |
| Variable       | 变量       | vary 变化 + able 能…的 → 能变的量            |
| Assignment     | 赋值       | assign 分派 → 把值分派给名字                 |

## 自测一下

> [!question]- 1. 执行下面三行后，屏幕上打印出什么？
>
> ```python
> a = 10
> b = a
> a = 99
> print(b)
> ```
>
> 打印 **10**。`b = a` 发生在 a 还是 10 的时候——b 复制了当时的值，之后 a 怎么改都与 b 无关。变量存的是「值」而不是「和 a 的绑定关系」。这是初学者最容易想错的一题。

> [!question]- 2. `type("3.14")` 和 `type(3.14)` 分别是什么？为什么不同？
> 前者是 `str`（字符串）：引号让里面的 3.14 变成了四个字符「3」「.」「1」「4」；后者是 `float`（浮点数）。区别很实际：`"3.14" * 2` 得到 `"3.143.14"`（重复两遍的文字），而 `3.14 * 2` 得到 `6.28`（算术运算）。

> [!question]- 3. 下面哪个是合法的变量名？为什么其余不行？
>
> ```text
> ① my-name  ② model_2  ③ 2nd_place  ④ print
> ```
>
> **② 合法**。①不行：连字符 `-` 会被当成减号（要用下划线 `_`）；③不行：变量名不能以数字开头；④不报错但危险——`print` 是内置函数名，覆盖它之后你就没法打印了。命名规则小结：字母/下划线开头，后面可跟字母数字下划线，且避开关键字和内置名。

> [!question]- 4. 为什么说 AI 工程里「从文件读出来的数字要小心类型」？
> CSV 表格、JSON 文件、网页输入框拿到的数据几乎都是字符串。直接拿来训练模型会报错或算出离谱结果，必须先转成数值（如 `float(x)`）。真实事故模式：某列数据混进一个空值，整列悄悄变成字符串，模型精度暴跌——排查两小时，最后发现是类型问题。**类型意识是数据清洗的第一课**。
