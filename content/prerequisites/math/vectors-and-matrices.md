> [!abstract] 本课将学到
>
> - **向量（Vector）**：一串有序的数字——数据点的通用外形
> - **点积（Dot Product）**：两个向量有多「合拍」；余弦相似度怎么算出「语义相似」
> - **矩阵（Matrix）**：向量的批量加工厂，乘法规则一次讲透
> - 形状匹配：(3,4) @ (4,2) → (3,2)，AI 代码里最常见的报错来源
> - 用 NumPy 把一切变成一行代码

## 生活场景切入

想给朋友描述今天的心情，你可以说：「开心 8 分、精力 6 分、焦虑 3 分」。

```text
心情 = (8, 6, 3)
```

三个数字按固定顺序排列——这个结构就是向量。把维度加多：

- 一张 28×28 的手写数字图 → 展平成 784 维向量
- 一个词在 GPT 眼中 → 几千维的向量（术语叫 embedding 嵌入）
- 一位病人的体检结果 → 血压、心率、血糖……几十维向量

**AI 不认识猫、不认识句子、不认识病人——它只看见向量。**本课的任务就是搞清这些数字阵列怎么加减、怎么相乘、怎么衡量相似。

## 核心概念拆解

### 概念 1：向量 —— 排好队的数字

```text
v = (3, 1, 2)          写成一行叫行向量
v = [3]
    [1]                写成一列叫列向量
    [2]
```

两个基本操作：

```text
加法（对位相加）：   (1,2) + (10,20) = (11,22)
数乘（每个都乘）：   3 × (1,2) = (3,6)
```

**几何直觉**（二维时最好画）：向量是一个带方向的箭头；加法是「接龙」（先走 a 再走 b）；数乘是「拉长/缩短/反向」。三维以上画不出来，但代数规则一模一样——**高维只是二维的延伸，不必害怕**。

### 概念 2：点积 —— 合拍程度测量仪

两个等长向量做**点积**：对应位置相乘再全部加起来，结果是**一个数**：

```text
(1, 2, 3) · (4, 5, 6) = 1×4 + 2×5 + 3×6 = 32
```

它为什么重要？因为它同时编码了「长度」和「方向夹角」：

```text
a · b = |a| × |b| × cos θ        （θ 是两箭头的夹角）
```

由此得到 AI 里出场率极高的**余弦相似度**：

```text
cos_sim(a, b) = a·b / (|a||b|)
=  1   两箭头同方向 → 内容几乎相同
≈ 0   垂直 → 毫无关系
= −1  正相反
```

**这就是「语义搜索」的全部数学骨架**：把「小猫」「猫咪」「Kitty」各自变成向量后，意思相近的词向量方向也接近，cos_sim 接近 1——模型从没被告知它们是近义词，是从海量文本里自己学出来的这种排列。

```python
from math import sqrt, isclose

def dot(a, b): return sum(x*y for x, y in zip(a, b))
def norm(a):   return sqrt(dot(a, a))
def cos_sim(a, b): return dot(a, b) / (norm(a) * norm(b))

print(cos_sim([1, 0], [0, 1]))       # 0.0      垂直：无关
print(round(cos_sim([1, 1], [1, 0]), 4))   # 0.7071  45° 夹角
print(cos_sim([1, 2], [2, 4]))       # 1.0      同方向（长度不同也算同向！）
```

### 概念 3：矩阵乘法 —— 别背口诀，看懂流水线

矩阵（Matrix）就是长方形的数字表格。`m×n` 矩阵可以看作 n 维向量加工成 m 维向量的机器。乘法规则：

```text
A (m×n) @ B (n×p) = C (m×p)

核心动作：C 的第 i 行第 j 列 = A 的第 i 行 · B 的第 j 列
即：每一格都是一次点积！
```

亲手算一个：

```text
A = [1 2]     B = [0 1]
    [3 4]         [1 0]

C[1][1] = A行1 · B列1 = (1,2)·(0,1) = 0+2 = 2
C[1][2] = A行1 · B列2 = (1,2)·(1,0) = 1+0 = 1
C[2][1] = (3,4)·(0,1) = 4          C[2][2] = (3,4)·(1,0) = 3

C = [2 1]
    [4 3]
```

三条必须内化的性质：

1. **形状守门员**：中间两个数字必须相等 `(m×n)@（n×p)`，外侧给出结果形状 `(m×p)`。AI 报错榜第一名 `shape mismatch` 就是它。
2. **顺序有所谓**：一般 `AB ≠ BA`（上面例子里 `BA` 根本算不了——形状不允许）。
3. **本质是复合变换**：M3 讲过复合函数；矩阵连乘就是把多步线性变换串成一步——深度网络的层层加工在数学上就是一连串矩阵乘法。

### 概念 4：神经网络里的矩阵 —— 一次真实的「前向传播」

最小的一层网络：输入 x（3 维），输出 h（2 维）：

```text
h = W @ x + b        W 是 2×3 权重矩阵，b 是 2 维偏置向量

W = [0.5  0.2  -0.1]      b = [0.1]
    [0.3  -0.4  0.6]          [0.2]

x = (1, 2, 3)
第一行点积: 0.5×1 + 0.2×2 − 0.1×3 = 0.6，加偏置 0.1 → 0.7
第二行点积: 0.3×1 − 0.4×2 + 0.6×3 = 1.3，加偏置 0.2 → 1.5
h = (0.7, 1.5)
```

B1 伴学页里那个「认数字的网络」，其 13002 个参数就是以这种方式组织成的几个大矩阵——所谓推理，不过是几次矩阵乘法加点激活函数。

### 概念 5：NumPy 实战 —— 十行代码验证全部理论

```python
import numpy as np

v = np.array([1, 2, 3]); w = np.array([4, 5, 6])
print(np.dot(v, w))                      # 32 —— 点积

A = np.array([[1, 2], [3, 4]])
B = np.array([[0, 1], [1, 0]])
print(A @ B)                             # [[2 1] [4 3]] —— 与手算一致

X = np.ones((3, 4)); W2 = np.ones((4, 2))
print((X @ W2).shape)                    # (3, 2) —— 形状守门员

# 终极演示：梯度下降拟合 y ≈ 2x + 1（M7 的完整预告片）
import random; random.seed(42)
xs = [i * 0.1 for i in range(50)]
ys = [2 * x + 1 + random.gauss(0, 0.05) for x in xs]

a, b, lr = 0.0, 0.0, 0.1
for _ in range(3000):
    ga = gb = 0.0
    for x, y in zip(xs, ys):
        ga += -2 * x * (y - (a*x + b))
        gb += -2 * (y - (a*x + b))
    a -= lr * ga / len(xs); b -= lr * gb / len(xs)

print(f"拟合结果 y ≈ {a:.3f}x + {b:.3f}")    # 拟合结果 y ≈ 1.999x + 0.999
# —— 从噪声数据里找回了 2 和 1：这就是「学习」二字最朴素的模样
```

> [!tip] 为什么 NumPy 是 M 板块和 P 板块的会合点？
> 向量加法/数乘/点积/矩阵乘法，纯 Python 循环都能写但啰嗦且慢；NumPy 的 `@` 一键完成且底层并行加速（P7 学过的向量化）。后面 ML 板块的手写线性回归、DL 板块的 PyTorch 张量，语法几乎照搬 NumPy——这一课的投资会一直花到最后一章。

## 自测一下

> [!question]- 1. 计算 `(2, −1, 3) · (−1, 4, 2)`
> `2×(−1) + (−1)×4 + 3×2 = −2 −4 + 6 = 0`。
> 点积为零说明这两个向量**互相垂直**（cos θ = 0）。垂直在高维里叫「正交」——互不携带对方的信息，这个性质后面正交化、注意力机制里都会遇到。

> [!question]- 2. A 是 (2×3)，B 是 (3×5)。AB 能算吗？BA 呢？结果的形状各是什么？
> `AB` 可以：中间的 3 对上了，结果 **(2×5)**。
> `BA` 不行：B 的列数 5 ≠ A 的行数 2，形状不匹配直接报错。
> 这题考的就是形状守门员——写 PyTorch 代码时 90% 的 shape 错误靠它在脑内 3 秒排查。

> [!question]- 3. 已知词向量 king=(1,1)、queen=(0.9,1.1)、apple=(−1,0.5)。哪个词与 king 最相似？（用余弦相似度比较 queen 和 apple）
> cos(king, queen)：分子 1×0.9+1×1.1 = 2.0；分母 √2 × √(0.81+1.21)=√2×√2.02≈1.414×1.421≈2.010 → ≈ **0.995**。
> cos(king, apple)：分子 1×(−1)+1×0.5 = −0.5；分母 √2 × √1.25≈1.414×1.118≈1.581 → ≈ **−0.32**。
> queen 远比 apple 相似。真实 embedding 中「国王—女王」这类近义词对确实能到 0.9 以上——余弦相似度是检索系统判断「相关」的第一道闸门。

> [!question]- 4. 为什么说「矩阵乘法顺序有所谓」和「网络层叠 = 复合函数」说的是同一件事？
> 单层变换 `h = Wx` 本质是一个函数；两层串联 `h₂ = W₂(W₁x)` 就是复合函数 `W₂∘W₁`，而它整体等价于一个新矩阵 `W₂W₁`——**注意必须是 W₂ 在前**，交换就换成了另一个完全不同的复合。
> 所以「AB≠BA」不是抽象代数的怪癖，而是「先穿袜子再穿鞋」不能颠倒的数学表述。深度网络的层序不可调换，根源正在这里。
