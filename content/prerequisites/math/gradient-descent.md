## 生活场景切入

游戏规则：你被蒙上眼空投到山坡上，要在有限步数内走到**最低的谷底**。你能感知的只有脚下的坡度。

策略其实只有一个：

1. 感受脚下哪边是下坡
2. 朝下坡方向迈一步（坡越陡步子越大）
3. 重复，直到脚下变平

这个朴素到近乎笨拙的策略，就是**梯度下降**。GPT、扩散模型、推荐系统……几乎所有 AI 的「训练」二字，翻译成数学都是这条循环。区别只是：山坡换成了误差函数，你的位置换成模型的几亿个参数。

## 核心概念拆解

### 概念 1：损失函数 —— 把「学得好不好」变成一座山

M3 说过模型是函数；训练要给它的输出打个分。**损失函数（Loss Function）** L 就是这个打分器：

```text
例：模型预测房价 w（万），真实价 120 万
    L(w) = (w − 120)²        ← 偏差平方（M1 的平方在这里上岗）
```

| 预测 w | 误差 w−120 | 损失 (w−120)² |
| ------ | ---------- | ------------- |
| 120    | 0          | **0** ← 谷底  |
| 110    | −10        | 100           |
| 130    | +10        | 100           |
| 90     | −30        | 900           |

画出来是一条开口向上的抛物线，最低点在 w=120。「训练」就是从某个初始猜测出发，找到让 L 最小的参数。

### 概念 2：一维下山 —— 导数指路

一维世界里（只有一个参数），下坡方向由导数的符号直接给出：

```text
在 w=100 处：L′(100) = 2(100−120) = −40   导数为负 → 右边是下坡 → 往右走
在 w=140 处：L′(140) = +40                导数为正 → 左边是下坡 → 往左走
```

发现规律了吗？**无论在哪，减去导数就是往低处走**。写出更新规则：

```text
新 w = 旧 w − 步长 × L′(旧 w)
```

用代码走一遍全程（真实运行结果）：

```python
def L(w):  return (w - 3) ** 2      # 目标：找到谷底 w=3
def dL(w): return 2 * (w - 3)       # 导数

w, lr, path = 0.0, 0.1, [0.0]
for _ in range(30):
    w -= lr * dL(w)
    path.append(round(w, 4))

print(path[:6])       # [0.0, 0.6, 1.08, 1.464, 1.7712, 2.017]
print("最终 w ≈", round(w, 5))    # 最终 w ≈ 2.99629 —— 收敛到了谷底附近
```

注意两个细节：① 离谷底越远导数越大、步子越大——**自动变速**；② 越接近谷底步子越小，永远差一点点但越来越近——这就是为什么训练曲线后期看起来「贴着地面爬」。

### 概念 3：多维世界 —— 从导数到梯度

真实模型有百万~万亿个参数，不是一个坐标而是一整个位置向量。每个方向各有各的坡度，把它们打包成一个向量：

```text
∇L = ( ∂L/∂w₁ , ∂L/∂w₂ , … , ∂L/∂wₙ )        读作 grad L 或「拿布la」
```

其中 `∂L/∂w₁`（读「偏 L 偏 w₁」）就是 M6 的导数，只不过**只动 w₁、其他参数全冻结**时算出的变化率，叫**偏导数（Partial Derivative）**。

**梯度的物理含义：当前点上坡最陡的方向。** 所以反方向 `−∇L` 就是下坡最陡的方向——蒙眼者的指南针。

二维演示（真实收敛）：

```python
def grad(w1, w2):                    # L = (w1-1)² + (w2+2)²
    return (2*(w1 - 1), 2*(w2 + 2))

w1, w2 = 5.0, 5.0
for _ in range(100):
    g1, g2 = grad(w1, w2)
    w1 -= 0.1 * g1
    w2 -= 0.1 * g2

print(round(w1, 4), round(w2, 4))    # 1.0 -2.0 —— 双双落进谷底
```

### 概念 4：那条著名的公式

把上面的一切压缩成一行——它值得被单独记住：

```text
w ← w − η · ∇L(w)
```

| 符号    | 名字                 | 人话                   |
| ------- | -------------------- | ---------------------- |
| `w`     | 参数（权重）         | 你站在山上的位置       |
| `←`     | 更新                 | 算出右边后覆盖左边     |
| `η`     | 学习率 Learning Rate | 步长系数，希腊字母 eta |
| `∇L(w)` | 梯度                 | 当前位置的上坡方向     |

负号是灵魂：减去上坡方向 = 迈向下坡。每一轮完整执行叫一次**迭代（Iteration）**；把全部训练数据过一遍叫一个**轮次（Epoch）**。

### 概念 5：学习率 —— 全部手艺浓缩在一个旋钮

η 是训练中最重要的人工设定的数（术语叫超参数）。三种命运：

```python
# lr 合适（0.1）：30 步内稳稳滑向谷底（见概念 2 的输出）

# lr 太大（1.1）：每步冲过头，越荡越高，发散爆炸！
w = 10.0
ws = []
for _ in range(6):
    w -= 1.1 * 2 * w            # L = w² 的梯度 2w
    ws.append(round(abs(w), 2))
print(ws)   # [12.0, 14.4, 17.28, 20.74, 24.88, 29.86] —— 一去不回
```

| η 的大小 | 现象               | 训练日志里的样子      |
| -------- | ------------------ | --------------------- |
| 太大     | 来回震荡甚至发散   | loss 变 NaN / 飞天    |
| 太小     | 每步挪一丝，磨洋工 | loss 千轮不动的水平线 |
| 合适     | 快速下降后平稳收敛 | 先陡后缓的标准滑坡    |

实战常用「先大后小」的**衰减调度**（M4 学过指数衰减：`lr(t) = lr₀ × 0.5ᵗ`），前期大步赶路、后期小步校准。

### 概念 6：局部最优与随机性 —— 真实世界的妥协

抛物线只有一个谷底，很幸运。真实损失面是亿维空间里崎岖的高原：无数小水洼（**局部最小值**）、平缓的鞍点。纯梯度下降可能一头栽进第一个水洼就宣布完工。

两大对策（名字混个脸熟即可，细节留给 ML/DL 板块）：

1. **随机梯度下降 SGD**：每次只用一小撮样本估梯度，而不是全部数据。估计带噪声——像下山时脚下打滑——反而常常帮你蹦出水洼。噪声还顺带把计算量砍掉几个数量级。
2. **动量 Momentum**：更新时保留一部分历史速度，像铁球滚动一样冲过小平地和浅坑。

还有一句反直觉的话值得带走：在大模型的世界里，研究者发现**大量局部最优彼此质量差不多**，真正的敌人是鞍点和平坦区。所以「陷入局部最优」没有传说中那么可怕——这是深度学习时代修正过的旧直觉。

| Loss function                     | 损失函数     | 给模型表现打分的错误度量器           |
| Gradient                          | 梯度         | 各方向偏导打包成的向量，指向最陡上坡 |
| Partial derivative                | 偏导数       | 冻结其他参数、只对一个求导           |
| Gradient descent                  | 梯度下降     | 沿负梯度反复更新的优化算法           |

## 自测一下

> [!question]- 1. 已知 L(w) = (w − 5)²，当前 w = 8，学习率 η = 0.25。手动算两步更新后的 w。
> 第一步：L′(w) = 2(w−5)，L′(8) = 6；`w ← 8 − 0.25×6 = 8 − 1.5 = 6.5`。
> 第二步：L′(6.5) = 3；`w ← 6.5 − 0.75 = 5.75`。
> 观察：每步都朝 5 靠近且步子在变小——自动减速是梯度下降的内置属性。

> [!question]- 2. 训练日志显示 loss 变成了 NaN（Not a Number）。用本课的知识给出最可能的第一个怀疑对象与修复动作。
> 第一嫌疑人是**学习率过大导致发散**：某一步跨得太远，损失值溢出浮点上限，数值系统崩溃成 NaN（概念 5 的「飞天」现象）。
> 修复动作：把 η 缩小 10 倍重新训练。若仍复现，再排查数据里是否有异常值/除零。工程经验：90% 的 NaN 来自学习率或脏数据，先查这两个。

> [!question]- 3. 为什么「只用一小撮样本估梯度」（SGD）反而可能比用全部数据更好？说出两条理由。
> ① **速度**：数据量动辄千万级，全量算一次梯度代价巨大；小批量的噪声估计便宜几个数量级，单位时间能走更多步。
> ② **逃逸能力**：噪声让轨迹抖动，不容易死死卡进第一个局部水洼或鞍点的平台；相当于给下山的人加了一点随机踉跄。
> （可加分的一句：噪声还随训练可以逐渐调小——batch 增大或衰减学习率——实现「前期探索、后期精修」。）

> [!question]- 4. 把本课内容串起来回答：为什么说「训练 AI」这句话在数学上是「优化问题」？
> 模型是一台带旋钮（参数 w）的机器（M3）；「学得好不好」被写成损失函数 L(w)（本课概念 1）；训练就是寻找让 L 最小的 w——即求解 `argmin_w L(w)`，这正是优化的定义。
> 由于无法一步解出答案（参数亿万级），采用迭代式数值方法（M2 二分法的亲戚）：每处用导数/梯度（M6）指示下降方向，按 `w ← w − η∇L(w)` 反复挪动直到收敛。所以：**训练 AI = 在亿维曲线上蒙眼下山**。
