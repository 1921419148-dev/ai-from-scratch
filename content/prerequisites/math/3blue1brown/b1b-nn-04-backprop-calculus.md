## 🗺 先拿地图

第 3 集说「锅按权重比例往回分摊」，这一集证明这句话在数学上就是**链式法则**：

```mermaid
LR
    A["∂C/∂w⁽ᴸ⁾<br/>最后一层权重的梯度"] --> B["乘上局部导数<br/>σ′(z)、a⁽ᴸ⁻¹⁾"]
    B --> C["得到 ∂C/∂a⁽ᴸ⁻¹⁾<br/>把信号传给前一层"]
    C --> D["再乘前一层的局部导数……<br/>循环到输入层"]
```

视频的展开顺序：

1. **约定记号**：每层神经元的「加权和」叫 z，「过完 Sigmoid 的值」叫 a。损失 C 是最外层的输出。
2. **单个训练样本、单个权重**开始：求 ∂C/∂w⁽ᴸ⁾——最后一层某条连线的梯度。
3. **三步走**：
   - C 对 a⁽ᴸ⁾ 多敏感？（激活值的影响）
   - a 对 z 多敏感？（Sigmoid 的斜率 σ′）
   - z 对 w 多敏感？（上一层的激活值本身）
   - **三者相乘 = 该权重的梯度**
4. **推广到偏置**：同样的套路少乘一个因子，白送。
5. **递归**：想拿前一层的梯度？需要 ∂C/∂a⁽ᴸ⁻¹⁾——它由后一层的梯度**聚合而来**。于是整个过程天然是「从后往前」，这就是名字里「反向」的由来。

## 🧠 核心概念拆解

### 概念 1：链式法则 = 敏感度相乘

高中版你已经见过：

$$\frac{dz}{dx} = \frac{dz}{du}\cdot\frac{du}{dx}$$

人话：「x 动一点 → u 动多少；u 动一点 → z 又动多少。**两段敏感度连乘**就是全程敏感度。」反向传播只是把它用在 1.3 万个参数上，并且**从后往前**算以复用中间结果。

### 概念 2：每个节点只干一件小事

反向传播最漂亮的地方：没有任何一个神经元需要「看全局」。每个节点只需要知道两样东西：

1. **传来的信号**（下游对它的总诉求）
2. **自己的局部导数**（自己这个小运算对输入的敏感度）

然后做一次乘法，把结果往前传。亿万次「小乘法」接力，就完成了整张账单。

### 概念 4 个字总结：乘、加、传

| 动作 | 对应操作 |
| --- | --- |
| 乘 | 信号 × 局部导数（链式法则） |
| 加 | 多个下游来的信号求和（多元链式法则） |
| 传 | 把结果送给更早的一层 |

### 概念 3：σ′ ≤ 0.25 与「梯度消失」

视频没展开但值得点破：Sigmoid 的导数最大才 0.25，且两端趋近 0。信号每穿一层都要乘一次 σ′——层数一多，连乘几个小数，传到前面的信号就**指数级萎缩**。这正是早期深层网络「训不动」的著名原因之一（梯度消失），也是 ReLU 等替代激活函数崛起的动机。

## ✅ 自测一下

> [!question]- 1. 用一句话说明链式法则和反向传播的关系。
> 链式法则是数学原理（复合函数的导数 = 各环节导数连乘），反向传播是它在网络上的高效实现（从输出层出发、复用中间结果、逐层往前递推）。

> [!question]- 2. 为什么反向传播要「从后往前」而不是随便哪头开始算？
> 因为前一层梯度 = 后一层传来的信号 × 前一层的局部导数。没有后一层的信号就算不了自己——依赖方向决定了计算顺序必须反向。（这也让所有下游的中间结果都能被复用，避免重复计算。）

> [!question]- 3. 一个神经元同时连接多个下游时，它的「传来信号」怎么算？
> 各下游传回的信号**求和**（多元链式法则：多条路径的贡献叠加）。对应 B3 里说的「多方诉求加在一起，可能互相抵消」。

> [!question]- 4. Sigmoid 的导数最大值是多少？这对深层网络意味着什么？
> 最大 0.25（在 n=0 处取到），两端趋近 0。信号每穿一层至少缩到原来的 1/4，层数多了前面层收到的梯度指数级衰减（梯度消失），训练几乎停滞——这是后来 ReLU 流行的核心原因之一。
