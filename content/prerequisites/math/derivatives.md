> [!abstract] 本课将学到
>
> - **导数（Derivative）**：某一瞬间变化有多快——曲线的速度计
> - 从「平均速度」到「瞬时速度」：极限思想的第一次亮相
> - 求导的基本法则：幂、乘积、链式——三个规则打天下
> - 极值点：导数为零的地方，为什么是「山谷底」
> - AI 视角：训练 = 让损失函数沿着导数的反方向挪

## 生活场景切入

导航软件说「前方路段，10:00–10:30 平均时速 60 km/h」。但这个数字掩盖了一切细节：你可能前 20 分钟堵在 20 km/h，后 10 分钟飙到 100 km/h。

**平均速度**是粗略总结；你真正关心的是**此刻仪表盘上的指针**——瞬时速度。数学上：

```text
平均速度   = 走过的路程 ÷ 花的时间           （一段区间）
瞬时速度   = 时间间隔压到无限短时的速度      （一个瞬间）→ 这就是导数
```

把「速度表」装到任何函数身上，读出来的数就叫导数。AI 训练时模型每一步都在问：「当前参数下，误差的变化速度是多少？」答案就是损失的导数。

## 核心概念拆解

### 概念 1：从割线到切线 —— 极限的一次预演

想求 f(x) 在 x₀ 处的瞬时变化率。直接算不出来（一个瞬间没有「变化」可言），于是用逼近术：

```text
① 取附近一点 x₀+h，两点连线（割线），斜率 = [f(x₀+h) − f(x₀)] / h
② 让 h 缩小：0.1 → 0.01 → 0.001 → …
③ 割线逐渐贴住曲线，最终变成切线；斜率稳定在一个数 —— 就是导数 f′(x₀)
```

记号读法：

| 记号        | 读法     | 含义                        |
| ----------- | -------- | --------------------------- |
| `f′(x)`     | f 一撇   | f 的导函数                  |
| `dy/dx`     | dy 比 dx | y 的微小变化 ÷ x 的微小变化 |
| `d/dx f(x)` | d 比 dx  | 「对 x 求导」这个动作       |

动手验证一次（比看十遍都有效）：

```python
def f(x): return x * x          # f(x) = x²

def numeric_derivative(x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

for x in [1, 2, 3.5]:
    print(f"x={x} 数值导数 ≈ {numeric_derivative(x):.4f}，理论值 2x = {2*x}")
# x=1 数值导数 ≈ 2.0000   理论值 2x = 2
# x=2 数值导数 ≈ 4.0000   理论值 2x = 4
# x=3.5 数值导数 ≈ 7.0000 理论值 2x = 7
```

x² 的导数恰好是 2x——下面用法则正式推出它。

### 概念 2：三条基本法则

**幂法则**（最常用，没有之一）：

```text
d/dx xⁿ = n·xⁿ⁻¹          「指数掉下来当系数，自己减一」

例：d/dx x² = 2x          d/dx x³ = 3x²
    d/dx √x = d/dx x^½ = ½·x^(−½)
```

**线性组合法则**：常数提出来，逐项分别求导：

```text
d/dx [3x³ + 5x − 7] = 9x² + 5        （−7 的导数是 0：静止的东西没有变化率）
```

**常用函数速查**（M4/M5 的伏笔在此兑现）：

| 函数    | 导数     | 一句话                   |
| ------- | -------- | ------------------------ |
| `eˣ`    | `eˣ`     | 自己的导数是自己，独一份 |
| `ln x`  | `1/x`    | 对数求导变倒数           |
| `sin x` | `cos x`  | 波形最陡时坡度为 1       |
| `cos x` | `−sin x` | 多个负号                 |

```python
import math
def g(x): return x**3 - 2*x + 1            # 理论导数 3x² − 2
def num_g(x, h=1e-6): return (g(x+h)-g(x-h))/(2*h)

print(round(num_g(2), 4), 3*4 - 2)          # 10.0 10  ✓
def e2(x): return 2 ** x                    # (2ˣ)' = 2ˣ·ln2
print(round((e2(1+1e-7)-e2(1-1e-7))/2e-7, 4), round(2*math.log(2), 4))   # 1.3863 1.3863
```

### 概念 3：乘积与商法则

两台机器相乘时，不能各自求导一乘了事。正确姿势：

```text
乘积：(u·v)′ = u′v + uv′          「各求各的，交叉相乘再相加」

例：d/dx (x² · sin x) = 2x·sin x + x²·cos x
```

数值验证（Python 实测输出）：

```python
import math
h = 1e-6
f = lambda x: x*x*math.sin(x)
num = lambda x: (f(x+h)-f(x-h))/(2*h)
theory = lambda x: 2*x*math.sin(x) + x*x*math.cos(x)
for x in [0.5, 1.0, 2.0]:
    print(round(num(x),5), round(theory(x),5))
# 0.91822 0.91822 | 1.38177 1.38177 | 3.077 3.077   ← 完全吻合
```

商法则长得吓人，但可以少背——除法当成乘倒数再用链式法则（下一节）：`(u/v)′ = (u·v⁻¹)′`。

### 概念 4：链式法则 —— 本课的心脏

复合函数（M3 概念 4）怎么求导？

```text
y = f(g(x)) 的导数 = 外层导数 × 内层导数

dy/dx = f′(g(x)) · g′(x)        「外层的导数作用在内层上，再乘内层的导数」
```

直觉版本——齿轮传动：大轮转 3 圈/分（外层速率），小轮随轴转 5 圈/分（内层速率），末端总速率 = 3 × 5 = 15 圈/分。**速率相乘，链条相接。**

完整例子：

```text
y = (2x + 1)²
外层：平方 → 导数 2·(□)
内层：2x+1 → 导数 2

y′ = 2(2x+1) × 2 = 8x + 4
```

```python
def y(x): return (2*x+1)**2
def y_num(x, h=1e-6): return (y(x+h)-y(x-h))/(2*h)

for x in [0, 1, 2]:
    print(f"x={x}: {y_num(x):.4f} vs 8x+4 = {8*x+4}")
# x=0: 4.0000 vs 4 | x=1: 12.0000 vs 12 | x=2: 20.0000 vs 20   ✓
```

> [!important] 为什么说它是本课心脏？
> 因为反向传播 = 链式法则的系统化执行。神经网络是几十层复合（M3 已铺垫），要回答「第 37 层的某个参数对最终误差有多大影响」，就把从该层到输出的所有局部导数**沿链条连乘**起来。B3/B4 伴学页（[[ai/nn/3blue1brown/index|3B1B 系列]]）把这个过程做成了动画，学到这里强烈建议去看。

### 概念 5：导数为零的地方 —— 山谷与山峰

想象蒙眼下山：脚底感知哪边更陡（导数），朝下坡方向迈步，直到脚下变平（导数=0）——你大概率站在谷底。

```text
f(x) = x² − 4x + 3
f′(x) = 2x − 4 = 0   →   x = 2
f(2) = 4 − 8 + 3 = −1     ← 抛物线最低点，也是最小值
```

（顺手用 M2 的配方法验一下：f(x) = (x−2)² − 1，最小值显然是 −1 ✓）

三种「平地」的区别：

| 形状    | 名称               | 判别               |
| ------- | ------------------ | ------------------ |
| ∪ 底部  | 局部最小值（谷底） | 左侧导数负、右侧正 |
| ∩ 顶部  | 局部最大值（山顶） | 左正右负           |
| ～ 平台 | 鞍点               | 左右同号           |

**人话**：导数为零只说明「这一刻不增不减」，至于是谷底还是山顶要看两侧。M7 的梯度下降会专门对付一个坑：找到的可能只是「小水洼」（局部最优），不是真正的山谷底——但现在先记住结论：**找极值 = 解方程 f′(x) = 0**。这套思想叫优化（optimization），整个机器学习训练都属于它。

## 自测一下

> [!question]- 1. 求 `f(x) = 3x⁴ − 2x² + 5x − 1` 的导数，并计算 f′(1)
> 逐项套幂法则：`f′(x) = 12x³ − 4x + 5`。
> 代入 x=1：`12 − 4 + 5 = 13`。
> 注意 −1 是常数项，导数为 0，直接消失——很多初学者会留个尾巴。

> [!question]- 2. 用乘积法则求 `g(x) = x³ · eˣ` 的导数
> `(u·v)′ = u′v + uv′`，其中 u = x³（u′ = 3x²）、v = eˣ（v′ = eˣ）：
> `g′(x) = 3x²·eˣ + x³·eˣ = x²eˣ(3 + x)`。
> 最后一步是提取公因式 eˣ 和 x²——整理成这种形状方便后续解 g′(x)=0。

> [!question]- 3. 用链式法则求 `h(x) = sin(3x)` 与 `k(x) = ln(x² + 1)` 的导数
> `h′(x) = cos(3x) × 3 = 3cos(3x)`（外层 sin→cos，内层 3x→3，相乘）。
> `k′(x) = 1/(x²+1) × 2x = 2x/(x²+1)`（外层 ln→倒数，内层 x²+1→2x）。
> 口诀复述一遍：先剥外层，再乘内层——像剥洋葱一样由外向内。

> [!question]- 4. 一个模型预测房价，误差函数 E(w) = (w − 120)²（w 是模型给出的估价，真实价 120 万）。E′(w) 在 w=100 处是多少？它的符号说明应该往哪边调整 w？
> `E′(w) = 2(w − 120)`，代 w=100 得 `2×(−20) = −40`。
> 导数为负意味着「w 增大则误差下降」（往右走下坡）。所以应该**增大 w**——即把估价往 120 万方向调。
> 这正是梯度下降每一步在做的事：`新 w = 旧 w − 步长 × E′(w)`，负号保证永远朝下坡走。M7 见！
