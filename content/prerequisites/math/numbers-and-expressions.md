## 生活场景切入

你其实每天都在做数学：

- 外卖满 30 减 8：先判断 **30 − 25.5 够不够门槛**（减法）
- 双人拼单 AA：**总价 ÷ 人数**（除法）
- 冰箱温度 −18°C：负数就在你家冷冻室里
- 手机电量「还剩 23%」：百分比
- 「这块地是那块的 2⁵ 倍大」：幂

这门课不搞题海，只把你在生活里已经会的东西**翻译成数学记号**，再补上几个 AI 领域高频的新记号。

## 核心概念拆解

### 概念 1：运算优先级 —— 数学世界的交通规则

式子 `2 + 3 × 4` 等于多少？如果你答 20，那是从左到右算的；正确答案是 **14**——乘法先排队。

| 优先级 | 运算   | 记号       |
| ------ | ------ | ---------- |
| 1      | 括号   | `( )`      |
| 2      | 幂     | `x²`, `2³` |
| 3      | 乘、除 | `×`, `÷`   |
| 4      | 加、减 | `+`, `−`   |

**人话**：括号是 VIP，永远最先；幂次紧随其后；乘除比加减更急。

```text
2 + 3 × 4      = 2 + 12     = 14
(2 + 3) × 4    = 5 × 4      = 20     ← 括号强制先加
2 + 3²         = 2 + 9      = 11
−2²            = −(2²)      = −4     ← 幂只管 2，负号最后才轮到！
(−2)²          = (−2)×(−2)  = 4      ← 想让负号一起平方就套括号
```

> [!warning] 新手第一坑：−2² 和 (−2)² 不一样
> 编程和论文里都沿用这套规则。Python 里 `-2**2` 是 **−4**，`(-2)**2` 才是 4。看到损失函数里出现平方项时，留意括号的位置——差一个括号，正负号就反了。

### 概念 2：负数 —— 往反方向走

把数轴想成一条东西向的路：0 是你家门口，右边是东，左边是西。

- `+3` 表示向东走 3 步，`−3` 表示向西走 3 步
- 「减一个数」就是「加上它的反向」：`5 − 8 = 5 + (−8) = −3`

两条铁律（后面到处用）：

```text
同号相乘得正，异号相乘得负：
  (−3) × (−4) = +12      负负得正
  (−3) × 4    = −12
```

**为什么负负得正？** 一个直觉：「欠钱翻倍地还清」。「每天欠 3 元」是 −3；「3 天前」（时间倒流，负负）你的钱比现在多 3 × 天数。记住结论即可，不必死抠哲学。

### 概念 3：分数与小数 —— 同一个数的两件外套

分数 `3/4` 的意思就是「3 ÷ 4」。它和小数 `0.75` 是**同一个数**的不同写法。

```text
1/2 = 0.5        1/4 = 0.25       3/4 = 0.75
1/3 = 0.333…（无限循环小数，写不尽）
```

关键规则只有三条：

| 规则           | 式子                           | 人话                      |
| -------------- | ------------------------------ | ------------------------- |
| 分数乘整数     | `2 × 3/4 = 6/4 = 3/2`          | 分子乘上去                |
| 分数除法的翻转 | `a ÷ (b/c) = a × c/b`          | 除以一个分数 = 乘它的倒数 |
| 通分比较       | `2/3 vs 3/5` → `10/15 vs 9/15` | 化成同分母再比            |

**AI 视角**：模型评估报告里的指标几乎全是 0 到 1 之间的小数——准确率 0.87、召回率 0.63。它们本质都是「正确的个数 ÷ 总个数」这种分数。电脑内部一律用小数存储；人脑比较大小的时候，转成分数反而常常更快（比如 0.125 就是 1/8，「八分之一」一听就懂有多小）。

### 概念 4：幂与根 —— 自己乘自己的速记法

`2³` 读作「2 的三次方」，意思是三个 2 连乘：

```text
2³ = 2 × 2 × 2 = 8
5² = 5 × 5 = 25        （读作「5 的平方」）
10⁶ = 1000000          （一百万，科学计数法的常客）
```

三条指数律（**本课最重要的三行字**，M4 全靠它们）：

| 名称               | 式子             | 数值例子             |
| ------------------ | ---------------- | -------------------- |
| 同底相乘，指数相加 | `aᵐ × aⁿ = aᵐ⁺ⁿ` | `2³ × 2⁴ = 2⁷ = 128` |
| 同底相除，指数相减 | `aᵐ ÷ aⁿ = aᵐ⁻ⁿ` | `2⁷ ÷ 2⁴ = 2³ = 8`   |
| 幂的幂，指数相乘   | `(aᵐ)ⁿ = aᵐˣⁿ`   | `(2³)² = 2⁶ = 64`    |

由「相除指数相减」能推出两个看似奇怪的记号：

```text
2⁰ = 1            （任何数的 0 次方 = 1）
2⁻¹ = 1/2         （负指数 = 翻到分母）
2⁻² = 1/4
```

**平方根（Square Root）** 是幂的反向操作：问「谁的平方等于 9？」答案是 ±3，其中正的那个记作 `√9 = 3`。

> [!tip] 为什么 AI 课要重视幂？
> 因为「误差平方」是训练模型最常用的度量。模型预测偏了 3 个单位，惩罚记 `3² = 9`；偏了 4 个单位，惩罚 `16`——**平方会放大大的错误**，逼着模型优先修正离谱的偏差。此外「十亿参数」写作 10⁹、「万亿 token」写作 10¹²，看不懂幂就看不懂 AI 新闻。

### 概念 5：整理式子 —— 平方差与完全平方

「式子（Expression）」就是把数字和字母用运算符号串起来的组合，如 `x² − 9`。**整理式子**就像整理房间：换个摆法，东西没多没少，但好找多了。

两个最高频的公式：

```text
平方差：(a + b)(a − b) = a² − b²
完全平方：(a + b)² = a² + 2ab + b²
```

用数字验证一下（比背证明更踏实）：

```text
(a,b) = (7,3)： (7+3)(7−3) = 10 × 4 = 40 ； 7² − 3² = 49 − 9 = 40 ✓
(a,b) = (7,3)： (7+3)² = 100 ； 49 + 42 + 9 = 100 ✓
```

**人话**：

- 平方差说「一正一反的两个括号相乘，交叉项正好抵消」
- 完全平方说「平方展开有三块：自己平方 + 两倍交叉 + 另一个自己平方」

> [!warning] 高频错误：(a+b)² ≠ a² + b²
> `(3+4)² = 49`，而 `3² + 4² = 25`。中间那个 `2ab` 丢不得——它是「两块地的交界小路」，面积不能忽略。

### 概念 6：百分比与准确率 —— AI 新闻里的数字

**百分比（Percentage）** 就是「分母固定为 100 的分数」：`87% = 87/100 = 0.87`。

AI 场景的标准算法：

```text
准确率 Accuracy = 答对的题数 ÷ 总题数

例：模型认了 100 张图，认对 87 张 → 准确率 = 87/100 = 87%
```

两个必须分清的说法：

| 说法              | 含义          | 换算         |
| ----------------- | ------------- | ------------ |
| 提高了 5 个百分点 | 从 80% 到 85% | 差值直接相减 |
| 提高了 5%         | 从 80% 到 84% | 80 × 1.05    |

新闻标题最爱混用这两者夸大效果。「准确率提升 300%」多半是把「错误率减半」这类小事包装出来的——学完这课，你就有了识破它的数学耳朵。

## 用 Python 验证今天学的（选读）

P 板块学过 Python 的读者可以亲手跑一遍：

```python
from fractions import Fraction

print(2 + 3 * 4)              # 14 —— Python 与数学同一套优先级
print((-2) ** 2, -2 ** 2)     # 4 -4 —— 括号的威力
print(Fraction(1, 3) + Fraction(1, 6))   # 1/2 —— 分数精确计算
print(2 ** 10)                # 1024 —— 幂
print((7 + 3) * (7 - 3) == 7**2 - 3**2)  # True —— 平方差成立
print(f"准确率 {87/100:.0%}") # 准确率 87%
```

（以上输出均为真实运行结果，Python 3.13。）

## 自测一下

> [!question]- 1. 计算：`−3² + (−3)² = ?`
> **答案：0**。
> `−3² = −9`（幂只作用于 3，负号在最后），`(−3)² = 9`（括号让负号一起平方）。所以 `−9 + 9 = 0`。这题考的就是概念 1 里那个坑。

> [!question]- 2. 用指数律化简：`2⁵ × 2⁻³ ÷ 2²` 等于多少？
> **答案：2⁰ = 1**。
> 同底数幂乘除只需指数加减：`5 + (−3) − 2 = 0`，而任何非零数的 0 次方都是 1。不需要真的算出每个 2 的几次方再乘除——这正是指数律省力的地方。

> [!question]- 3. 一个模型在 250 张测试图上认对了 215 张。它的准确率是多少？某新闻说「新版本将错误率降低了一半」，若旧版准确率是 86%，新版大约是多少？
> 第一问：`215 ÷ 250 = 0.86`，准确率 **86%**。
> 第二问：错误率旧版 `100% − 86% = 14%`，减半后 `7%`，新版准确率约 **93%**。注意这里是「错误率减半」而不是「准确率翻倍」——准确率已经接近 100%，不可能翻倍。读 AI 新闻时先把「率」的主语圈出来。

> [!question]- 4. 展开并化简：`(x + 5)(x − 5)` 和 `(x + 3)²`
> 平方差公式直接套：`(x+5)(x−5) = x² − 25`。
> 完全平方公式：`(x+3)² = x² + 6x + 9`（中间项 2·x·3 = 6x 别丢）。
> 这两个形状在后面求导、配方法里会反复出现，建议顺手默写一遍。
