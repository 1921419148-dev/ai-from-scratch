> - **均值（Mean）、中位数（Median）**：两个「平均」为什么常常打架

> - **正态分布**：钟形曲线为何无处不在，68-95-99.7 法则

## 生活场景切入

想知道一锅汤咸不咸，你不会把一锅喝完——舀一勺尝尝就行。

统计学的全部信心来自一个惊人的事实：**只要搅匀了，一勺就能代表一锅**。模型评估同理：不可能拿模型测试全世界所有图片，测几千张就能估计它的真实水平。这门课回答三个问题：怎么总结一勺的数据？波动怎么衡量？从勺推锅有多可靠？

## 核心概念拆解

### 概念 1：均值 vs 中位数 —— 被「平均」绑架的工资

```text
五名员工月薪（千元）：5, 6, 7, 8, 9      均值 = 35/5 = 7 ✓ 很有代表性

高管入职后：        5, 6, 7, 8, 9, 60    均值 = 95/6 ≈ 15.8 ← 被离群值拉飞！
```

```python
salaries = [5, 6, 7, 8, 9, 60]
mean = sum(salaries) / len(salaries)
srt = sorted(salaries)
median = (srt[2] + srt[3]) / 2          # 偶数个取中间两数的平均
print(round(mean, 2), median)            # 15.83 7.5
```

| 指标          | 抗离群值 | 适用场景                   |
| ------------- | -------- | -------------------------- |
| 均值 Mean     | 弱       | 数据对称、无极端值时最常用 |
| 中位数 Median | 强       | 收入、房价等右偏数据的首选 |

**AI 视角**：报告模型延迟时常说 P50 / P95 / P99——它们就是中位数和第 95、99 百分位数。平均延迟 50ms 的服务可能 1% 的请求要等 2 秒，用户骂的就是那 1%。**看性能别只看均值，看尾巴。**

### 概念 2：方差与标准差 —— 波动的度量

两组成绩，均值都是 80：

```text
甲班：78, 79, 80, 81, 82     （整齐）
乙班：60, 70, 80, 90, 100    （悬殊）
```

只报均值会漏掉关键差异。**方差** 衡量每个点偏离均值的平均幅度（取平方防止正负抵消），**标准差** 是方差的平方根——回到原单位，更好解释：

```text
方差 Var = Σ (xᵢ − x̄)² / n
标准差 σ = √Var
```

```python
import math
def mean(xs): return sum(xs)/len(xs)
def std(xs):
    m = mean(xs)
    return math.sqrt(sum((x-m)**2 for x in xs)/len(xs))

jia = [78, 79, 80, 81, 82]
yi  = [60, 70, 80, 90, 100]
print(mean(jia), mean(yi))        # 80.0 80.0 —— 均值相同
print(round(std(jia), 2), round(std(yi), 2))   # 1.41 14.14 —— 波动差十倍
```

### 概念 3：正态分布 —— 钟形曲线统治世界

测量误差、身高、噪声……大量独立小因素叠加的结果都趋向同一种形状——**正态分布（Normal Distribution）**，中间高两头低的钟形：

```text
        ╭─╮
       ╱   ╲
      ╱     ╲         x̄ = 均值：峰的位置
    _╱       ╲_       σ = 标准差：钟的胖瘦
   /|---------|\
```

它的魔法是 **68-95-99.7 法则**：

```text
均值 ±1σ 内  ：约 68% 的数据
均值 ±2σ 内  ：约 95%
均值 ±3σ 内  ：约 99.7%
```

实测验证一下（200 个模拟身高，均值 170、σ=8）：

```python
import random; random.seed(11)
data = [random.gauss(170, 8) for _ in range(200)]
m, s = mean(data), std(data)

w1 = sum(1 for x in data if abs(x-m) <= s)   / len(data)
w2 = sum(1 for x in data if abs(x-m) <= 2*s) / len(data)
print(f"±1σ: {w1:.3f}  ±2σ: {w2:.3f}")   # ±1σ: 0.685  ±2σ: 0.950 —— 和理论严丝合缝
```

**人话**：知道均值和标准差两个数，就能推断任意区间的占比。「身高 186cm」在 σ=8、均值 170 的世界里是 +2σ → 大约只有前 2.5% 的人这么高。**σ 是把原始数字翻译成「罕见程度」的汇率。**

### 概念 4：抽样与中心极限定理 —— 一勺汤的可靠性

从总体反复抽样本、算样本均值，这些均值本身也有波动。规律（本课示例实测）：

```text
n=10:   样本均值的标准差 ≈ 2.485 （理论 8/√10 ≈ 2.53）
n=100:  ≈ 0.787              （理论 8/√100 = 0.80）
n=1000: ≈ 0.242              （理论 8/√1000 ≈ 0.253）
```

两条结论值得刻进脑子：

1. **样本量扩大 k 倍，精度只提升 √k 倍**（平方根定律）——想把误差减半，样本要翻四倍。问卷要发多少份、A/B 测试要跑多久，背后都是这条公式。
2. **不管原始数据长什么样，样本均值的分布趋向正态**（中心极限定理）。这就是钟形曲线无处不在的原因，也是各种统计检验敢用正态假设的底气。

### 概念 5：混淆矩阵 —— 模型评估的正确打开方式

分类模型的预测与真相交叉出四个格子（以「垃圾邮件识别」为例）：

```text
                    实际是垃圾      实际正常
预测是垃圾  │   TP = 40      │  FP = 10（误杀）
预测正常    │   FN = 20（漏网）│  TN = 30
```

由此派生三大指标：

```python
tp, fp, fn, tn = 40, 10, 20, 30

accuracy = (tp + tn) / (tp + fp + fn + tn)   # 准确率：全对的比例
precision = tp / (tp + fp)                   # 精确率：报警的里面真有几只狼
recall    = tp / (tp + fn)                   # 召回率：所有的狼抓住了几只

print(f"准确率={accuracy:.2f}  精确率={precision:.2f}  召回率={recall:.2f}")
# 准确率=0.70  精确率=0.80  召回率=0.67
```

| 指标   | 回答的问题             | 什么时候最重要             |
| ------ | ---------------------- | -------------------------- |
| 准确率 | 总体判对多少？         | 类别均衡时的粗略参考       |
| 精确率 | 说「是」的时候靠谱吗？ | 误报代价高（放行恶意文件） |
| 召回率 | 该抓的抓全了吗？       | 漏检代价高（癌症筛查）     |

> [!warning] 准确率的经典陷阱
> 违约率 1% 的贷款数据上，一个无脑输出「人人不违约」的模型准确率高达 99%——但对业务毫无价值。**类别不平衡时必须看精确率/召回率**，这正是 ML4「过拟合」之外另一个新手深坑。

## 自测一下

> [!question]- 1. 某小区房价（万元）：300, 320, 310, 305, 2500。中介宣传「均价 747 万」，哪里有问题？应该用什么指标？
> 数字没错但误导：2500 的豪宅把均值拉到 (300+320+310+305+2500)/5 ≈ **747 万**，而 4 户普通住宅都在 300 出头。
> 应改用**中位数 310 万**——它不受离群值影响，才反映典型房源。凡是收入、房价、延迟这类右偏数据，先怀疑均值。

> [!question]- 2. 一条生产线灌装 500ml 饮料，实际每瓶均值 500ml、σ=6ml 且近似正态。低于 488ml 即不合格。大约多大比例不合格？
> 488 与均值差 −12ml = −2σ。
> 由 68-95-99.7 法则，±2σ 外约占 5%，其中一半（2.5%）在左侧 → 约 **2.5% 不合格**。
> 解题套路：先把原始值换算成「离均值几个 σ」（这个换算叫标准化），再套法则。

> [!question]- 3. A/B 测试显示新推荐算法点击率高 0.3%，但样本只有 200 人。老板要求「再收集多少数据才能让结论可信度明显提升」——用本课哪条规律估算？
> 用**平方根定律**：样本量扩 k 倍，波动只缩 √k 倍。
> 要把估计精度提高一倍需要 4 倍样本（800 人）；提高三倍需要 9 倍（1800 人）。
> 所以合理建议是把样本扩到数千级再下结论——200 人的 0.3% 差异大概率淹没在噪声里。

> [!question]- 4. 癌症筛查模型和垃圾邮件过滤器，各自更应该优化精确率还是召回率？说明理由。
> **癌症筛查优先召回率**：漏掉一个患者（FN）可能致命，误报（FP）只是多做一次复查确认——漏检代价远高于误报。
> **垃圾邮件过滤优先精确率**：重要邮件被误杀进垃圾箱（FP）损失惨重，偶尔漏进一封垃圾邮件（FN）忍忍就过去了。
> 口诀：**代价在哪边，指标看那边**。两者可以调节阈值互相权衡，不存在同时最大。
