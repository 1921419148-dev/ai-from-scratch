## 生活场景切入

楼下自动售货机是一台「函数机」：

```text
投入 A7 按钮  →  出矿泉水
投入 C2 按钮  →  出可乐
再投 A7       →  还是矿泉水      ← 关键！同样输入必得同样输出
```

如果按 A7 这次出矿泉水、下次出雨伞，这台机器就坏了。**函数的定义只有一句话：每个合法输入，都唯一对应一个输出。**至于机器内部怎么运作，你可以完全不关心——这叫「黑箱思维」，也是工程和科学的通用姿势。

## 核心概念拆解

### 概念 1：f(x) 记号 —— 给机器起名字

```text
f(x) = 2x + 1
```

读作「f 作用在 x 上」。拆开看：

| 记号   | 含义           | 类比         |
| ------ | -------------- | ------------ |
| `f`    | 这台机器的名字 | 售货机的编号 |
| `x`    | 输入（自变量） | 你投的按钮   |
| `f(x)` | 输出（因变量） | 掉出来的饮料 |

使用方式是**代入**：

```text
f(0) = 2×0 + 1 = 1        f(5) = 2×5 + 1 = 11        f(x+1) = 2(x+1) + 1 = 2x + 3
```

最后那个例子值得多看一眼——**代入的东西不必是数字，可以是另一个式子**。这个看似不起眼的性质正是 M6 链式法则的地基。

用 Python 写同一个函数（P5 学过的知识立刻复用）：

```python
def f(x):
    return 2 * x + 1

print(f(0), f(5))     # 1 11 —— 和手算一致
```

### 概念 2：定义域与值域 —— 机器的收货范围

- **定义域（Domain）**：机器肯接收的所有输入
- **值域（Range）**：机器可能吐出的所有输出

售货机不收 5 毛硬币 → 5 毛不在定义域内。函数 `f(x) = 1/x` 不接受 x=0（除法会爆炸）→ 定义域是「所有非零实数」。

```text
g(x) = x²          定义域：任意数        值域：[0, +∞)      ← 平方不会出负数
h(t) = 现在的温度   定义域：时刻 t         值域：当天温度范围
```

> [!tip] AI 视角
> 把图片喂给分类器之前要缩放到 224×224 像素、数值归一化到 [0,1]——这就是在手动保证输入落在模型的定义域里。「报错」和「输出乱答案」往往不是模型坏了，而是输入越界了。

### 概念 3：图像 —— 函数的 X 光片

把每个输入 x 和对应输出 f(x) 当作平面上的点 (x, f(x)) 描出来，连成的曲线就是**图像**。图像让函数的「性格」一目了然：

```text
f(x) = 2x + 1     → 一条直线，一直往上走（单调增）
g(x) = x²         → 一条抛物线，先降后升，最低点在原点
```

读图三问（后面每课都用得上）：

1. **往哪边走？**——上升 / 下降 = 函数增减性
2. **哪里最陡 / 最平？**——陡峭 = 变化快；水平 = 变化为零（M6 导数的伏笔！）
3. **过不过横轴？**——穿过点就是 M2 说的方程的根

```python
# 用 Python 亲手画一条（需要 matplotlib，见 P9）
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-3, 3, 100)
plt.plot(x, 2*x + 1, label="f(x)=2x+1")
plt.plot(x, x**2, label="g(x)=x²")
plt.legend()
plt.savefig("functions.png")   # 直线与抛物线同框对比
```

### 概念 4：复合函数 —— 机器流水线

两台机器串起来，前一台的出口接后一台的入口：

```text
f(x) = 2x + 1（先把数翻倍再加一）
g(x) = x²（再把结果平方）

g(f(x)) = (2x + 1)²          ← 先过 f，再过 g
f(g(x)) = 2x² + 1            ← 先过 g，再过 f
```

验证一下顺序真的有所谓（x=2）：

```text
g(f(2)) = g(5) = 25
f(g(2)) = f(4) = 9            ← 顺序不同，结果不同
```

记号 `g(f(x))` 也写作 `(g ∘ f)(x)`，读作「g 圈 f」——从里往外执行。

**为什么这是本课最重要的一块拼图？** 因为神经网络就是一条超长的复合函数流水线：

```text
输入像素 → 第1层变换 → 第2层变换 → … → 第50层变换 → 「这是一只猫的概率」
```

每一层都是一台小机器，整个网络是一个巨型复合函数。M6 的链式法则会告诉我们：**复合函数的导数 = 各台机器导数的连乘**——这正是「反向传播」的全部数学基础。

```python
def f(x): return 2*x + 1
def g(x): return x*x

print(g(f(2)))    # 25
print(f(g(2)))    # 9  —— 顺序确实重要
```

### 概念 5：AI 最爱的一条曲线 —— Sigmoid

认识一个新朋友，它将在 ML3 正式上岗：

```text
σ(x) = 1 / (1 + e⁻ˣ)        （e ≈ 2.718，M4 会正式介绍）
```

它的图像是一条平滑的 **S 形曲线**：

```text
x 很负 → σ(x) ≈ 0        x = 0 → σ(0) = 0.5        x 很正 → σ(x) ≈ 1
```

```python
import math

def sigmoid(x):
    return 1 / (1 + math.exp(-x))

for v in [-10, 0, 10]:
    print(f"sigmoid({v}) = {sigmoid(v):.6f}")
# sigmoid(-10) = 0.000045
# sigmoid(0)   = 0.500000
# sigmoid(10)  = 0.999955
```

它受欢迎的理由：**任何数字进来，都会被温柔地压进 0 到 1 之间**。而 0~1 正好可以解释成概率——「这张图是猫的概率 0.87」。把千奇百怪的原始分数变成规规矩矩的概率，这一招贯穿整个机器学习。

## 自测一下

> [!question]- 1. 已知 `f(x) = 3x − 2`，求 `f(4)` 和 `f(a+1)`（用含 a 的式子表示）
> `f(4) = 3×4 − 2 = 10`。
> `f(a+1) = 3(a+1) − 2 = 3a + 1`。
> 第二问的关键：把括号里的整体当作「新的 x」代入，然后展开整理。

> [!question]- 2. `f(x) = x + 1` 与 `g(x) = x²`。计算 `f(g(−2))` 和 `g(f(−2))`
> `g(−2) = 4` → `f(4) = 5`，所以 `f(g(−2)) = 5`。
> `f(−2) = −1` → `g(−1) = 1`，所以 `g(f(−2)) = 1`。
> 又一次看到顺序有所谓。注意 `g(−2) = (−2)² = +4`——负数平方为正，M1 的老朋友。

> [!question]- 3. 函数 `h(x) = 1/(x−3)` 的定义域是什么？
> 分母不能为零，即 `x − 3 ≠ 0`，所以定义域是**除了 3 以外的所有实数**。
> 从图像看：x 越接近 3，h(x) 的绝对值冲向无穷大，曲线在 x=3 附近竖直地「逃逸」——这条线叫垂直渐近线。写代码时对应的现象是：除以一个极小的数，浮点结果突然爆表（inf）。

> [!question]- 4. 为什么说「深度学习网络是一个巨大的复合函数」？用本课的语言描述「训练网络」这件事。
> 网络把原始输入（如像素矩阵）依次送过几十个变换层，前一层的输出是后一层的输入——正是复合函数 `f₅₀(…f₂(f₁(x)))` 的结构。
> 「训练」就是调整每台小机器内部的旋钮（参数），使得整条流水线对训练样本给出的输出尽量接近标准答案。怎么知道该往哪个方向拧旋钮？这正是 M6 导数与 M7 梯度下降要回答的问题。
