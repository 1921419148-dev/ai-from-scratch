## 生活场景切入

两张纸，让你选一张当工资：

- A：每天固定涨 100 元，30 天后 = 3000 元/天
- B：第一天 1 分钱，之后每天翻倍

直觉选 A？算算 B：第 30 天是 `0.01 × 2²⁹ ≈ 536 万元`。这就是**指数增长**——它不按直线走，而是「越涨越快」，人类的线性直觉在它面前形同近视。

反过来，**对数**就是往回问：「翻倍到某个数，用了几次？」它是给爆炸增长踩刹车、让巨大数字变得可以聊天的工具。

## 核心概念拆解

### 概念 1：指数函数 —— 越滚越大的雪球

```text
f(x) = aˣ        （a > 0 且 a ≠ 1）
```

M1 的指数律在这里全部适用。看两个方向：

```text
a > 1（如 2ˣ）：增长型     2, 4, 8, 16, 32 … 每次涨幅比上次大
0 < a < 1（如 (1/2)ˣ）：衰减型   1, 0.5, 0.25 … 越跌越慢，但永远不触底
```

衰减型有个重要性质：**减半式衰减永远到不了零**。训练后期损失曲线越来越平、贴着地面爬行却不停——就是这个形状。

### 概念 2：e 与连续增长

有一个特殊的底数 **e ≈ 2.71828**，来自「利滚利到极致」的思想实验：

```text
银行年利率 100%：
  一年结一次息：    本金变 (1+1)¹ = 2 倍
  每月结一次：      (1 + 1/12)¹² ≈ 2.613 倍
  每天结一次：      (1 + 1/365)³⁶⁵ ≈ 2.7146 倍
  结息无限密集：    → e ≈ 2.71828 倍
```

以 e 为底的指数 `eˣ` 是数学里的「原装」指数函数——求导最方便（M6 会看到它的导数是它自己），所以 AI 论文里到处是它。

```python
import math
print(math.e)                    # 2.718281828459045
print((1 + 1/365) ** 365)        # 2.71456748202…  正在逼近 e
print(math.exp(1))               # 2.718…  exp(x) 就是 eˣ
```

### 概念 3：对数 —— 「问底数的几次方」

对数是指数的反向提问：

```text
2³ = 8          ← 陈述句
log₂ 8 = ?      ← 疑问句：「2 的几次方等于 8？」答案 3
```

读法与规则：

| 记号               | 读法      | 含义            |
| ------------------ | --------- | --------------- |
| `log₂ 8 = 3`       | log 二 八 | 2 的 3 次方是 8 |
| `ln x`             | 自然对数  | 以 e 为底的 log |
| `lg x` / `log₁₀ x` | 常用对数  | 以 10 为底      |

三种底的关系只是换尺子：`log₂ 8`、`ln 8`、`lg 8` 数值不同，说的都是同一个 8。

**核心口诀：对数把乘法变成加法。**

```text
log(a × b) = log a + log b        log(a ÷ b) = log a − log b
log(aⁿ)    = n · log a
```

验证（任意底都成立）：

```text
log₂(8 × 4) = log₂ 32 = 5 ；  log₂ 8 + log₂ 4 = 3 + 2 = 5 ✓
```

这条性质在计算尺时代救过无数工程师的命；今天它依然活在 AI 里：

- **交叉熵损失取对数**：概率连乘（几十层小数相乘会小到电脑存不下，叫「下溢出」）变成对数相加，稳定又好算
- **学习率的对数坐标图**：训练日志里横轴常画成 log 刻度，因为学习率从 10⁻² 扫到 10⁻⁵，线性轴根本挤成一团

### 概念 4：AI 场景一 —— 学习率衰减

训练模型时常用「每过一段轮数就把学习率减半」的策略：前期大步找方向，后期小步精修。

```text
lr(t) = lr₀ × 0.5ᵗ          （t 为衰减次数）
```

```python
lr0 = 0.1
print([round(lr0 * 0.5**t, 6) for t in range(6)])
# [0.1, 0.05, 0.025, 0.0125, 0.00625, 0.003125]
# —— 指数衰减：快速下降、永不归零，正是概念 1 说的形状
```

反过来想从「最终学习率」反推衰减了几次，就要用对数解方程 `0.1 × 0.5ᵗ = 0.003125` → `t = log₀.₅ 0.03125 = 5`。

### 概念 5：AI 场景二 —— 信息熵：不确定性的度量

信息论里，**熵（Entropy）** 衡量一套概率的「惊讶程度」：

```text
H(p) = −Σ pᵢ · log₂ pᵢ        （对所有可能的 i 求和）
```

两个硬币的对比（代码实测）：

```python
import math

def entropy(p):
    q = 1 - p
    if p in (0, 1):
        return 0.0
    return -(p * math.log2(p) + q * math.log2(q))

print(round(entropy(0.5), 4))    # 1.0     公平硬币：完全猜不透，熵最大
print(round(entropy(0.99), 4))   # 0.0808  几乎必然正面：基本没有悬念
print(entropy(1.0))              # 0.0     必然事件：毫无惊讶
```

**人话**：越「五五开」的事越难猜（熵高）；越一边倒的事越好猜（熵低）。语言模型预测下一个词时追求的就是降低不确定性——GPT 名字里的 T（Transformer）背后，损失函数正是这套熵的家族（交叉熵）。细节留给 ML 板块，这里只需带走直觉：**log 让概率的乘积链可加、负号让「小概率」贡献大惊讶。**

### 概念 6：对数坐标 —— 压扁世界的镜头

比较 100 万和 10 亿参数的两个模型，线性数轴上前一个几乎看不见；换成对数刻度，它们分别是 10⁶ 和 10⁹，各占一格——**对数把「数量级」变成等距台阶**。摩尔定律曲线、GPU 价格走势、Scaling Laws 图几乎全是 log-log 图。看到陡直得吓人的曲线，先看一眼坐标轴是不是 log 的，再决定要不要震惊。

## 自测一下

> [!question]- 1. 求 `log₃ 81`
> 问「3 的几次方是 81？」→ `3⁴ = 81`，所以 **log₃ 81 = 4**。
> 卡住时的笨办法很有效：把 81 连除 3，除了 4 次到 1，次数即答案。

> [!question]- 2. 化简：`ln 12 − ln 4`（不许查表）
> 同底对数相减 = 真数相除：`ln(12/4) = ln 3`。
> 这题考概念 3 的口诀。顺带一验：ln12≈2.485，ln4≈1.386，差≈1.099=ln3 ✓。

> [!question]- 3. 学习率从 0.08 开始每次训练周期减半，多少个周期后会低于 0.005？
> 解不等式 `0.08 × 0.5ᵗ < 0.005` → `0.5ᵗ < 0.0625`。
> 而 0.0625 = 1/16 = (1/2)⁴，所以 `t > 4`，答案是 **5 个周期起**（第 4 个周期恰好等于 0.005，还不算「低于」）。
> 两边同除正数不用翻不等号——M2 的规则在指数方程里的应用。

> [!question]- 4. 为什么交叉熵损失要对概率取对数？说出至少一条理由。
> 主要理由有二：
> ① **数值安全**：一连串概率连乘（比如 100 个 0.1 相乘 = 10⁻¹⁰⁰）会小于浮点数能表示的下限而「下溢」归零；取对数后变成加法（−100），任何数值都能稳稳表示。
> ② **匹配信息直觉**：−log p 正好是「惊讶度」，把多个独立事件的惊讶度直接相加，符合「信息可叠加」的常识，也让梯度性质更好（M6 之后你会真正体会这一点）。
