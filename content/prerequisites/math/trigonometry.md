## 生活场景切入

你坐在摩天轮里，朋友在地面给你拍延时视频。把照片按时间排开，你**离地面的高度**变化是什么形状？

不是直线，也不是抛物线——是一条平滑的波浪：缓缓升到顶、缓缓落回、再升上去。这条波浪就是**正弦曲线（Sine Wave）**。

凡是有「转圈」「摆动」「振动」的地方——钟摆、声波、交流电、Wi-Fi 载波、四季气温——背后都是同一套三角函数。AI 处理的语音是一维声波、图像旋转要用坐标变换，连 Transformer 里每个词的位置信息都用 sin/cos 写成密码。这门课只学最必要的部分：认识三兄弟 + 单位圆 + 会读波形。

## 核心概念拆解

### 概念 1：直角三角形里的三个比值

画一个直角三角形，盯着其中一个锐角 θ（theta）：

```text
        /|
       / |
  斜边/  | 对边（θ 正对着的那条）
     /   |
    /θ___|
      邻边（挨着 θ 的那条直角边）

sin θ = 对边 ÷ 斜边
cos θ = 邻边 ÷ 斜边
tan θ = 对边 ÷ 邻边     （= sin θ ÷ cos θ）
```

**人话**：斜边是「总距离」，对边和邻边是它在两个方向上的分量。sin/cos 回答的是「斜着的力/位移，有多少落在竖直/水平方向」。

一个立刻能用的例子：30° 时 `sin 30° = 0.5`——爬 30° 的坡，走 10 米路，高度只升 5 米。

### 概念 2：单位圆 —— 把三角形变成转圈

半径为 1 的圆，圆心在原点。一个点从 (1,0) 出发逆时针转 θ 角：

```text
         y
         |    ●(x, y)
         |   /:
         |  / :
    -----●--:------ x
        /θ
     (1,0)

这个点的坐标永远是：
  x = cos θ      y = sin θ
```

这一步抽象威力巨大：

1. **角度可以超过 90° 甚至 360°**——点继续转就行，sin/cos 照样有定义
2. **周期性自动出现**：转满一圈回到原地，所以 `sin(θ + 360°) = sin θ`，波形无限重复
3. 符号规律一目了然：第二象限 y>0（sin 正），第四象限 y<0

```text
θ:        0°     90°     180°     270°     360°
sin θ:    0      1       0        −1       0      ← 完整一轮
cos θ:    1      0       −1       0        1
```

```python
import math
def d2r(d): return d * math.pi / 180

for deg in [0, 90, 180, 270, 360]:
    print(deg, round(math.sin(d2r(deg)), 3), round(math.cos(d2r(deg)), 3))
# 0 0.0 1.0 | 90 1.0 0.0 | 180 0.0 -1.0 | 270 -1.0 0.0 | 360 -0.0 1.0
```

### 概念 3：弧度 —— 数学家卷尺

度数把圆周分成 360 份纯属历史遗产（巴比伦六十进制）。数学更爱**弧度（Radian）**：弧长等于半径时对应的角 = 1 rad。

```text
180° = π rad        90° = π/2 rad        360° = 2π rad
换算：rad = 度 × π / 180
```

为什么要受这份罪？因为在弧度下，`sin` 的导数公式最干净（M6 见），工程库全部默认弧度——Python 的 `math.sin(3.14159)` 里传的是弧度，传 180 就错了。**写代码用弧度，跟人聊天可用度数，注意切换。**

### 概念 4：正弦波 —— 波动的通用语

把 y = sin θ 按横轴展开画出来，就是那条摩天轮高度曲线。控制波形只需三个旋钮：

```text
y = A · sin(B·θ + C)

A：振幅 —— 波多高（音量大小）
B：频率 —— 转得多快（音调高低）；周期 T = 2π/B
C：相位 —— 整条波左右平移（起点早晚）
```

**为什么它如此普适？** 数学定理（傅里叶级数）保证：任何周期性信号——无论多么锯齿、多么怪异——都能拆成一堆不同频率的正弦波之和。声音压缩（MP3）、JPEG 图像压缩、神经网络里的位置编码，全是这套分解思想的子孙。

```python
# 听不见但看得见的"声音"
samples = [round(math.sin(2*math.pi*2*t/16), 3) for t in range(8)]
# [0.0, 0.707, 1.0, 0.707, 0.0, -0.707, -1.0, -0.707]
# 一个完整周期内的 8 个采样点——正负对称、平滑往返
```

### 概念 5：AI 视角 —— 旋转与位置编码

**① 二维旋转公式。** 把平面上的点绕原点转 θ 角（逆时针）：

```text
x' = x·cos θ − y·sin θ
y' = x·sin θ + y·cos θ
```

图像增强里随手一转的数据增广、机械臂关节角度计算，用的都是它。

```python
import math, cmath
v = complex(1, 0)              # 向量 (1, 0)，也可直接代上面的公式
rotated = v * cmath.exp(1j * math.pi/3)   # 转 60°
print(round(rotated.real, 3), round(rotated.imag, 3))   # 0.5 0.866
```

**② Transformer 的位置编码。** 注意力机制本身不知道词的前后顺序（「猫追狗」和「狗追猫」会看成一样），所以要给第 pos 个词注入位置信息。原始论文的做法正是生成一对 sin/cos 值拼进词向量：

```text
PE(pos, 2i)   = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
```

直觉：每个词拿到一组不同频率的「指针」，像时钟的时分秒针组合一样，让模型能推算任意两处的相对距离。**你不需要现在看懂公式——只需要知道：当年难倒 NLP 的「顺序问题」，最终是靠初中就认识的 sin/cos 解掉的。**

## 自测一下

> [!question]- 1. 直角三角形中某锐角的对边 = 3，斜边 = 5。求 sin 和 cos（提示：先勾股定理求邻边）
> 邻边 = √(5² − 3²) = √16 = 4。
> 所以 sin θ = 3/5 = 0.6，cos θ = 4/5 = 0.8。
> 这组 3-4-5 是最常见的整数直角三角形，值得记住。顺带验证 tan θ = 3/4 = sin/cos ✓。

> [!question]- 2. 不用计算器，判断 sin 200° 的符号并说明理由
> 200° 在第三象限（180°~270°）。单位圆上第三象限的点 x<0、y<0，而 sin 是纵坐标，所以 **sin 200° < 0**。
> （具体值 ≈ −0.342，但本题只要符号——考的是「单位圆定符号」这个方法，而不是背数值表。）

> [!question]- 3. 波形 `y = 3·sin(2x)` 相比 `y = sin(x)`，振幅和周期各变成多少？
> 振幅由系数 A=3 决定 → 变为原来的 3 倍。
> 频率由 B=2 决定 → 周期 T = 2π/B = **π**（原来 2π 的一半），即同样宽度里挤了两个完整波。
> 口诀：「前面管高矮，里面管快慢」。

> [!question]- 4. 为什么 Transformer 需要「位置编码」？它的实现借用了哪个数学工具？
> 因为注意力机制把输入当成一堆并列的词来处理，天然不区分先后——而语序改变语义（「我打他」≠「他打我」）。
> 解决办法是把每个位置的编号通过**不同频率的 sin/cos 函数**算出一组数值，加到词向量上，让模型能从向量本身读出位置和相对距离。工具就是本课的单位圆三角函数。
