> [!abstract] 本课将学到
>
> - **概率（Probability）**：给不确定性标上 0 到 1 的刻度
> - 条件概率：新证据如何更新判断
> - **贝叶斯定理**：「见到证据后，真相的概率」怎么算——AI 推理的心脏
> - 期望值：长期平均意义上的「预期」
> - 蒙特卡洛方法：用随机模拟解决算不出的问题

## 生活场景切入

天气预报说「降水概率 80%」。没人能保证今晚一定下雨——未来充满不确定。但 80% 这个数字依然有用：它告诉你带伞比不带伞划算。

AI 世界没有「确定」二字：

- 人脸识别说「这是你的概率 0.97」
- 天气模型说「明天下雨 p=0.8」
- 大语言模型逐词生成时，每个候选词都带一个概率

**概率就是把「不确定」变成可以计算的东西。**本课只讲三件兵器：条件概率、贝叶斯定理、期望。

## 核心概念拆解

### 概念 1：概率是什么 —— 频率的极限

抛硬币、掷骰子做几万次，统计某结果出现的比例——这个比例会稳定下来，稳定值就叫概率。

```python
import random
random.seed(7)

for n in [100, 10000, 100000]:
    freq = sum(random.random() < 0.5 for _ in range(n)) / n
    print(n, round(freq, 4))
# 100 0.48        小样本：离谱是常态
# 10000 0.5065    开始靠拢
# 100000 0.5005   几乎贴住理论值 0.5
```

三条基本规则：

| 规则     | 内容                         | 例子                     |
| -------- | ---------------------------- | ------------------------ |
| 取值范围 | 0 ≤ P ≤ 1                    | P(太阳升起)≈1            |
| 全体求和 | 所有可能结果的概率加起来 = 1 | 六面骰每面 1/6，共 1     |
| 独立事件 | 互不影响则相乘               | 连抛两次正面 = ½ × ½ = ¼ |

### 概念 2：条件概率 —— 新证据改变判断

```text
P(A | B) 读作「在 B 已发生的条件下，A 的概率」

P(A|B) = P(A 且 B) / P(B)        「交集占 B 的比例」
```

经典陷阱题（面试高频）：两枚硬币，已知至少一个正面，问两个都是正面的概率？

```python
from itertools import product

rolls = list(product(["H", "T"], repeat=2))          # 四种等可能结果
both_h       = [r for r in rolls if r == ("H", "H")]
at_least_one = [r for r in rolls if "H" in r]

print(len(at_least_one))                       # 3 → (HH)(HT)(TH)
print(len(both_h) / len(at_least_one))         # 0.333…
```

直觉纠偏：很多人脱口而出 ½。但「至少一个正面」把 HH/HT/TH 三种情况摆上桌，其中全正面只占 1/3。**条件一变，样本空间就变——这是条件概率的全部要义。**

### 概念 3：贝叶斯定理 —— AI 推理的心脏

把条件概率公式倒过来用，得到八成 AI 应用的底层逻辑：

```text
                P(证据 | 真相) × P(真相)
P(真相 | 证据) = ────────────────────────
                        P(证据)
```

每个部件都有名字：

| 部件          | 名字            | 含义                       |
| ------------- | --------------- | -------------------------- |
| P(真相\|证据) | 后验 Posterior  | 看到证据后的更新判断       |
| P(真相)       | 先验 Prior      | 还没看证据时的基础判断     |
| P(证据\|真相) | 似然 Likelihood | 若真相成立，证据多可能出现 |
| P(证据)       | 归一化常数      | 证据本身有多常见           |

**经典医疗检测题**（数字务必过目一遍）：

```text
某病患病率 1%（先验）。检测灵敏度 99%（真患者 99% 呈阳性），
误报率 5%（健康人也有 5% 呈阳性）。
你检出阳性，实际患病的概率是多少？
```

```python
P_D, sen, fpr = 0.01, 0.99, 0.05
pos = P_D * sen + (1 - P_D) * fpr      # 阳性的总概率
posterior = P_D * sen / pos
print(round(posterior, 4))             # 0.1667 —— 只有约 17%！
```

只有 **16.7%**！因为健康人基数太大（99%），哪怕误报率仅 5%，假阳性的绝对人数也碾压了真阳性。**人话**：罕见事件 + 不完美检测 → 阳性结果远没有想象中可怕。垃圾邮件过滤、医学影像辅助诊断、风控系统，全部运行在这条公式之上。

### 概念 4：期望值 —— 长期平均的「预支答案」

```text
期望 E[X] = Σ (每个结果 × 它的概率)
```

骰子的期望：`E = (1+2+3+4+5+6)/6 = 3.5`——注意 3.5 根本不是任何一次的实际点数，它是**无数次投掷的平均归宿**。

```text
抽奖例子：
  90% 不中奖（得 0 元），9% 中小奖 10 元，1% 中大奖 1000 元
  E = 0.9×0 + 0.09×10 + 0.01×1000 = 10.9 元
若票价 20 元 > 期望回收 10.9 元 → 大量购买必亏（赌场与保险公司的数学根基）
```

**AI 视角**：损失函数本质就是「误差的期望」——我们无法穷举所有可能的样本，但希望模型对它们平均而言错得最少。训练目标 `minimize E[loss]` 里的 E 就是它。

### 概念 5：蒙特卡洛方法 —— 用随机性打败复杂性

有些问题（比如 π 的精确值、高维积分）解析解难如登天，但可以用随机采样逼近——这就是**蒙特卡洛（Monte Carlo）** 方法：

```python
import random
random.seed(7)

n = 100_000
inside = sum(
    1 for _ in range(n)
    if random.random()**2 + random.random()**2 <= 1
)
print("π ≈", 4 * inside / n)        # π ≈ 3.14224 —— 撒十万把"米"就够准
```

原理：往边长 2 的正方形里均匀撒点，落在内切圆里的比例 ≈ π/4，乘 4 就是 π。精度不靠聪明，靠**次数**——现代大模型训练里无数超参数搜索、强化学习的环境模拟都是这个思路的后代。

## 自测一下

> [!question]- 1. 抛一枚公平硬币三次，恰好两次正面的概率是多少？
> 枚举：三次抛掷共 8 种等可能组合。「恰好两次正面」= {HHT, HTH, THH} 共 3 种。
> 所以概率 = **3/8**。
> 快捷式（二项分布）：C(3,2) × ½² × ½¹ = 3 × ¼ × ½ = 3/8 ✓。核心动作还是数清样本空间。

> [!question]- 2. 把贝叶斯检测题里的患病率从 1% 提到 10%（灵敏度和误报率不变），阳性后真患病的概率变成多少？说说为什么变化这么大。
> 分子 = 0.10 × 0.99 = 0.099；
> 分母 = 0.099 + 0.90 × 0.05 = 0.099 + 0.045 = 0.144；
> 后验 = 0.099 / 0.144 ≈ **68.8%**。
> 先验从 1% 升到 10%（十倍），后验从 17% 跳到 69%——**先验的分量远比直觉重**。这也是筛查策略的常识：高危人群复检才有意义，全员筛查低流行病会产生海量假阳性。

> [!question]- 3. 某游戏抽卡：SSR 概率 1%，保底之外每次独立。抽一次的期望「SSR 张数」是多少？抽 60 次呢？
> 单次期望 E = 0.99×0 + 0.01×1 = **0.01 张**。
> 60 次独立抽取，期望可加：60 × 0.01 = **0.6 张**。
> 即平均而言 60 抽还凑不满一张 SSR（约 0.6 张）。注意「期望不到 1」不代表你抽不到——期望描述的是长期平均，不是个人命运。

> [!question]- 4. 为什么分类模型输出「概率 0.87 是猫」而不是直接回答「是猫」？用贝叶斯的思想说明这种设计的好处。
> 因为模型掌握的只是间接证据（像素），而证据到类别的关系天然是不确定的——硬回答会丢掉置信度信息。
> 输出概率相当于给出似然信息：下游系统可以把 0.87 当作软依据继续决策——医疗场景低于阈值转人工复核、推荐场景高于阈值才投放。这本质上保留了贝叶斯框架中「证据更新信念」的接口：**概率让后续的新证据还能继续参与运算，一刀切的结论不能。**
