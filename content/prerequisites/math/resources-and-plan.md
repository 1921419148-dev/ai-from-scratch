> [!abstract] 这页解决什么
> 站内 [[prerequisites/math/index|M1–M10]] 是「课程」，这页是「配套资源」：把 23 个常见数学频道/平台逐一评估（用户指定清单 22 项 + 苏德矿），告诉你**哪些进主线、哪些当字典、哪些现阶段不碰**，最后给出一份可执行的 24 周计划。
>
> ⚠️ 编写说明（2026-08-22）：本页基于模型内置知识整理，编写时无法实时联网复核。资源本身评价稳定，但播放列表长度、B 站搬运是否失效请使用前自行确认一分钟。标 ⚠️ 的条目为不完全确定的信息。

## 一、23 个资源逐个评估

### ★★★ 主力级 —— 直接进计划

| 资源 | 是什么 | 语言 | 用法定位 |
| --- | --- | --- | --- |
| **Khan Academy** | 结构化 K12→大学数学，带练习题即时反馈 | 英文官网 / ⚠️ 国内访问稳定性自查 | M1–M5 阶段的**主线教材**：唯一自带刷题系统的免费平台 |
| **3Blue1Brown** | 动画可视化：《线性代数的本质》《微积分的本质》、神经网络系列 | 英文（B 站有官方号） | **直觉层甜点**：每学完一个正式章节后看，建立几何直觉 |
| **Paul's Online Math Notes** | 免费文字版大学数学笔记：预备知识、微积分 I/II/III、线代、微分方程，带例题和解答 | 英文 | **文字主线**：适合精读 + 打印离线用，信息密度比视频高得多 |
| **MIT OpenCourseWare** | 正式大学课程录像+讲义：18.06 线代（Gilbert Strang 经典 34 讲）、18.01/18.02 微积分、6.0001 Python 入门 | 英文（B 站有搬运 ⚠️ 可能失效） | 进阶主力：M8 用 Strang 前 10 讲；Python 阶段配 6.0001 |
| **Professor Leonard** | 完整大学课堂实录：College Algebra → Trig → 微积分 I/II/III → 微分方程，每讲 40–90 分钟板书推导极细 | 英文 | **英文视频主线备选**：能坐住长视频就是最扎实的选择；时间紧只看微积分 I 导数部分 |
| **武忠祥** | 西交大教授，考研高数名师，系统性强、套路总结好 | 中文（B 站有正版课程） | **中文视频主线**：不想啃英文的首选，只听基础篇高数部分即可覆盖 M6 需求 |
| **徐小湛** | 川大教授，高数/线代/概率录像，板书慢节奏、零基础友好 | 中文（⚠️ 网络可得性多变） | 中文备选：节奏比武忠祥更慢更细；线代录像可作 M8 中文替代 |

### ★★ 辅助级 —— 特定场景才打开

| 资源 | 用法定位 |
| --- | --- |
| **PatrickJMT** | 短平快单题讲解库。卡在某类计算题时按主题搜一条看懂就走，**不要追着刷** |
| **The Organic Chemistry Tutor** | 超长合集版单题库。适合考前集中刷一类题型（如「积分技巧 100 分钟」） |
| **Eddie Woo** | 澳洲中学课堂实录，讲课热情。只在 M1–M5 某个中学概念没吃透时找对应主题看 |
| **Mathigon** | 交互式数学课程（概率论那门很好）。M9 阶段当互动练习场玩 |
| **Mathematics Stack Exchange** | 卡题时的搜索库。**先搜后问**，90% 初等问题已有高质量回答 |
| **苏德矿** | 浙大「矿爷」，微积分口碑极佳（⚠️ 课程视频的网络可得性需自行确认）。中文微积分另一候选，与武忠祥二选一 |
| **李永乐** | 人大附中老师，每期一个主题的科普短视频（贝叶斯、大数定律等）。**不是系统课**，休息时间的零食 |

### ★ 了解即可 / 现阶段不碰

| 资源 | 为什么现在不碰 |
| --- | --- |
| **AoPS**（Art of Problem Solving） | 竞赛数学体系，目标是奥赛而非 AI 地基，投入产出比低。Alcumus 刷题系统倒可以偶尔玩 |
| **Mathologer** | 数学科普频道，偏证明欣赏。当娱乐视频看，不占计划时间 |
| **BlackPenRedPen** | 积分技巧表演型频道。AI 路线对积分深度要求很低 |
| **Brilliant** | 付费交互平台，与免费的 Khan/Mathigon 功能重叠。预算充足再考虑 |
| **葛军** | 内容面向高考/竞赛应试，与 AI 地基路线错位 |
| **周沛耕** | 北大附中特级教师，高考/竞赛方向，同上错位 |
| **孙维刚** | 已故传奇教师，「结构化教学」思想值得敬佩，但现存资料是老课堂记录不成体系。想了解思想读《孙维刚初中数学》即可 |
| **胡小群** | ⚠️ 上海高中数学教师（背景未核实），内容偏初等解题，与 AI 地基路线错位 |
| **MathOverflow** | 职业数学家的研究级问答社区，初学者问题会被关闭。读到研究生水平再说 |

## 二、核心结论：主线只需要 4 个资源

```
主线三角（缺一不可）：
  Khan Academy（刷题系统）+ Paul's Notes（文字精读）+ 3Blue1Brown（直觉甜点）

第 4 个按语言偏好二选一：
  英文视频党 → Professor Leonard（微积分部分）
  中文视频党 → 武忠祥（基础篇）或 徐小湛（更慢更细）

进阶补充：
  M8 线代时加 MIT 18.06 Strang；Python 阶段加 MIT 6.0001
```

其余 16 个全部是「卡住了才查的字典」或「休息时的零食」，不进日程表。

## 四、24 周执行计划（每周约 8–10 小时）

> 假设：工作日每天 1 小时 + 周末各 2.5–3 小时。
> 两条轨道可选：**A 纯数学冲刺**（先数学后编程）、**B 数学+Python 并行**（推荐，防枯燥）。
> 每周日留 30 分钟做检查点自测；不过关就下周减新内容、补旧内容。

### 阶段一（W1–W4）：地基——数、式、方程

- **周一~五 每天 60 min**：Khan Algebra（30 min 视频 + 30 min 练习，练习不过 80% 不前进）
- **周六 2.5h**：Paul's Notes 预备知识章精读 + 抄例题
- **周日 3h**：本周错题重做 + 本站 M1/M2 课文 + 1 集 3B1B 当甜点
- ✅ 检查点 W4：能徒手解一元二次方程（配方法 + 求根公式）；能做分数指数运算；知道为什么负数没有实数平方根

### 阶段二（W5–W8）：函数、指数、三角

- 同上节奏，Khan 推进到 Precalculus
- 轨道 B 从本周开始：每周三晚改为 Python P1–P3
- ✅ 检查点 W8：给定 f(x)=2^(x-1)+3 能说出图像如何从 y=2^x 变换而来；会用单位圆解释 sin；Python 能写出猜数字小游戏

### 阶段三（W9–W13）：导数（最关键的一个月半）

- **主线切换**：Khan 退居练习器；正文用 Paul's Calc I（Limits → Derivatives → Chain Rule 各节）
- 视频轨：Leonard Calc I 对应讲次 **或** 武忠祥基础篇导数章（二选一，别都看）
- 甜点：3B1B《微积分的本质》全集（每集看完写一句「这集讲了什么直觉」）
- 本站：完成 M6 课文 + gradient-descent + B1–B4 伴学页
- 轨道 B：周四晚 Python P4–P6
- ✅ 检查点 W13：能手推 d/dx[x³·sin(x)]（乘积法则）；能用链式法则解释「责任分摊」；能给朋友讲明白「梯度下降为什么是下山」

### 阶段四（W14–W17）：线性代数

- **3B1B《线代的本质》全集先行**（每集 ~15 分钟，建立画面感）
- 然后 MIT 18.06 Strang 第 1–10 讲（或徐小湛线代录像，中文）
- Paul's 线代笔记做定义速查
- 轨道 B：Python P7–P8（NumPy/Pandas——正好用代码验证线代！）
- ✅ 检查点 W17：能把矩阵乘法解释成「线性变换的复合」；知道特征向量在说什么事；能用 NumPy 手写一次矩阵乘法并验证

### 阶段五（W18–W20）：概率与统计

- Khan 统计与概率 + Mathigon 概率课（交互）
- 李永乐的贝叶斯/大数定律科普穿插当零食
- 轨道 B 收尾：P9–P10（Matplotlib + 真实数据集实战）
- ✅ 检查点 W20：会用贝叶斯公式做一道两步推断题；能解释「p 值不是假设为真的概率」这句话对不对；P10 数据集分析报告完成

### 阶段六（W21–W24）：汇合——进入机器学习

- 本站 ML1–ML3（什么是机器学习、线性回归、逻辑回归）
- 你会发现：ML2 的「最小二乘」就是 W14 学的投影，ML3 的 sigmoid 就是 W9 的函数变形——**所有前置知识在这里咬合**
- 3B1B 神经网络系列第 5 集起（注意力机制）留给深度学习阶段
- ✅ 毕业检查点 W24：不看答案手推线性回归的梯度下降更新式并用 NumPy 实现；向别人讲清「训练 = 调参数让损失变小」

## 五、本地化策略（离线/弱网可用）

1. **Paul's Notes**：每节页面有打印版，把要学的章节批量下载打印——最适合纸质精读的材料
2. **B 站缓存**：武忠祥/徐小湛/李永乐/3B1B（B 站有官方号）的剧集用官方缓存功能下载，通勤路上看
3. **Khan 中文版**：⚠️ 官网注册账号同步进度，国内访问稳定性自查；网易公开课有部分官方翻译课程
4. **MIT OCW**：讲义 PDF 全部可直接下载；18.06 视频在 B 站有搬运（⚠️ 可能失效，失效去 ocw.mit.edu 找原版下载）
5. **Anki**：把本站 [[prerequisites/english/high-frequency-terms|E2 · 高频术语 100 词]] 导入 Anki，每天 10 分钟，配合英文资源食用
6. **本站 widgets**：`quartz/static/widgets/*.html` 都是本地文件，断网也能玩（学习率下山实验、责任分摊模拟器等）

## 六、三条纪律（比计划本身更重要）

1. **同一时段只有一条视频主线**。Leonard 和武忠祥讲的是同一门课，同时看两个 = 时间减半收获不变
2. **3B1B 永远是甜点不是主食**。看懂动画 ≠ 会做题；做题永远以 Khan 练习和 Paul's 例题为准
3. **每周日检查点不过关，下周就补课不加新**。进度落后是常态，连续两周落后就砍掉并行轨道而不是熬夜
