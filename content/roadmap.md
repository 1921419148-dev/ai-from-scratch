> [!abstract] 怎么用这张路线图？
> 学习就像爬山，不需要一口气登顶——**每次走一小段就好**。下面的路线分为几个阶段，每个阶段都建立在你已经学过的内容之上。带 ✅ 的课程已完成，🚧 表示正在编写中。

## 全景图

```mermaid
flowchart LR
    A[入门<br/>AI 是什么] --> B[前置知识<br/>数学 · Python · 英语]
    B --> C[人工智能大类]
    C --> C1[机器学习]
    C --> C2[深度学习]
    C2 --> D1[NLP]
    C2 --> D2[GenAI]
    C2 --> D3[强化学习]
```
