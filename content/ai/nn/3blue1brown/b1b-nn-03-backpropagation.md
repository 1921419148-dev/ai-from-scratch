## 🗺 先拿地图

第 2 集说过：训练 = 沿负梯度微调参数。但梯度有 1.3 万个分量——**每个权重、每个偏置各一个**。谁来算？

```mermaid
flowchart RL
    A["输出层<br/>『我把 2 认成了 9，<br/>错得离谱』"] --> B["倒数第二层<br/>『你们给我的激活值里，<br/>这几个帮凶嫌疑最大』"]
    B --> C["再往前一层……<br/>责任按连线权重比例<br/>层层分摊到每个参数"]
    C --> D["结果：每个参数都拿到<br/>自己的『该往哪调、调多少』清单"]
```

视频用一整集讲透一件事：

1. **聚焦一个训练样本**：网络把「2」认成了「9」。我们希望输出层怎么变？——代表 2 的神经元激活值升高，代表 9 的降低。
2. **倒推一步**：要让那个输出神经元变亮，它的「上游投票者」应该怎么变？（激活值、对应的权重、偏置，三条路都能出力）
3. **关键洞察**：同一个隐藏层神经元同时连着**所有**输出神经元——它收到的「整改要求」是各方诉求的**总和**。它自己也会犯难：「我到底该更亮还是更暗？」
4. **递归下去**：对倒数第二层的每条要求，继续问「它该怎么变才能满足」——一路推回输入层。
5. **乘上比例**：所有「该变的量」最终都要按**连线权重的比例**折算成「每个参数的调整量」。

> [!quote] 视频里的金句
> 反向传播衡量的是：**每一个参数对这次错误「贡献」了多少，从而决定它该被调整多少。**

## 🧠 核心概念拆解

### 概念 1：这不是「一次算法」，而是「一份账单」

初学者常以为反向传播是某种神秘机制。其实它就是**链式记账**：

```text
总误差（锅的总量）
   ├─ 摊给输出层每个神经元 → 各自的「应改方向」
   │     ├─ 摊给每条入边（按权重比例）→ 权重的调整量
   │     └─ 累加到上游神经元 → 隐藏层的「应改方向」
   │           └─ 继续往下摊……直到输入层
```

走完全程，1.3 万个参数人手一张账单：「你 +0.03、你 -0.17、你 +0.001……」

### 概念 2：为什么「锅」能精确分摊？——因为有权重

分摊比例不是拍脑袋：**权重大的连线，影响大，自然多背锅**。这正是第 1 集「权重 = 话语权」的回收：话语权越大，说错话的责任越大。

### 概念 3：「求和」与「冲突」

同一层的一个神经元被多个下游「点名」，它收到的是**带正负号的诉求之和**。可能互相抵消——这是真实且重要的现象，说明这个参数对整体误差影响不大。

### 概念 4：直觉篇 vs 数学篇

本集刻意回避公式。但请记住对应关系，第 4 集会全部兑现：

| 直觉语言（本集）             | 数学语言（下一集） |
| ---------------------------- | ------------------ |
| 锅的总量                     | 损失 C             |
| 「该往哪变、变多少」的敏感度 | 偏导数 ∂C/∂a       |
| 责任按权重比例摊             | 链式法则乘以 ∂a/∂w |
| 层层倒推                     | 递归应用链式法则   |

## ✅ 自测一下

> [!question]- 1. 反向传播解决的核心问题是什么？
> 网络答错后，计算**每一个参数（权重/偏置）对这次错误的「责任大小」**，也就是损失函数对每个参数的偏导数。有了这份完整账单，梯度下降才知道每个参数该往哪调、调多少。

> [!question]- 2. 为什么隐藏层神经元收到的整改要求是「求和」？
> 因为它同时向多个下游神经元供数，每个下游都会根据自己的需求向它提「变亮/变暗」的诉求。这些带方向的诉求叠加（可正可负、可抵消）才是它真正应该做的调整。

> [!question]- 3. 分摊责任的「比例」由什么决定？这解释了训练中的什么现象？
> 由连线权重决定：权重越大、影响越大、分到的责任越多。所以训练中**强连接会被大幅调整，弱连接几乎不动**——网络自动把学习资源集中在影响大的参数上。

> [!question]- 4. （接第 2 集）有了反向传播，梯度下降就齐活了吗？还差什么？
> 齐活了。梯度下降说「朝下坡迈小步」，反向传播负责高效算出「坡度在每个方向上的分量」。两者合起来就是完整的训练循环：前向算输出 → 反向传误差 → 沿梯度更新 → 重复。
