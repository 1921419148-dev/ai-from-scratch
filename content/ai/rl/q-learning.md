## 生活场景切入

想象一张神奇的评分表：

```text
            左     右    上    下
客厅·沙发   2.1   0.3   1.5  -0.8
厨房        0.5   4.7   0.9   0.2   ← 在厨房时「向右」得分最高
门口       -1.2   3.3   0.1   0.6
```

每一行是一个状态，每一列是一个动作，格子里是 **Q 值**——「在这个状态做这个动作，长远能拿到多少累计奖励」的预估。

有了这张表，行动规则简单粗暴：**每到一处，挑分数最高的动作执行**。Q-Learning 的全部工作就是从零开始、纯靠试错把这张表填对。

## 核心概念拆解

### 概念 1：更新公式解剖 —— 一行代码的贝尔曼方程

```python
Q[s][a] += alpha * (r + gamma * max(Q[s_next]) - Q[s][a])
```

| 部件                     | 名字             | 人话                         |
| ------------------------ | ---------------- | ---------------------------- |
| `r`                      | 即时奖励         | 这一步实际拿到手的好处       |
| `gamma * max(Q[s_next])` | 未来价值的估计   | 下个状态能继续薅到的最好前景 |
| `r + gamma·max…`         | 目标值 TD target | 「这一步实际表现出的价值」   |
| `Q[s][a]`                | 当前估计         | 你之前以为的价值             |
| 两者之差 × alpha         | TD 误差          | 预期与现实的差距，修正量     |

人话总结：**「现实比你想的好 → 调高分数；比你想的差 → 调低分数；差多少修多少（乘个小系数 α 别矫枉过正）」**。每个采样 (s, a, r, s') 都触发一次微调——不需要知道环境规则，玩着玩着表格就对了。这就是「无模型（model-free）」的含义。

### 概念 2：完整实战 —— 悬崖行走

经典试验场：6×3 网格，左下角出发要走到右下角终点，底部中间三格是悬崖（掉下去 −100 并扔回起点），每走一步 −1（鼓励走快）。训练 500 轮（实际运行结果）：

```text
前 50 轮平均回报: −31.22     ← 乱撞期：频繁掉悬崖
后 50 轮平均回报: −17.20     ← 进化完成

学到的最优路径:
(2,0)→(1,0)→(1,1)→(1,2)→(1,3)→(1,4)→(1,5)→(2,5)
↑ 先向上爬一格避开悬崖，再沿第二行横穿，最后下来进终点
```

读出三个学习现象：

1. **前期惨烈是必然**：初始 Q 全零=所有动作等概率随机，掉坑是学费
2. **−100 的悬崖惩罚自动传播**：掉过几次坑后，「靠近悬崖边缘」状态的 Q 值被拉低，智能体自发学会绕行——没人教它「安全第一」，是数字告诉它的
3. **每步 −1 的设计巧思**：若不设步数惩罚，最优解可能是原地不动（反正没奖励也没损失）；小负奖励逼它尽快到达

### 概念 3：ε-greedy —— 训练期的探索保险丝

训练时不能永远选当前最高分（会错过更好的路），也不能太随机（学得慢）。ε-greedy 的折中：

```text
以 ε=0.1 概率：随机选一个动作（探索）
以 0.9 概率：选当前 Q 最高的动作（利用）
```

进阶技巧是 **ε 衰减**：前期 ε 大（多探索广撒网），后期 ε 小（专注利用已学成果）——与 DL12 学习率衰减同款的「先探索后收敛」哲学。

### 概念 4：on-policy 与 off-policy —— Q-Learning 的隐藏身份

Q-Learning 有个精妙性质：更新目标用的是 `max(Q[s_next])`——**假设下一步一定走最优动作**，不管实际执行的是什么（探索时的随机动作也按最优算）。

```text
Off-policy：学的策略（贪心）≠ 行动的策略（含探索的 ε-greedy）
   → 可以「看别人玩」来学习（经验回放池、模仿数据都行）
On-policy（如 SARSA）：学的和做的是同一个策略
   → 更保守，会把「探索的风险」也计入评估
```

在悬崖实验里两者有著名的行为差异：SARSA 学到远离悬崖的安全路线，Q-Learning 学到贴边最短路线（因为它的 max 不考虑自己可能失足）。**没有谁对谁错——是否为探索风险买单是个设计选择。**

### 概念 5：表格的天花板 —— DQN 登场的理由

Q-Learning 完美适用于小而离散的世界，但两个死穴：

```text
① 状态爆炸：Atari 游戏的画面状态约 2^（210×160×像素位数）种，
   表格根本建不过来
② 无法泛化：没见过的状态全是空白——学过 100 种房间布局，
   第 101 种还是从零摸索
```

破局思路顺理成章：**用神经网络代替表格**——输入状态，输出各动作的 Q 值，网络自动泛化到相似的新状态。这就是 2015 年 DeepMind 的 DQN（Deep Q-Network），在 Atari 49 局游戏里达到人类水平，引爆了深度强化学习时代。RL4 将走向另一条路线（策略梯度），但 DQN 这条价值派主线同样通向 AlphaGo 与 RLHF。

## 自测一下

> [!question]- 1. 把更新公式里的 `max(Q[s_next])` 改成 `min(Q[s_next])` 会发生什么？改成 `mean` 呢？
> `min`：变成悲观主义学习——每一步都按「下个状态最坏前景」估值，学出的策略极端保守（可能宁可停在起点也不动，因为动就可能变差）。
> `mean`：等于对所有可能动作的前景取平均——这其实是另一种算法的思想（期望 SARSAA 类），学到的是「随大流策略」而非最优策略。
> 三种选择的本质差异在于**如何对待下一个状态的不确定性**：乐观 max 冒险、悲观 min 保守、均值 neutral——没有绝对正确，取决于环境惩罚的严重性（悬崖场景 min 反而是安全的选择）。

> [!question]- 2. 为什么悬崖实验里 Q-Learning 学出贴边路线而 SARSA 学出安全路线？（提示：训练时还有 ε 探索）
> 训练时带 ε=0.1 的随机探索，意味着贴边行走时有 10% 概率失足掉崖吃 −100。
> SARSA 是 on-policy：它把「探索导致的坠崖」真实计入了自己策略的价值评估——贴边的 Q 值被这些事故拖低，于是学会留出一格安全距离。
> Q-Learning 是 off-policy：更新时用 max 假设「下一步必走最优」，探索风险不计入评估——所以它的 Q 表认为贴边是最优的（确实是最短路径！），只是执行时会因探索偶尔翻车。
> 哲学余味：Q-Learning 学的是「理想驾驶者的地图」，SARSA 学的是「包括自己手抖的现实地图」。

> [!question]- 3. 经验回放（存历史样本反复抽学）为什么能加速稳定训练？
> 两大功效：① **打破时间相关性**——连续采样的轨迹高度相似（相邻帧几乎一样），按顺序学习会让更新方向震荡；随机抽取打散了相关性，更接近独立同分布的统计学习前提。
> ② **数据复用**——昂贵的交互经验（尤其真实机器人）被反复榨取价值，样本效率倍增。
> 附赠一个 off-policy 才有的福利：回放池里的旧数据是用旧策略采集的，Q-Learning 的 off-policy 性质允许它们依然有效——这也是为什么经验回放天然搭配 Q-Learning 家族。

> [!question]- 4. 你的 Q-Learning 训练一万轮后策略仍然乱撞。给出四条排查方向。
> ① **α/γ/ε 配置**：α 太小学不动、太大震荡；ε 太大学不会利用、太小陷入局部；γ 与任务视野错配；
> ② **奖励尺度异常**：奖励过大导致 Q 值发散溢出，或全为零无信号——打印 Q 表分布一眼可见；
> ③ **状态编码缺陷**：关键信息没进状态（MDP 违反），不同情形被迫共享同一行的 Q 值互相打架；
> ④ **bug 三巨头**：更新公式符号写反、next_state 取错（用了旧状态）、终止判断遗漏（无限循环刷奖励）。
> 排查心法沿用 DL12：先看数据流（Q 表数值分布），再查公式实现，最后才怀疑算法本身。
