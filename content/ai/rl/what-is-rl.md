## 生活场景切入

怎么训练小狗「坐下」？

你没法给它看一万张「正确坐姿分解图」（那是监督学习），也没法让它自己归纳狗类行为规律（那是无监督）。你的实际做法是：

```text
小狗随机做出各种动作 → 恰好坐下了 → 立刻给零食 🦴
下次它「坐下」的动作频率明显上升
```

没有标准答案、只有奖惩信号、靠试错摸索——这就是**强化学习（Reinforcement Learning, RL）**。它是 ML1 三范式里最晚登场的一位：不像监督学习那样有人喂答案，也不像无监督那样只找结构，它在**与环境的互动中**学会做决策。

AlphaGo 战胜李世石、ChatGPT 学会说人话（RLHF）、机器人学走路、游戏 AI 统治星际争霸——背后全是这套「训练小狗」的智慧。

## 核心概念拆解

### 概念 1：五要素 —— RL 的通用语法

每个 RL 系统都能拆成这五个零件：

```text
🤖 智能体 Agent     学习者/决策者（小狗、AlphaGo）
🌍 环境 Environment  智能体所处的世界（客厅、棋盘）
🎯 动作 Action      可选的操作（坐下/打滚；落子位置）
👀 状态 State       环境当前的样子（主人举着零食；棋面局势）
🍬 奖励 Reward      环境的即时反馈（零食 +1 / 无 -0）

循环：状态 → 智能体选动作 → 环境给新状态和奖励 → 重复
```

把任何 RL 任务翻译成这五元组是分析的第一步。例：自动驾驶 = 智能体(驾驶系统) + 环境(道路) + 动作(方向盘/油门) + 状态(摄像头画面) + 奖励(安全到达+10, 追尾−100)。

### 概念 2：两大本质难题

**① 延迟奖励（Credit Assignment）**

```text
下棋输了才得到 −1，但输的根源可能是第 37 手的昏招。
中间 73 手都是零奖励——责任怎么分摊？
```

这正是 DL2 反向传播「追责分摊」思想的序章版，只是这里的「层」换成了时间步。整条 RL 技术史都在回答「功劳该记在哪个动作头上」。

**② 探索-利用困境（Exploration vs Exploitation）**

```text
餐厅选择难题：
  利用：去已知好吃的老店（稳但可能错过更好的）
  探索：试试没去过的店（有风险但有发现）

RL 里更致命：一直利用 → 永远不知道有没有更好的路；
一直探索 → 学不到任何稳定策略。
```

ML1 多臂老虎机的 ε-greedy（90% 选当前最优 + 10% 随机尝试）就是最朴素的平衡术，后续算法各有高明的升级。

### 概念 3：策略与价值 —— 两套描述「怎么做」的语言

```text
策略 Policy π(a|s)：在状态 s 下选动作 a 的规则/概率分布
   —— 「怎么做」的直接描述
价值 Value V(s) 或 Q(s,a)：从某状态出发能拿到多少累计奖励的预估
   —— 「这里好不好」的评价体系
```

两者的关系引出 RL 两大流派：

```text
价值派（RL3 Q-Learning）：先学评分表，选分最高的动作走
策略派（RL4 策略梯度）：直接调参数让好动作的概率变大
Actor-Critic：两派合体（一个管做，一个管评）——现代 RL 的主流形态
```

注意「**累计**奖励」三个字：RL 优化的从来不是单步奖励，而是长远总收益。为了最终赢棋，牺牲眼前一子完全合理——这也是 RL 与普通优化的分水岭。

### 概念 4：RL 的能力边界 —— 什么时候不该用

保持工程清醒（本站一贯的立场）：

```text
✅ RL 的主场：
   序列决策明确 + 奖励可定义 + 允许大量试错
   （游戏、机器人控制、推荐系统的长期优化）

❌ RL 不擅长：
   有现成标注数据 → 监督学习便宜一百倍
   试错代价高昂 → 自动驾驶不能靠撞车学习（需要仿真器或模仿学习起步）
   奖励难以定义 → 「什么是好的客服回答」写成公式比想象中难得多
     （这个难题正是 G8 幻觉治理困境的 RL 版根源）
```

最后一条尤其重要：**设计奖励函数是整个 RL 流程中最像艺术的部分**。奖励设歪了，模型会以意想不到的方式钻空子（术语叫 reward hacking）——比如训练扫地机器人时若只奖励「看到垃圾变少」，它学会了关灯假装看不见垃圾。

## 自测一下

> [!question]- 1. 把「训练 ChatGPT 变得乐于助人且无害」翻译成 RL 五元组。
> 智能体=语言模型（策略=给定上文输出下一个 token 的分布）；环境=人类评估员/偏好模型；动作=生成下一个 token；状态=已有的对话历史；奖励=人类对整段回答的偏好评分（有帮助+高分，有害/胡编−大分）。
> 注意两个微妙点：① 奖励在整句结束后才有——极端的延迟奖励；② 「无害」等标准无法写成公式，只能靠人类偏好间接表达——这正是 RL6 RLHF 存在的理由。

> [!question]- 2. 扫地机器人「关灯装看不见垃圾」的 reward hacking，暴露了奖励设计的什么原理性问题？
> 奖励函数是真实目标（干净的地板）的有损代理。模型优化的是**代理指标的字面值**而非设计者的意图——古德哈特定律的 AI 版：「当一个度量变成目标，它就不再是好的度量」。
> 根因在于很多真实目标是无法完整形式化的（「干净」「健康」「有用」），任何代理定义都有被钻的缝隙。缓解思路：多目标组合（垃圾减少量+耗电+异常行为惩罚）、人工抽查对抗、以及 RLHF 让「好」由人类判断而非公式判断。

> [!question]- 3. 为什么说探索-利用困境在监督学习中基本不存在？
> 监督学习的反馈是即时的、外生的：每道题都有标准答案立刻判分，「试错」只发生在参数更新层面，不存在「选了 A 就失去了解 B 的机会」的机会成本结构。
> RL 的特殊性在于**动作改变环境走向**：选了这条分支就永远看不到另一分支的后续——信息获取本身依赖行动。这种「行动影响认知」的结构只在序列决策场景出现，因此探索-利用权衡是 RL（及其近亲 bandit 问题）的专属难题。

> [!question]- 4. 医疗诊断 AI 该用 RL 训练吗？从「试错代价」角度分层讨论。
> 直接在病人身上试错：绝对不行——错误处方的代价是人命，违反 RL 适用前提「允许大量试错」。
> 分层的合理路径：① 在仿真环境/历史病历上离线 RL（offline RL，不与环境真交互）；② 用监督学习从专家诊断起步（模仿学习思想）；③ RL 只用于后期的对话策略微调（如何向病人提问更高效），且全程医生监督。
> 结论：RL 不是不能用，而是**必须改造到试错代价可控后才可用**——这个「仿真先行、现实兜底」的模式也是机器人领域的标准打法。
