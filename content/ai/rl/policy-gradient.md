## 生活场景切入

学骑自行车有两种教练：

```text
价值派教练：给你一张评分表——「车把左倾 5° = 3 分，右倾 2° = −1 分」，
            你按表选最高分的操作。
策略派教练：什么都不解释，只在你骑得稳时说「就这样保持！」，
            骑晃了说「别这样」——你自己的身体慢慢调整直觉。
```

RL4 的策略梯度就是第二种教练：不建评分表，直接用一个神经网络输出动作偏好，靠回报信号微调网络参数。**好动作 → 提高它的概率；坏动作 → 降低概率**，如此往复。

## 核心概念拆解

### 概念 1：为什么需要第二条路线

RL3 的 Q 表有两个结构性死穴（已预告），策略派逐一化解：

| 死穴                   | 策略派的解法                           |
| ---------------------- | -------------------------------------- |
| 状态爆炸，表格建不过来 | 网络天然参数化，状态再复杂也是输入向量 |
| 无法泛化到相似新状态   | 神经网络的归纳能力自动外推             |
| **连续动作无法枚举** ★ | 输出分布参数而非逐个打分               |

第三条最致命：方向盘转 37.5°、机械臂关节角 0.83 弧度——连续空间里动作无穷多，max(Q) 没法穷举。而策略网络可以直接输出「正态分布的均值和方差」，从分布中采样一个具体角度。**机器人控制几乎清一色策略派**。

### 概念 2：REINFORCE —— 最朴素的策略梯度

算法核心只有一行直觉：

```text
∇J(θ) ≈ 回报 G × ∇log π(动作|状态)

翻译：整局赚得多 → 大幅强化这局的每个动作
      整局亏了   → 削弱这局的每个动作
```

注意它优化的是**整条轨迹的总回报 G**，而不是单步奖励——延迟奖励问题在这里被粗暴但有效地处理：一局赢了，全员记功；输了，全员背锅。（更精细的归功技术——如只用未来回报、减去基线——是后续改进版的事。）

### 概念 3：实战 —— 走廊实验

10 格走廊，从 0 走到 9 结束；向右一步 −1，向左原地踏步罚 −2（逼它学会别回头）。策略网络只有两个参数 θ=[左分数, 右分数]（实际运行结果）：

```python
# 训练 1000 轮 REINFORCE

前 50 轮平均回报: −9.96     ← 初期乱走
后 50 轮平均回报: −9.00     ← 已是最短路径（9 步 × −1）

学到的策略: P(向右)=0.9999  P(向左)=0.0001
→ 几乎确定性地一路向右，完美收敛 ✓
```

虽然任务简单，五脏俱全：采样动作 → 收集整局轨迹 → 按总回报给每个 (状态, 动作) 对打梯度补丁——这套循环放大到百万参数网络 + 复杂环境，就是现代策略梯度的全部骨架。

### 概念 4：方差之痛与 Actor-Critic

REINFORCE 有个著名弱点：**方差巨大**。同一策略玩十局，回报可能天差地别（运气成分），导致梯度忽大忽小、训练震荡。

主流解法是 **Actor-Critic（演员-评论家）** 双网络架构：

```text
Actor（演员）：策略网络，负责出动作        ← RL4 的主角
Critic（评论家）：价值网络，实时点评动作好坏  ← RL3 的 Q 函数转世

更新逻辑：不再用整局回报 G 当信号（方差大），
         改用 Critic 的估值差「比预期好多少」当信号（方差小）
```

这是两派的合体：策略派出招、价值派点评。A2C/PPO 等当代主力算法都是这个家族——PPO 更是 RLHF 的核心引擎（RL6 见）。

### 概念 5：两派对比总表 —— 选型速查

| 维度       | 价值派（Q-Learning/DQN） | 策略派（REINFORCE/PPO）        |
| ---------- | ------------------------ | ------------------------------ |
| 学什么     | 动作的评分表             | 动作的概率分布                 |
| 连续动作   | ❌ 要离散化              | ✅ 天然支持                    |
| 随机策略   | 别扭                     | ✅ 天然输出概率                |
| 样本效率   | 高（可反复回放）         | 低（数据用完即弃倾向）         |
| 训练稳定性 | 表格稳定/深度版要技巧    | 方差大，需 baseline/Critic     |
| 典型应用   | 游戏（离散按键）         | 机器人、NLP 对齐（token 分布） |

最后一条暗藏伏笔：语言模型生成 token 本来就是一个「输出分布再采样」的过程——**策略派结构与 LLM 天然同构**。这就是为什么 RLHF 选 PPO 而不是 DQN 的深层原因，种子在 RL4 就埋下了。

## 自测一下

> [!question]- 1. REINFORCE 为什么用「整局总回报」而不是「该动作的即时奖励」做权重？举例说明即时奖励会怎么误导。
> 经典反例：棋局中第 1 手弃车引诱（即时奖励为负——丢了个大子），布局成功后 40 手后获胜（终局大奖）。
> 若用即时奖励加权：弃车动作被削弱（当时奖励负），模型永远学不出战略性牺牲。
> 整局回报把「这一步对最终胜负的贡献」打包计入——牺牲的价值经由终局胜利回流到第 1 手。这正是 RL1「荣誉分配」难题的第一代答案（粗糙但方向正确），精细版是折扣回报到每步（G 从该步算起）与优势估计。

> [!question]- 2. 「减去基线（baseline）」为什么能降低方差却不改变梯度的期望方向？
> 数学事实：基线 b 只要与动作无关，E[(G−b)·∇log π(a)] = E[G·∇log π] − b·E[∇log π]，而后一项为零（∑π∇log π = ∇∑π = ∇1 = 0）。
> 直觉解读：所有回报都减去平均水平后，信号从「绝对好坏」（+50 和 +80 都是正=都在强化）变成「相对意外程度」（高于预期才强化、低于预期才削弱）——信号的正负更有信息量，数值波动更小，方差自然下降。
> 这正是 Actor-Critic 里 Critic 的第一职责：充当那个会动的基线。

> [!question]- 3. 为什么机器人控制领域策略派碾压价值派？
> 决定性因素是**连续动作空间**（概念 1 第三条）：机械臂有 7 个关节角度、无人机有 4 个电机推力——动作空间是连续实数向量。
> 价值派要给「每个可能的动作组合」打分：7 维连续空间无法建表，离散化则精度损失且维度灾难（每维切 100 份就是 100⁷ 个格子）；即便用 DQN 也需要先人为离散化动作。
> 策略派直接输出高斯分布的 (均值, 方差)，采样即得平滑的控制指令——结构上就是为连续控制而生的。此外仿真到现实的迁移中，随机策略的平滑性也更抗噪。

> [!question]- 4. 语言模型的 RLHF 为什么天然属于策略派？从「动作是什么」出发推理。
> LLM 的每步动作 = 在几万~几十万词表的 token 上输出一个概率分布，然后采样下一个 token。
> 这个结构就是标准的 softmax 策略：状态=已有对话，动作=选哪个 token，策略网络=LLM 自己。
> 若硬套价值派（DQN）：需要对每个候选 token 打 Q 值再取 max——理论上可行但抛弃了模型原有的分布输出头，且词表级 max 的搜索成本高昂；策略派则只需对「已采样的序列」计算梯度，LLM 结构零改动。
> 结论：**LLM 本身就是一个现成的巨型策略网络**，RLHF 只需教它「哪些续写人类更喜欢」——PPO 登场的一切前置条件至此就位。
