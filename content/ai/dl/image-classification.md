## 生活场景切入

ML10 你做过表格数据的回归，这一课升级到**图像数据的多类分类**——流程骨架完全一样，新增的只有两块砖：softmax（多类概率输出）和图像特有的数据形态。

为了人人可跑，我们不用 MNIST 手写数字（下载要网络、训练要时间），而是**自制三种 8×8 迷你图案**：横线、竖线、对角线。麻雀虽小：从像素到预测的每一环都和真实项目同构。

## 核心概念拆解

### 第 0 步：任务卡

```text
输入：8×8 灰度图（展平成 64 维向量）
输出：三选一 —— 0=横线, 1=竖线, 2=对角线
指标：测试集准确率 + 混淆矩阵
基线：瞎猜 = 33.3%
```

### 第 1 步：造数据 —— 带噪声的三种图案

```python
import random, math
random.seed(3)

def make_img(kind):
    img = [0.0]*64
    if kind == 0:                          # 横线：随机选一行点亮
        r = random.randrange(1, 7)
        for j in range(8): img[r*8+j] = 1.0
    elif kind == 1:                        # 竖线：随机选一列
        c = random.randrange(1, 7)
        for i in range(8): img[i*8+c] = 1.0
    else:                                  # 对角线：主对角
        for d in range(8): img[d*9] = 1.0
    # 加高斯噪声 + 随机截断，模拟真实成像的不完美
    return [min(1, v+max(0, random.gauss(0, 0.15))) for v in img]

data = []
for kind in range(3):
    for _ in range(60):
        data.append((make_img(kind), kind))
random.shuffle(data)
```

每张图的位置有随机性（哪一行/列），噪声让边界模糊——逼模型学「模式」而不是背「坐标」。

### 第 2 步：新零件 softmax —— 多类的概率出口

二分类用单个 sigmoid 就够；K 类需要 K 个输出各自变成概率且总和为 1：

```text
softmax(z)ₖ = e^zᵏ / Σⱼ e^zʲ

实测: softmax([2.0, 1.0, 0.1]) ≈ [0.659, 0.242, 0.099]
```

两个工程细节：

- **数值稳定版要先减最大值**再算指数：`exp(1000)` 会直接溢出报错，`exp(1000−1001)=exp(−1)` 稳如泰山——所有框架内部都这么做
- **softmax + 交叉熵是一对天作之合**：两者复合后对输入的梯度恰好是 `p − y`（预测减独热真值，中心差分数值验证逐位一致）——与 ML3 的 sigmoid 场景异曲同工，优雅得像是设计好的（其实就是数学设计好的）

### 第 3 步：建模 —— 单层全连接 + softmax

```python
W = [[random.gauss(0, 0.05) for _ in range(64)] for _ in range(3)]
b = [0.0]*3
```

结构上是「64 → 3 的全连接 + softmax」。这个看似朴素的模型有个学名——**多项逻辑回归（multinomial logistic regression）**。它的 192 个权重每个都有清晰含义：「第 i 个像素对『是横线』的证据强度」。稍后可视化会看到惊喜。

### 第 4 步：训练 —— 老朋友循环

```python
lr = 0.5; n_tr = 150          # 150 训练 / 30 测试
for epoch in range(200):
    for x, t in zip(X[:n_tr], Y[:n_tr]):
        z = [sum(W[k][i]*x[i] for i in range(64)) + b[k] for k in range(3)]
        p = softmax_stable(z)
        for k in range(3):
            g = p[k] - (1 if k == t else 0)      # softmax+CE 的优雅梯度
            for i in range(64):
                W[k][i] -= lr*g*x[i]
            b[k] -= lr*g
```

对照清单：交叉熵损失（ML3）✓ 梯度下降（M7）✓ `p−y` 梯度（DL2 数值验证过）✓ 先切后看（ML4）✓。

### 第 5 步：评估 —— 准确率 + 混淆矩阵

实际运行结果：

```text
train acc = 1.000    test acc = 1.000

混淆矩阵 (真实, 预测): [(0,0)×12, (1,1)×6, (2,2)×12]
→ 对角线上全是数，零串行 —— 完美分类
```

对比基线 33.3%，模型把准确率拉满了三倍。任务简单是原因之一，但更重要的是**特征与模式的匹配**：像素天然保留线条的空间结构，线性模型就足以切开三类。

### 第 6 步：彩蛋 —— 把权重画出来看看

最精彩的一步：第一类（横线）的 64 个权重按 8×8 排回原图，按行求和：

```python
print([round(sum(W[0][r*8:(r+1)*8]), 2) for r in range(8)])
# [-15.04, 5.84, 5.77, 5.51, 5.27, 5.36, 5.14, -13.34]
```

读这张「权重脸谱」：**中间六行的权重全为正**（这些位置的亮像素支持「横线」判断），**首尾两行大幅为负**（顶部/底部出现亮点反而反对横线——因为那是竖线和对角线的地盘）。没有人教过它行列结构，梯度下降自己悟出了「横向亮带才是横线的证据」。

这正是 DL5 说的「第一层卷积核长成边缘检测器」的迷你预演：**训练后的权重就是模型的认知，而且看得见摸得着。**

## 自测一下

> [!question]- 1. 为什么 softmax 内部计算前要把所有 z 减去最大值？减完结果会变吗？
> 不减的话 `exp(z)` 遇到大 z 直接溢出成 inf（实测 `math.exp(1000)` 抛 OverflowError）。整体平移不改变 softmax 输出——因为分子分母同乘一个常数 `e^(−max)` 后正好约掉。
> 所以减最大值是「免费的保险」：数学等价、数值安全。这类技巧在深度学习里到处都是（log-sum-exp、注意力里的类似处理），第一次见懂了就终身受用。

> [!question]- 2. 如果把本课的三类改成十类，「横线」的样本被误判成「竖线」，混淆矩阵里会体现在哪个格子？
> 行=真实类 0（横线）、列=预测类 1（竖线）的那个格子计数加一。
> 读混淆矩阵的心法：**对角线是正确率，非对角线找「谁被认成了谁」**。如果发现错误集中在某两类的互相误判（比如横线↔竖线），说明模型分不清这对——可能需要更强的模型或更好的特征；若是均匀散布的小错误，则更像噪声所致。

> [!question]- 3. 本课模型在带噪声数据上也 100% 了，能不能说「线性模型够用了，CNN 没必要学」？
> 在**本课的合成任务**上确实如此——线性边界恰好切得开三类图案。
> 但推广不成立：真实图像里「猫」的姿态、光照、遮挡千变万化，猫的判定区域在高维像素空间中高度非线性缠绕，线性模型力不从心。CNN 的价值在复杂视觉模式 + 大规模真实数据上兑现。
> 工程判断力正在于此：**先问任务的决策边界长什么样，再决定动用什么火力**——能用线性解决的问题是幸运，不是常态。

> [!question]- 4. 「权重可视化显示中间六行为正、首尾两行为负」，为什么负号出现在首尾两行？
> 因为那两类竞争对手的「地盘」在那里：竖线可以出现在任何一列但常贯穿上下边缘区，对角线必经左上角和右下角。
> 对横线分类器来说，顶部或底部出现强亮点强烈暗示「这是竖线/对角线而非横线」——于是梯度下降把这些位置的权重压成负值作为反证据。
> 这体现了 softmax 多类学习的一个微妙之处：**每个类的权重是在与其他类的对抗中被塑造的**，负权重同样是学到的重要知识。
