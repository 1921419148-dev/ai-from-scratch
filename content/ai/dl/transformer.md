## 生活场景切入

2017 年，Google 八位研究员发表了一篇标题狂妄的论文——《Attention Is All You Need》（注意力就是你所需要的一切）。他们把当时主流的 RNN 从序列模型里彻底开除，只留注意力机制，结果翻译质量暴涨且训练速度飞快。

七年后的今天回望：GPT 系列是它，BERT 是它，Claude 是它，Stable Diffusion 的文本编码器是它，连视觉领域的 ViT 还是它。**Transformer 已经成为「深度学习新架构」的同义词。**

但拆开看，它没有任何一个部件是你没学过的：

| 积木           | 出身             | 本站课程 |
| -------------- | ---------------- | -------- |
| 注意力         | 对齐/检索思想    | DL8      |
| 前馈网络       | 最古老的神经网络 | DL1/DL4  |
| 残差连接       | ResNet（2015）   | 本课讲   |
| 嵌入 + softmax | 词向量思路       | ML3/DL6  |

**创新不在零件，而在组装方式**——这本身就是一堂工程哲学课。

## 核心概念拆解

### 概念 1：整体流水线 —— 一个 token 的旅程

以 GPT 处理「猫 坐 在 垫子上」为例：

```text
① 分词：文本 → token 序列
② 嵌入 Embedding：每个 token → 高维向量（查表）
③ + 位置编码 Positional Encoding：注入顺序信息
④ × N 层 Transformer Block：
     自注意力（token 间交换信息）→ 前馈网络（各自深度加工）
⑤ 输出层：最后一个位置的向量 → softmax → 下一个词的概率分布
```

### 概念 2：位置编码 —— 注意力的补丁

DL8 说过注意力天生是「无序集合」视角——打乱输入顺序输出不变。但语言显然有序（「狗咬人」≠「人咬狗」）。

原论文的解法优雅而古典：给每个位置生成一组**不同频率的正弦/余弦波**，加到词嵌入上：

```text
PE(pos, 2i)   = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
```

这正是 M5 三角函数课的原文重现！直觉：每个位置拿到一组「时分秒针」组合，任意两个位置的相对距离可以从编码中直接推算。后来的变体（如 RoPE，旋转位置编码）换汤不换药——**用数学结构编码序列结构**。

### 概念 3：Transformer Block —— 两道工序的流水线

每一层做两件事，先社交再思考：

```text
x = x + MultiHeadAttention(LayerNorm(x))    ← 工序一：横向社交（词间交换信息）
x = x + FeedForward(LayerNorm(x))           ← 工序二：纵向加工（每词独立过两层 MLP）

×N 层堆叠（GPT-3 用了 96 层）
```

前馈层常被忽视却占据约三分之二的参数量——它是「存储知识」的主要场所（研究界称其中的神经元为 key-value memory）。注意力负责「路由信息」，前馈负责「消化信息」，分工明确。

### 概念 4：残差连接与 LayerNorm —— 无名英雄

**残差连接（Residual Connection）** 就是上面公式里的 `x = x + ...`：每层的输出不是替换输入而是叠加在输入上。这个来自 ResNet 的小改动威力惊人：

```text
无残差：梯度要穿过每一层的全部变换 → 层数一深就消失（DL1/DL7 老病）
有残差：恒等通道直达底层，梯度可以「抄近路」→ 百层网络轻松训练
```

类比：编辑改稿时不是重写全文而是在原稿上批注——原稿永远保留一条完整通路。**深度学习最深的教训之一：给梯度留退路。**

**LayerNorm** 则是把每个向量的数值拉回稳定区间（均值 0 方差 1），防止深层堆叠时数值漂移爆炸。两者合璧，才撑得起千亿参数 × 96 层的巨构。

### 概念 5：三大家族 —— 一块基石三种玩法

同一个 Transformer 骨架，改变注意力的掩码方式和训练目标，分化出三大门派：

| 家族 | 结构             | 训练任务   | 擅长       | 代表         |
| ---- | ---------------- | ---------- | ---------- | ------------ |
| GPT  | 单向（因果掩码） | 预测下一词 | 生成、对话 | GPT/Claude   |
| BERT | 双向（无掩码）   | 完形填空   | 理解、分类 | BERT/RoBERTa |
| T5   | 编码器+解码器    | 文本到文本 | 翻译、摘要 | T5/mT5       |

回忆 DL8 的结论：掩码由训练目标决定。三大家族的分野本质上是**三种训练目标的分野**。今天的大语言模型主线是 GPT 式——因为它与「续写一切」的通用智能路径天然契合，而且预训练不需要任何人工标注。

### 概念 6：参数都藏在哪 —— 以 GPT-3 为例

用估算公式 `参数 ≈ 12 × 层数 × 维度²` 验证官方数字（实际计算结果）：

```text
GPT-3: 96 层 × 12288 维 → 12 × 96 × 12288² ≈ 174B ≈ 官方公布的 175B ✓

其中约 2/3 在前馈层，1/3 在注意力投影——「知识主要存在 FFN 里」的实证。
```

从 GPT-1（1.17 亿）到 GPT-3（1750 亿）只用了四年，参数翻了三个数量级。这条陡峭曲线背后的规律和争议，正是 DL11 的主题。

## 自测一下

> [!question]- 1. 论文标题说「只需要注意力」，但标准 Transformer 里明明还有前馈层。怎么理解这个标题？
> 它针对的是当时的争论：「序列建模必须依赖循环结构吗？」答案是断然的不。
> 标点的准确含义是：**RNN 的循环（ recurrence ）并非必需，注意力一种机制就足以承担全部跨位置信息交换**。前馈层不负责跨位置通信（每个位置独立加工），所以不在被否定的范围内。读论文标题要读它的论战语境。

> [!question]- 2. 为什么说残差连接「给梯度留了高速公路」？从反向传播的角度解释。
> 反向传播经过 `y = x + f(x)` 这一层时，∂y/∂x = 1 + ∂f/∂x——那个常数 1 构成恒等通路：无论 f 的导数多小，梯度都能以不低于「原样通过」的强度继续往回传。
> N 层堆叠后，至少有一条路径的梯度衰减只与求和有关而非连乘——梯度消失被结构性消灭。这解释了为什么 Transformer 能叠 96 层而朴素深网络十几层就训不动。

> [!question]- 3. GPT 和 BERT 都基于 Transformer，为什么一个擅长聊天一个擅长搜索/分类？追溯到一处关键差异。
> 关键差异是**因果掩码的有无**（DL8 已铺垫）：GPT 加掩码只能看前文，天然适配「续写」式生成；BERT 双向全看，对「判断/理解」类任务是更充分的信息利用。
> 训练目标随之分化：预测下一词 vs 完形填空。所以选型口诀是「要生成就 decoder-only，只要理解可考虑 encoder」——一切差异的源头都是那一行上三角 −∞。

> [!question]- 4. 「创新不在零件而在组装」——这句话对你理解技术进步有什么启示？
> Transformer 的每个零件（注意力、MLP、残差、LayerNorm、正弦编码）都在 2017 年之前存在；突破在于判断出哪些是本质（注意力足以替代循环）、哪些可以舍弃（RNN 的递归约束），并把零件以正确的比例与顺序组装。
> 启示有三：① 组合式创新是技术演进的主流形态；② 判断力（敢删掉大家默认的东西）比发明力更稀缺；③ 深刻理解旧零件是做出新组装的前提——这正是本站坚持从神经元讲起的原因。
