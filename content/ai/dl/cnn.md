## 生活场景切入

人在看一张猫片时，眼睛并不会同时关注 100 万个像素——视线扫过轮廓、耳朵、胡须这些**局部小块**。而且识别「斜线」的能力不管用在图片左上角还是右下角都一样好。

深度学习的两大朴素洞察恰好对上：

```text
① 看局部就够了        → 局部连接（每个神经元只连一小块区域）
② 规律到处都一样      → 权重共享（同一个检测器扫遍全图）
```

把这两条焊在一起的结构就是**卷积神经网络（CNN）**——2012 年 AlexNet 凭它在 ImageNet 上一战封神，计算机视觉的天从此换了人间。

## 核心概念拆解

### 概念 1：先看全连接有多浪费

一张 100×100 的小图，接 512 个隐藏单元：

```text
全连接第一层参数 = 10000 × 512 ≈ 512 万
```

问题不只是多：

1. **浪费**：像素只在邻域内有意义，「左上角的像素」和「右下角的像素」直接连线毫无道理
2. **死板**：猫挪个位置，全连接网络眼里的输入模式完全变了，得重新学

CNN 的回答：每个神经元只看 3×3 或 5×5 的小窗口，且**整张图共用同一套权重**。

### 概念 2：卷积 —— 滑动的小模板

**卷积核（Kernel/Filter）** 是一个小矩阵（如 3×3），在图上从左到右、从上到下滑动；每停一处，对应位置相乘再求和，得到输出的一个格子。

手算一遍最经典的「竖直边缘检测」（实际运行结果）：

```python
img = [[0,0,0,255,255],
       [0,0,0,255,255],
       [0,0,0,255,255],
       [0,0,0,255,255],
       [0,0,0,255,255]]
kernel = [[-1,0,1],
          [-1,0,1],
          [-1,0,1]]

# 卷积输出尺寸 = 输入 − 核大小 + 1 = 5 − 3 + 1 = 3
for i in range(3):
    row = [sum(img[i+ki][j+kj]*kernel[ki][kj] for ki in range(3) for kj in range(3))
           for j in range(3)]
    print(row)
# [0, 765, 765]
# [0, 765, 765]
# [0, 765, 765]
```

解读这张 3×3 输出图：左边一列是 0（纯黑区域内没边缘），右边两列是 765（黑白交界处的强烈响应）——**模板「看见」了那条竖直边缘**。

关键账目：

```text
这个卷积层参数量 = 3×3 = 9 个
全连接做同样的事 = 25×9 = 225 个
100×100 图场景   = 9 vs 约 512 万    ← 五个数量级的差距！
```

而且这 9 个参数在整张图上复用——图片里的边缘出现在哪里都能被检出，**天生平移不变**。

### 概念 3：池化 —— 缩小地图保留要点

卷积之后通常接**池化（Pooling）**：把特征图切成小块，每块只留一个代表值。最大值池化（Max Pooling）最常用——「这块区域里最强的响应是什么」：

```python
big = [[1,3,2,4],
       [5,6,7,8],
       [3,2,1,0],
       [4,5,6,9]]

def maxpool(m):
    H, W = len(m), len(m[0])
    return [[max(m[i][j] for i in range(r, r+2) for j in range(c, c+2))
             for c in range(0, W, 2)] for r in range(0, H, 2)]

print(maxpool(big))
# [[6, 8], [5, 9]]     ← 4×4 变 2×2
```

池化的三重好处：数据量减半再减半、小幅平移不再影响结果（取 max 抹平抖动）、零参数（纯固定操作）。代价是丢失精确位置信息——但对「有没有猫」这种任务，位置本来就不重要。

### 概念 4：堆起来 —— 特征阶梯的完整形态

一层卷积只能测一种模式。真实 CNN 把「卷积→ReLU→池化」作为一个标准积木反复堆叠：

```text
输入图 (224×224×3)
  ↓ [Conv 3×3 ×64] → ReLU → Pool     学到：短边缘、颜色斑块
  ↓ [Conv 3×3 ×128] → ReLU → Pool    组合出：角落、纹理
  ↓ [Conv 3×3 ×256] → ReLU → Pool    组合出：眼睛、轮子等部件
  ↓ 展平 → 全连接 → softmax          综合判断：「这是金毛犬 87%」
```

三个值得注意的设计：

1. **通道数翻倍、分辨率减半**是常见节奏——空间细节换语义浓度
2. DL1 的「特征层级涌现」（边缘→部件→整体）在 CNN 里被原样观察到，且第一层卷积核画出来真的像各种方向的边缘检测器
3. 最后的全连接层负责「读图发言」，前面的卷积部分负责「看出名堂」

### 概念 5：为什么 CNN 曾统治视觉十年

| 能力              | 全连接     | CNN                   |
| ----------------- | ---------- | --------------------- |
| 参数量（百px 图） | 数百万     | 千级                  |
| 平移不变性        | 无         | 卷积+池化双重保证     |
| 训练数据需求      | 巨大       | 相对小得多            |
| 适用范围          | 表格类通用 | 图像/网格结构数据专精 |

2012–2021 年间几乎所有视觉记录都是 CNN 刷的（AlexNet → VGG → ResNet）。2020 年后 Transformer 开始入侵视觉（ViT，DL9 见），但 CNN 仍是小数据、端侧部署场景的首选——**理解 CNN 就是理解「结构先验」这个大主题的最佳案例**：把「图像该有哪些规律」直接写进架构，模型就能用更少的数据学到更好的表征。

## 自测一下

> [!question]- 1. 一张 32×32 的图经过 3×3 卷积（无填充），输出多大？加上 padding=1 呢？
> 无填充：(32−3+1)² = **30×30**——每卷一次缩一圈。
> padding=1：在四周补一圈零变成 34×34 再卷，输出 (34−3+1)² = **32×32**，尺寸保持不变。
> 这就是实践中几乎总用 padding=1 的原因：让卷积层专心提特征、不偷偷改图幅，尺寸控制权交给池化层。

> [!question]- 2. 为什么说「卷积+池化」组合实现了平移不变性？各自贡献了什么？
> **卷积贡献平移等变**：猫往右挪三像素，特征图上的响应也跟着右移三像素——位置变了但图案还在。
> **池化贡献不变性**：2×2 取最大值时，响应在小范围内挪动一格根本不影响取出的那个数——位置差异被抹掉了。
> 两级配合后，「图中某处有耳朵尖」这个事实无论出现在哪个角落都会触发同一个下游神经元。严格地说不变性是多级池化累积出来的近似，浅层只有等变性。

> [!question]- 3. 一个 5×5 图配 3×3 核只有 9 个参数，但它能检测的边缘种类是不是太少了？怎么获得丰富的特征？
> 单个核确实只会一种模式——所以每一层都并行放**几十上百个不同的核**（比如 64 个），每个学出一种偏好的模式，产出 64 张特征图叠成 64 通道。
> 更妙的是这些核不是人设计的，是训练学出来的：初始化随机，反向传播自动把它们雕成「竖边」「圆弧」「斑点」等各司其职的检测器。**多样性靠数量，专业性靠训练。**

> [!question]- 4. 医疗影像数据往往只有几千张标注图，直接训 CNN 容易过拟合。给出两条符合本课思想的缓解思路。
> ① **迁移学习**（DL10 正式讲）：拿在百万张图上预训练过的 ResNet，冻结前面学过通用边缘纹理的层，只用几千张微调最后几层——把「大数据学通用、小数据学专业」落到实处。
> ② **数据增强**：随机翻转/旋转/调亮训练图——利用 CNN 的平移（旋转）特性免费扩充样本多样性，压制 ML4 的背题倾向。
> （加分思路：更小的网络或加正则——医疗任务不需要 ImageNet 级容量。）
