## 生活场景切入

你的脑子里有大约 860 亿个细胞在同时做一件事：**接收信号 → 累积 → 够强就放电**。

```text
树突（收信号）→ 细胞体（累积）→ 超过阈值？→ 轴突（放电传给下一个）
```

每个单独的神经元蠢得可怜——它只会做「加一加、够数就喊」这一件事。但 860 亿个这样的零件连接起来，就有了你。深度学习赌的就是同一个命题：

> **简单的单元 × 海量的连接 × 分层的组织 = 智能**

1943 年，McCulloch 和 Pitts 把这个过程抄成了数学；1958 年 Rosenblatt 做出感知机——人工智能的第一缕曙光。本课就从这里开始。

## 核心概念拆解

### 概念 1：神经元的数学模型 —— 加权投票器

把上面的流程逐句翻译：

| 生物动作     | 数学动作                     | 记号            |
| ------------ | ---------------------------- | --------------- |
| 树突收信号   | 输入乘上权重（信号有强有弱） | `w₁x₁, w₂x₂ …`  |
| 细胞体累积   | 全部加起来，再加个基础偏好   | `z = Σwᵢxᵢ + b` |
| 超阈值才放电 | 过一个非线性函数决定输出强度 | `a = σ(z)`      |

完整公式一行写完：

```text
a = σ(w·x + b)        与 ML2/ML3 的 wx+b 完全同构！
```

发现了吗？**一个神经元就是一个迷你逻辑回归**。权重 w 表示「这个输入有多重要」，偏置 b 表示「这个神经元整体多容易被激活」。

用「要不要出门」做个直观演示（实际运行结果）：

```python
import math

def neuron(x, w, b):
    z = sum(xi*wi for xi, wi in zip(x, w)) + b
    return 1 / (1 + math.exp(-z))

# 特征：(天气好, 有空)；天气好更重要 → 权重更大
w, b = [3.0, 2.0], -4.0
for x in [(1,1), (1,0), (0,1), (0,0)]:
    print(f"{x} → 出门意愿 {neuron(x, w, b):.4f}")
# (1,1) → 0.7311 | (1,0) → 0.2689 | (0,1) → 0.1192 | (0,0) → 0.0180
```

天气好权重 3.0 > 有空权重 2.0，所以「好天气但没空」（0.27）比「有空但天气差」（0.12）更可能出门——**权重就是神经元的价值取向**。

### 概念 2：激活函数 —— 非线性的灵魂

σ 只是最常见的选项之一。三大主流选手对比（数值表为实际计算结果）：

```text
x:        −3      −1      0       1       3
ReLU:      0       0      0       1       3      ← 小于 0 一刀切零，其余原样放行
sigmoid:  0.047   0.269   0.5    0.731   0.953  ← S 形挤压进 (0,1)
tanh:    −0.995  −0.762   0      0.762   0.995  ← S 形但关于原点对称，范围 (−1,1)
```

| 函数    | 输出范围 | 优点                 | 缺点                       | 典型位置         |
| ------- | -------- | -------------------- | -------------------------- | ---------------- |
| ReLU    | [0, +∞)  | 计算飞快、正区不饱和 | 负区梯度恒为零（死神经元） | 隐藏层默认       |
| sigmoid | (0, 1)   | 天然概率含义         | 两端饱和→梯度消失          | 输出层（二分类） |
| tanh    | (−1, 1)  | 零中心               | 同样两端饱和               | 老式网络隐藏层   |

现代隐藏层的默认选择是 **ReLU**（Rectified Linear Unit）：`max(0, x)`。简单到不像数学，却解决了深层网络的训练难题——2012 年 AlexNet 的功臣之一。

### 概念 3：没有非线性，层数再多也白搭

这是本课最重要的思想实验。假如不用任何激活函数，直接堆两层线性变换会怎样？（NumPy 实测）：

```python
W2 @ (W1 @ x) == (W2 @ W1) @ x
# 两层线性叠加 = 一个新矩阵 W' = W2@W1，还是线性！
# 实测：[2.66] == [2.66]
```

无论叠多少层，效果都等价于**一层**——因为矩阵乘法的结合律把所有层折叠了。sigmoid、ReLU 这些「弯折」才是让网络拥有表达任意曲线的能力的来源：每一层的非线性弯折都在空间上「揉」一次数据，揉的次数多了，再纠缠的分类问题也能被揉开。**深度（Deep）这个词，指的就是这种层层揉捏的结构。**

### 概念 4：分层 = 概念的抽象阶梯

单个神经元只能画一条直线边界。但把它们组织成层，就能学到层级化的概念——以认猫为例（B1 伴学页的可视化正是这个结构）：

```text
第 1 层（边缘检测器）：「这里有条斜线」「那里有个圆弧」
第 2 层（部件组合器）：「斜线+圆弧=耳朵」「圆弧+圆弧=眼睛」
第 3 层（整体判断器）：「耳朵+眼睛+胡须 → 猫！」
```

低层学局部特征，高层学抽象组合——这个现象后来在训练好的真实网络中被反复观察到。有趣的是没人规定第一层必须学边缘：**层级抽象是从数据中自发涌现的**，这正是深度学习最迷人的地方。

### 概念 5：XOR 危机 —— 单层的死穴（下一课的悬念）

1969 年 Minsky 和 Papert 在书里证明：单层感知机连 XOR（异或）都学不会。XOR 的四个样本在平面上对角分布，任何一条直线都无法分开它们——而单层神经元只会画直线。

```text
(0,0)→0   (1,1)→0        ○ ○ 对角同类
(1,0)→1   (0,1)→1        ● ● 另一对角
                          直线怎么摆都要切错
```

这个打击直接导致了第一次 AI 寒冬。破局的关键其实早就写在概念 3 里：**加一层隐藏层，两次弯折就能把平面揉出一条弯曲的边界**。两层网络如何通过链式法则学会自我纠正——这就是 DL2 反向传播的故事。

## 自测一下

> [!question]- 1. 一个神经元和 ML3 的逻辑回归是什么关系？
> 数学上完全同构：都是 `σ(wx+b)`。
> 视角差异：「逻辑回归」是把整个模型当做一个分类器来用；「神经元」是把它当做更大网络的一个零件。深度学习可以理解为**把几百万人见人爱的逻辑回归焊在一起，让它们的输出互相喂养**——ML3 学的东西一点没浪费。

> [!question]- 2. 为什么 ReLU 比 sigmoid 更适合深网络的隐藏层？至少说出两条理由。
> ① **梯度健康**：sigmoid 导数最大只有 0.25，深层反向传播时层层缩水（10 层连乘 ≤ 10⁻⁶，实测验证），梯度消失让远处的层几乎学不到东西；ReLU 正区导数恒为 1，信号不衰减。
> ② **计算便宜**：max(0,x) 是一次比较，sigmoid 要算指数。
> ③ **稀疏激活**：一半左右的神经元输出为零，网络更高效且有一定抗过拟合作用。
> （代价是负区导数为零可能导致「死神经元」，工程上有 Leaky ReLU 等变体补救。）

> [!question]- 3. 「两层线性网络等价于一层」的证明依赖哪条代数性质？这说明什么？
> 依赖**矩阵乘法结合律**：`W2(W1·x) = (W2·W1)·x`，两个矩阵先乘成一个新矩阵，多层塌缩成单层。
> 这说明线性运算的复合仍是线性的——**表达能力不会因为堆叠线性层而增强**。非线性的价值正在于它破坏了这种折叠性：σ(W2·W1·x) 无法合并成一个矩阵，每多一层就多一分表达力。这也是「深度」二字真正的技术含量所在。

> [!question]- 4. 认猫例子说「第一层学边缘、第二层学部件」。这是工程师设计好的吗？如果不是，怎么验证这种层级真的存在？
> 不是设计好的——训练时没有任何地方告诉网络「第一层该看边缘」，这些分工完全是从数据中自发涌现的。
> 经典验证方法：把训练好的卷积网络的第一层权重直接画成图像，会发现它们长得像各种方向的边缘检测器（与视觉神经科学的发现惊人一致）；更高层则可以用「最大化激活该神经元的输入图案」来可视化，能看到眼睛、纹理等部件级图案。**结构与任务对齐，但没有设计师**——涌现（emergence）是深度学习最深的魅力。
