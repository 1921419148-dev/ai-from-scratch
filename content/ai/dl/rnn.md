## 生活场景切入

「今天天气不错，我心情也」——补全这句话的空格，你几乎不需要思考。

但注意：填什么完全取决于**前文**。如果前面是「今天天气糟糕透了」，同样的句式你会填不同的词。处理这种任务的网络必须携带一个**对已读内容的记忆**——而 CNN 和全连接网络都是「一次吃完所有输入、内部无状态」的结构，天生没有这个能力。

文本、语音、股价、传感器数据……世界上大量数据是**序列**。RNN 就是第一个为序列量身定做的深度结构。

## 核心概念拆解

### 概念 1：RNN 的核心动作 —— 状态接力

普通网络一层用一批权重；RNN 的绝妙之处是**同一个单元沿时间轴反复登场**：

```text
h₁ = tanh(Wx·x₁ + Wh·h₀ + b)      ← 当前输入 + 上一刻的记忆 → 新记忆
y₁ = Why·h₁ + by                   ← 用新记忆做预测
```

- `h`（hidden state 隐藏状态）就是网络的「工作记忆」：每读入一个词更新一次
- `Wx` 管「新来的输入怎么影响记忆」，`Wh` 管「旧记忆怎么保留下来」——**两组权重在所有时间步共享**
- 参数量与序列长度无关：读 10 个字和读 1000 个字用的是同一套网络

### 概念 2：训练 —— 沿时间轴展开的反向传播

把 RNN 沿时间展开，就是一个「每一层共享权重的超深网络」，DL2 的反向传播原样适用：

```text
x₁ → h₁ → y₁
          x₂ → h₂ → y₂        展开后从最后一个时间步
               x₃ → h₃ → y₃   倒着把误差传回第一步（BPTT）
```

工程上的妥协叫**截断式 BPTT（TBPTT）**：只往回传固定步数（如 32 步），更远的过去不再追责——省显存省计算，代价是学不到特别长的依赖。

### 概念 3：实战 —— 教 RNN 背出 abc 循环

最小的序列学习任务：「abcabcabc…」里预测下一个字符。三分类问题，一个字符一个字符喂进去（完整训练代码约 50 行纯 Python；实际运行结果）：

```python
# 结构：one-hot(3) → 隐藏层(tanh, H=6) → softmax(3)
# 关键行：h_new = tanh(Wx·x + Wh·h_old + b)   ← 记忆更新
#         y    = Why·h_new + by                ← 输出

epoch 125: loss/char = 0.0005
epoch 500: loss/char = 0.0001
next-char accuracy: 1.000     ← 完美掌握 abc 循环！
```

模型学会了什么？它记住了「我刚读过 a」这件事藏在 h 里，于是输出层知道该押 b；读到 b 后 h 更新为「刚读过 b」，接着押 c……**隐藏状态就是它对上下文的全部理解**。

这个玩具展示了 RNN 的标准用法——**语言建模（language model）**：给定前文预测下一个词。GPT 的核心任务与此完全相同，只是规模大了七个数量级、结构换成了 DL9 的 Transformer。

### 概念 4：长程依赖 —— RNN 的阿喀琉斯之踵

理论很美，现实骨感。BPTT 把误差传回 100 步之前时会发生什么？

```text
∂L/∂h₁ ∝ (Wh 的连乘)^100 × (tanh 导数的连乘)^100

tanh 导数 ≤ 1，Wh 特征值通常 < 1 → 连乘一路缩水 → 梯度消失
个别大特征值 → 连乘爆掉 → 梯度爆炸
```

这与 DL1 讲过的「深网络梯度消失」同根同源，但在 RNN 里更致命：时间步数可以成百上千，等价于上千层的网络。后果是 RNN 只记得最近的事——让它记住 200 字前的伏笔，基本指望不上。

**补救方案谱系**：

| 方案        | 一句话                     | 出场年份 |
| ----------- | -------------------------- | -------- |
| LSTM        | 加「门控」决定记什么忘什么 | 1997     |
| GRU         | LSTM 的简化版，效果相近    | 2014     |
| 注意力机制  | 干脆允许直接回看任意位置   | 2014→    |
| Transformer | 彻底抛弃循环，全靠注意力   | 2017     |

LSTM 的门控思想值得体会：它给每个记忆单元装了三个阀门（输入门/遗忘门/输出门），阀门本身也是可学习的——「该记多久」变成了可以从数据中学到的技能。这条改进路线统治了 2014–2017 年的 NLP，直到 DL9 的故事开场。

## 自测一下

> [!question]- 1. RNN 与全连接网络最本质的区别是什么？参数量上有什么有趣差异？
> 本质区别：RNN **跨时间步共享权重且有隐藏状态**——同一个变换反复应用于序列每个位置，并把上一刻的结果喂给下一刻。
> 有趣差异：全连接的参数量由输入维度决定，而 RNN 的参数量与序列长度无关——读一句诗和读一本小说用同一套参数。「共享 + 复用」正是它能处理任意长度序列的原因。

> [!question]- 2. 为什么说「语言建模」是最重要的预训练任务之一？本课的 abc 实验和 GPT 是什么关系？
> 因为「预测下一个词」不需要人工标注——互联网上任何文本天然就是训练样本（前文是输入，后一个词是免费标签）。要把它做好，模型被迫理解语法、事实常识甚至推理。
> abc 实验=字符级语言建模的最小版本；GPT=同一任务放大到数千亿参数+万亿 token。**任务一模一样，规模天差地别**——DL11 会讲为什么「只是变大」就能涌现出惊人能力。

> [!question]- 3. 截断式 BPTT 牺牲了什么？举一个会被牺牲的具体场景。
> 牺牲了超出截断窗口的长程梯度。具体场景：小说第 3 章「主角左撇子」的设定影响第 20 章持刀动作的合理性——若两处相距超过截断长度（如 512 token），误差信号无法跨越这段距离告诉模型「记住这个设定有用」。
> 缓解手段：加大截断窗口（费显存）、层次化状态、或改用注意力机制让任意两个位置直接连线（DL8）。

> [!question]- 4. LSTM 的「遗忘门」解决的是 RBN 的哪个具体病灶？用一句话解释它的机制。
> 解决「记忆被无情冲刷」：朴素 RNN 每个 time step 都要用 tanh 重写整个隐藏状态，久远信息在连乘中被稀释殆尽。
> 遗忘门的机制一句话：**用一个可学习的 sigmoid 阀门控制「上一刻细胞状态的保留比例」（0~1 乘上去）**——想长期保存的信息可以让阀门保持接近 1，梯度得以近乎无损地穿越上百个时间步。这就是「长短期记忆」名字的含义。
