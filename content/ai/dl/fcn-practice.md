## 生活场景切入

ML3 的逻辑回归画直线边界，很够用——直到数据长成两个交错的月牙：

```text
        ☾ 上弦月（类1）
   ☽ 下弦月（类0）

任何一条直线都切不开这对月牙 —— 线性模型的天花板
```

这是检验「非线性力量」的经典试金石：**同一个数据，逻辑回归卡在 90% 附近上不去；两层网络轻松逼近 100%**。本课用 60 行纯 Python 走完全程，每一行都对应你已经掌握的知识。

## 核心概念拆解

### 概念 1：造数据 —— 月牙的手工生成

```python
import random, math
random.seed(7)

n = 100
data = []
for _ in range(n):                       # 上弦月：半径 1 的上半圆弧
    t = math.pi * random.uniform(0, 1)
    data.append(([math.cos(t), math.sin(t)], 1))
for _ in range(n):                       # 下弦月：翻转+下移，形成交错
    t = math.pi * random.uniform(0, 1)
    data.append(([1-math.cos(t), 0.5-math.sin(t)+0.35], 0))
random.shuffle(data)
```

200 个点、两个特征、标签 0/1。数据无噪声时任务干净利落；把噪声调大自然出现 ML4 的过拟合戏码。

### 概念 2：搭网络 —— 与 DL1/DL2 逐件对应

```text
输入层(2) → 隐藏层(16, ReLU) → 输出层(1, sigmoid)

参数量：(2×16+16) + (16×1+1) = 48 + 17 = 65 个
```

为什么是 16 个隐藏单元？经验起点：任务越扭越宽。太少（如 2 个）表达力不够，太多容易过拟合且慢——**这个旋钮没有公式，靠验证集说话**（ML9）。

### 概念 3：训练 —— 反向传播的最后一场手工秀

纯 NumPy/Python 实现（完整可跑，数字为真实输出；PyTorch 等价版见 DL3 五件套）：

```python
H = 16
W1 = [[random.gauss(0, 0.5) for _ in range(2)] for _ in range(H)]
b1 = [0.0]*H
W2 = [random.gauss(0, 0.5) for _ in range(H)]
b2 = 0.0
lr = 0.05

idx = list(range(len(data))); random.shuffle(idx)
tr, te = idx[:160], idx[160:]            # 80/20 划分，先切后看！

for epoch in range(300):
    total_loss = 0.0
    for k in tr:
        x, t = X[k], Y[k]
        # 前向（ReLU 隐藏层）
        h_pre = [sum(W1[j][i]*x[i] for i in range(2)) + b1[j] for j in range(H)]
        h = [max(0, v) for v in h_pre]
        o = 1/(1+math.exp(-sum(W2[j]*h[j] for j in range(H)) + b2))
        loss = -(t*math.log(o+1e-12) + (1-t)*math.log(1-o+1e-12))   # 交叉熵
        # 反向（ReLU 导数：pre>0 时为 1 否则 0）
        d_o = -(t - o)
        d_h = [d_o*W2[j]*(1 if h_pre[j] > 0 else 0) for j in range(H)]
        # 更新（梯度下降）
        for j in range(H):
            W2[j] -= lr*d_o*h[j]
            W1[j][0] -= lr*d_h[j]*x[0]; W1[j][1] -= lr*d_h[j]*x[1]
            b1[j] -= lr*d_h[j]
        b2 -= lr*d_o

epoch   60: avg loss = 0.0243
epoch  300: avg loss = 0.0027
train acc = 1.000     test acc = 1.000
```

逐段对照你的存货：

| 代码片段                 | 出身            |
| ------------------------ | --------------- |
| `max(0, v)`              | DL1 ReLU        |
| 交叉熵 loss              | ML3/DL2         |
| `d_o = -(t-o)`           | ML3 梯度化简    |
| `1 if h_pre[j]>0 else 0` | ReLU 的局部导数 |
| `w -= lr*grad`           | M7 梯度下降     |
| 先切 tr/te               | ML4 纪律        |

### 概念 4：ReLU 为什么赢了 sigmoid —— 亲手换掉试试

把隐藏层激活换成 sigmoid 再训一次（其余不变），典型现象：

```text
sigmoid 隐藏层: 收敛明显变慢，同样的 epoch 数损失常停在 0.1~0.3 区间徘徊
ReLU 隐藏层:    60 轮内损失已压到 0.02 量级
```

原因正是 DL1 的预告：sigmoid 局部导数 ≤ 0.25 且两端饱和，反向传播时每层缩水一次；ReLU 正区导数恒为 1，责任原封不动地传回第一层。**层数越深差距越大**——这也是 2012 年后深度学习爆发的技术前提之一。

### 概念 5：决策边界可视化 —— 看见网络「想」了什么

把平面每个点的预测值算出来涂色，会看到边界是一条平滑弯曲的 S 形曲线，精确地从两个月牙之间穿过。对比逻辑回归的直线边界被月牙拦腰截断的样子，「非线性表达力」从抽象名词变成了看得见的图。

更进一步的玩法（DL5 的伏笔）：把隐藏层 16 个神经元各自的「激活热区」画出来——你会发现它们各自负责边界的一小段，像拼图一样合体成完整曲线。**分工是涌现的，没人指定过。**

## 自测一下

> [!question]- 1. 把隐藏单元数从 16 改成 2 会发生什么？改成 512 呢？
> 2 个隐藏单元只有两次弯折机会，月牙这种双弧边界可能切不干净（欠拟合方向，测试准确率掉到 95% 甚至更低）。
> 512 个单元对这个小任务属于大炮打蚊子：能学但参数 8 千多个而样本只有 320 个——按 ML4 的剧本，测试误差开始对随机种子敏感，个别种子下过拟合显现。
> 经验法则：从「任务复杂度 × 10」量级起试，让验证集裁决。

> [!question]- 2. 本课示例 train/test 都是 100%，怎么知道模型不是在背题？
> 三重证据：① 数据划分前做了 shuffle 且测试集全程未参与梯度更新；② 测试点覆盖整个月牙区域而非训练点的复制；③ 可以做终极检验——生成一批全新种子的月牙喂进去（本站读者可以动手试），新样本上的表现才是泛化的金标准。
> 这也是 ML9 的提醒：100% 在合成数据上并不罕见，别把它当成「完美模型」的同义词。

> [!question]- 3. 学习率 lr=0.05 是怎么定的？如果改成 5 或 0.00001 各会发生什么？
> 定法：以 0.1 为中心做数量级扫描（0.001/0.01/0.1），选收敛最快且稳定的，再微调——就是 ML9 说的超参数搜索的土办法。
> lr=5：步子太大冲过谷底，损失剧烈震荡甚至 nan（M7 的发散现场）。
> lr=0.00001：每步挪一丝，300 轮结束时损失还在半山腰（磨洋工）。
> 现代做法是用 Adam 优化器（自适应步长，DL12 详谈）减少手调负担。

> [!question]- 4. 这个网络有多少参数？如果输入是一张 100×100 的图片呢？这说明了什么问题？
> 现在：48+17=65 个参数，轻松愉快。
> 100×100 图片直接展平 = 10000 维输入，接 512 个隐藏单元的第一层就有约 512 万参数——参数爆炸。
> 说明全连接结构对图像**不经济**：它不知道「相邻像素有关联」「平移不变的规律」。解决这两个浪费的正是 DL5 卷积神经网络——用「局部连接+权重共享」把百万参数砍回几千。
