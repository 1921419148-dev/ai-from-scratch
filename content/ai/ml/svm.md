> [!abstract] 本课将学到
>
> - **SVM 的核心思想**：分界线不只要分开两类，还要**离两边都尽量远**
> - **支持向量（Support Vector）**：决定边界的那几个关键样本——其他点都可以扔掉
> - **软间隔（Soft Margin）**：允许少量犯错，换取整体更稳
> - **核技巧（Kernel Trick）**：数据线性不可分？换个坐标系变魔术
> - 小数据集上的对偶求解演示，亲眼看到支持向量浮出水面

## 生活场景切入

在马路中间画一条中线，让两侧的车流各行其道。两条画法都能「分开」车流：

```text
画法 A：紧贴左车道边缘画线     —— 分开了，但右边的车稍微偏一点就越界
画法 B：正中间画线             —— 两边都有最大的缓冲区
```

显然 B 更安全。**SVM 就是坚持画法 B 的算法**：它不只要求分开两类，还要求分界线到两类的最近距离（间隔 margin）最大化。

```text
 ●●●                    ● = 正类
 ●●●   ↕ 缓冲带  ┊  ↕ 缓冲带
                ┊        ○○○
                ┊       ○○○    ○ = 负类
        最宽的路 ← 这就是 SVM 选的线
```

## 核心概念拆解

### 概念 1：支持向量 —— 真正说了算的少数派

「离两边最近的那些样本」有个专名——**支持向量（Support Vector）**。分界线的位置完全由它们决定；把其他所有样本删掉，重新训练，得到的边界一模一样。

用一个小实验亲眼看它们浮出来。对称的两类数据 `正类 {(2,2),(3,3),(3,1)}`、`负类 {(-2,-2),(-3,-1),(-2,-3)}`，用简化对偶算法求解 SVM（Python 实际运行结果）：

```python
# 数据与核矩阵准备（线性核 K(i,j) = xi·xj）
pos = [(2,2),(3,3),(3,1)]
neg = [(-2,-2),(-3,-1),(-2,-3)]
data = [(p,1) for p in pos] + [(n,-1) for n in neg]
n = len(data)
K = [[sum(data[i][0][k]*data[j][0][k] for k in range(2)) for j in range(n)] for i in range(n)]
y = [lab for _, lab in data]

# 对偶问题的简化投影梯度上升
alpha = [0.0]*n; C = 10; lr = 0.001
for _ in range(20000):
    grad = [1 - sum(alpha[j]*y[j]*K[i][j] for j in range(n))*y[i] for i in range(n)]
    for i in range(n):
        alpha[i] = min(C, max(0.0, alpha[i] + lr*grad[i]))

w1 = sum(alpha[i]*y[i]*data[i][0][0] for i in range(n))
w2 = sum(alpha[i]*y[i]*data[i][0][1] for i in range(n))
sv = [i for i in range(n) if alpha[i] > 1e-4]

print(f"w = ({w1:.3f}, {w2:.3f})")
print(f"支持向量个数: {len(sv)} / {n}，它们的 α = {[round(alpha[i],3) for i in sv]}")
print(f"决策边界: x₂ = {-w1/w2:.3f} · x₁")
# w = (0.250, 0.250)
# 支持向量个数: 2 / 6，它们的 α = [0.062, 0.062]
# 决策边界: x₂ = -1.000 · x₁      即 x₁+x₂=0，正是两团数据的对称中线！
```

三个观察：

1. **6 个样本里只有 2 个成为支持向量**——其余 4 个的 α=0，删掉也不影响边界
2. 边界 `x₁+x₂=0` 正是两团数据的对称中线——「最宽的路」找到了
3. 直觉核对：支持向量必然是每类里**最靠近对方阵营**的点（这里是 (2,2) 与 (-2,-2) 一线哨兵），远处的点毫无发言权

### 概念 2：为什么「宽」就是好

窄边界的模型在贴着某类样本画线——训练集里任何一个点轻微晃动（新设备采集误差、测量噪声），边界就得大幅摆动。宽边界则对样本扰动钝感。

用 ML4 的语言说：**最大化间隔 = 控制模型复杂度 = 一种内置的正则化**。SVM 从设计源头就把「泛化优先」写进了目标函数，这是它与逻辑回归最大的气质差异：

|              | 逻辑回归               | SVM                                   |
| ------------ | ---------------------- | ------------------------------------- |
| 关心什么     | 每个样本的概率都尽量准 | 只关心边界附近的少数派                |
| 输出         | 概率（可解释置信度）   | 类别 + 到边界的距离（概率要额外校准） |
| 天然抗过拟合 | 需要正则化帮忙         | 最大间隔自带正则化                    |

### 概念 3：软间隔 —— 允许少数人犯错

现实数据总有噪声和重叠。硬逼着一条线分开所有样本，会得到一条被离群点绑架的扭曲边界。**软间隔（Soft Margin）** 引入松弛变量：「大部分点守规矩即可，个别越界的交罚款」：

```text
minimize  ½‖w‖²  +  C × Σ 违规量
          ↑想要宽路    ↑犯错总额，C 是罚款单价
```

C 大 → 容不得任何错误 → 接近硬间隔（可能过拟合）；C 小 → 无所谓错误 → 边界更平滑（可能欠拟合）。C 是 SVM 版的学习率级超参数，ML9 会讲怎么系统地调它。

### 概念 4：核技巧 —— 搬不起山，就搬自己

同心圆数据（内圈一类外圈一类）任何直线都切不开。SVM 的解法华丽得违反直觉：

**把数据搬到更高维空间，在那里它们就线性可分了。**

一维例子秒懂：`{-1, 1}` 分不开？加一个特征变成二维 `{(-1,1),(1,1),(0,-1)}`——横着切一刀完事。常用的升维函数（比如 `x → (x, x²)`）就叫**核（Kernel）**。

```text
原始空间（切不开）：          升维后（随便切）：

 ○ ● ○                        │
 ○ ● ○  ← 一条线怎么切？      ○│○ ●│●
                              ○│○ ●│●
                                └──── 一刀两断 ✓
```

**魔法在于**：SVM 的推导里所有计算都以「样本对的点积」形式出现，而高维空间的点积可以用原空间的函数直接算出——根本不用真的执行升维！这就是**核技巧**，让 SVM 在亿维空间里跑出了低维的速度。常用核：多项式核、RBF 高斯核（默认万金油）、文本相似度核。

### 概念 5：SVM 在今天的位置

诚实地说：深度学习时代，SVM 已退出图像/文本等感知任务的主战场。但它仍是值得学的模型：

- **小数据 + 高维特征的经典场景**依然是它的天下（基因数据：几千样本 × 几十万特征）
- 「最大间隔」「对偶」「核方法」是机器学习理论的基石概念，后面 NLP 板块的老牌词向量时代处处有它的影子
- 它是「从几何视角做分类」的最佳教材——与逻辑回归的概率视角互补

## 自测一下

> [!question]- 1. 把训练集中远离边界的所有样本删除再重新训练 SVM，边界会变吗？换成逻辑回归呢？
> SVM：**不会变**。边界只由支持向量决定，远处的点对 w 和 b 的贡献为零。
> 逻辑回归：**会变**。它的损失累及每一个样本——每个点的概率都被推着往 1 或 0 走，删掉任何点都会轻微改变参数。
> 这个对比是两种模型气质差异的极致展示：SVM 只看「边界形势」，逻辑回归「人人有份」。

> [!question]- 2. C 调得非常大（如 10⁶）会发生什么？非常小呢？
> C 极大 → 罚款单价天价，模型宁可把边界扭成麻花也要分对所有训练样本 → 接近硬间隔，噪声敏感，**过拟合风险大**。
> C 极小 → 罚款约等于免费，模型躺平乱画，连明显可分的错也懒得纠正 → **欠拟合**。
> 这是又一个 ML4 教科书案例：一个旋钮同时控制着过拟合与欠拟合的两端，调参就是在两端之间找平衡。

> [!question]- 3. 核技巧为什么「不用真的升维」也能享受升维的好处？
> 因为 SVM 的对偶推导中，算法需要的全部信息只是**样本对之间的点积 ⟨xi, xj⟩**，从来不需要单个样本自己的坐标。
> 设升维映射为 φ，数学上存在函数 K 使得 K(xi,xj)=⟨φ(xi),φ(xj)⟩——直接算 K 往往比先算 φ 再点积便宜几个数量级（RBF 核一行公式 vs 亿维向量运算）。哪里用到点积就在哪里替换，其余照旧——这是机器学习史上最优雅的偷懒。

> [!question]- 4. 手头有一份「500 个病人 × 20000 个基因表达值」的数据要做良恶性判断，你会选逻辑回归、随机森林还是 SVM？理由？
> 首选 **SVM（线性核或 RBF）**。理由：
> ① 样本少（500）而维度极高（20000）——这正是 SVM 的主场，最大间隔在高维下依然稳健；
> ② 基因数据的判别信号常是非线性组合，RBF 核能捕捉；
> ③ 深度学习在这种「n≪p」（样本数远小于特征数）场景极易过拟合且需要海量数据；随机森林可用但高维稀疏下的表现通常逊于 SVM。
> （加分项：基因学界确实长期使用 SVM 做这类任务，属于行业实证。）
