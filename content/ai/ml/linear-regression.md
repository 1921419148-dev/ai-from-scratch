> [!abstract] 本课将学到
>
> - **线性回归（Linear Regression）**：用一条直线 `y = wx + b` 描述两个变量的关系
> - **损失函数（Loss Function）**：怎么量化「这条线画得不好」——均方误差 MSE
> - 两种求最优解的方法：**最小二乘公式**（一步到位）与**梯度下降**（逐步逼近，M7 正式上岗）
> - R²：这条线解释了多少规律？
> - 完整代码：从生成数据到做出预测

## 生活场景切入

中介说：「这片儿的房子，每平米大概值 8000，另外每套都有 50 万的底价。」

这句话翻译成数学就是一条直线：

```text
价格（万） = 0.8 × 面积（㎡） + 50
```

80 平的房子该卖多少？`0.8 × 80 + 50 = 114 万`。你看，「预测」其实没那么神秘——只要知道**斜率**（每平米单价 w）和**截距**（底价 b），任何面积都能算。

但问题来了：中介是怎么知道「0.8」和「50」的？他是看过很多套成交房之后**估**出来的。机器学习做的事一模一样：给它一堆成交记录，让它自己把最合适的 w 和 b 找出来。这个「找」的过程就叫**训练**。

## 核心概念拆解

### 概念 1：模型 —— 一条有两个旋钮的直线

```text
ŷ = wx + b        读作「y hat」，帽子表示「模型的预测值」（区别于真实值 y）
```

- `w`（weight 权重）：斜率——x 每增加 1，预测值变化多少
- `b`（bias 偏置）：截距——x 为 0 时的基础值

训练前 w、b 是未知数；训练后它们就是「模型学到的知识」。**一个线性回归模型的全部智慧就是这两个数**——简单，但麻雀虽小五脏俱全：后面深度学习的几亿参数，本质也是同样的角色。

### 概念 2：损失函数 —— 给「画歪了」定价

有了数据，怎么判断哪条线更好？定义一个打分器：

```text
MSE（Mean Squared Error，均方误差）
       1    n
MSE = ── Σ (yᵢ − ŷᵢ)²
       n   i=1
```

逐字翻译：「每个样本的真实价减预测价（误差），平方后取平均」。M1 讲过平方的作用——放大大的错误且抵消正负；现在它正式上岗：**误差越大惩罚越重，且方向无关紧要**。

| 真实 y | 预测 ŷ | 误差 | 平方 |
| ------ | ------ | ---- | ---- |
| 110    | 100    | +10  | 100  |
| 130    | 140    | −10  | 100  |

正负相消是绝对不行的（那会显得完美无错），平方解决了这个问题。

于是「找最好的线」变成了一个纯数学命题：

```text
minimize  L(w, b) = MSE(w, b)
```

**这就是优化问题的标准长相**——M2 解方程找未知数，这里找的是让损失最小的参数。

### 概念 3：方法一 —— 最小二乘公式（一步登天）

对 L 分别求偏导并令其为零（M6 的极值思想：导数为零处是谷底），解方程组，得到闭式解：

```text
w* = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²        （协方差 ÷ 方差，M10 的亲戚）
b* = ȳ − w*x̄
```

不需要背公式——需要记住的是它的含义：**存在一条数学上「最优」的线，而且可以直接算出来**。

### 概念 4：方法二 —— 梯度下降（AI 的通用套路）

最小二乘公式漂亮但有个致命局限：只对线性回归这类特殊形状成立。深度学习的损失面复杂无比，没有现成公式——那时唯一的手段就是 M7 的梯度下降：

```text
重复：
  w ← w − η · ∂L/∂w
  b ← b − η · ∂L/∂b
```

实战中必须先**归一化特征**（比如把面积缩到 0~1 区间），否则 x 的量纲太大会让损失面又细又长，梯度下降寸步难行或直接发散。这是第一个「工程细节决定成败」的现场。

### 概念 5：完整实战 —— 两种方法殊途同归

生成 100 套房子的模拟成交数据（真实价格规律是 `0.8x + 50` 加噪声），看算法能否自己找回答案（以下数字均为 Python 3.13 实际运行结果）：

```python
import random
random.seed(42)

# ① 数据：面积 50~150㎡，价格 = 0.8x + 50 + 噪声
xs = [random.uniform(50, 150) for _ in range(100)]
ys = [0.8*x + 50 + random.gauss(0, 5) for x in xs]
n = len(xs)
mx, my = sum(xs)/n, sum(ys)/n

# ② 方法一：最小二乘闭式解
w = sum((x-mx)*(y-my) for x, y in zip(xs, ys)) / sum((x-mx)**2 for x in xs)
b = my - w*mx
print(f"最小二乘: w={w:.4f}, b={b:.4f}")      # 最小二乘: w=0.8189, b=49.0180

# ③ 方法二：归一化后梯度下降
xmin, xmax = min(xs), max(xs)
xs_n = [(x-xmin)/(xmax-xmin) for x in xs]
a, c, lr = 0.0, 0.0, 0.1
for _ in range(3000):
    ga = sum(-2*x*(y-(a*x+c)) for x, y in zip(xs_n, ys)) / n
    gc = sum(-2*(y-(a*x+c)) for x, y in zip(xs_n, ys)) / n
    a -= lr*ga; c -= lr*gc
w_gd = a/(xmax-xmin); b_gd = c - a*xmin/(xmax-xmin)   # 还原到原始尺度
print(f"梯度下降: w={w_gd:.4f}, b={b_gd:.4f}")         # 梯度下降: w=0.8189, b=49.0180

# ④ 用学到的模型做预测
print(f"80㎡ 预测: {w*80+b:.1f} 万")                    # 80㎡ 预测: 114.5 万
```

看结果：两条路找到的线**一模一样**（w≈0.819，b≈49.02）。真实规律是 0.8 和 50——因为数据有噪声，估计值不可能精确复原，但已经非常接近。这就是「学习」：**从带噪声的样本里，恢复出背后的规律**。

### 概念 6：R² —— 这条线到底行不行？

拟合完了总得打个分。R²（决定系数）回答的问题是：

```text
R² = 1 − SS残差 / SS总体

SS残差 = 数据点到你的线的距离平方和     （你的模型没解释掉的部分）
SS总体 = 数据点全部拉平到均值线的距离平方和（最蠢模型留下的部分）
```

- R² = 1：完美解释所有波动
- R² = 0.96：**96% 的价格波动能被面积解释**，剩下 4% 归咎于装修、楼层等没考虑的因素
- R² < 0：比直接猜平均数还烂（赶紧换模型）

本例实测 R² ≈ **0.96**——面积确实主导房价，模拟数据的设定得到了验证。

## 自测一下

> [!question]- 1. 为什么损失函数里要对误差「平方」，取绝对值不行吗？
> 取绝对值也可以（那叫 MAE，平均绝对误差），两者都是合法的损失函数。选平方的理由：
> ① **处处可导**——绝对值在零点是尖角，导数不存在，梯度下降会卡壳；平方光滑无死角。
> ② **放大离谱错误**——偏 10 的样本罚 100，偏 2 的只罚 4，逼迫模型优先修正大偏差。
> 代价是平方对异常值过于敏感（一个录入错误的豪宅数据能把整条线拽歪）——ML9 会再谈这个坑。

> [!question]- 2. 本课梯度下降示例中，如果不做归一化直接用原始面积（50~150）训练，会发生什么？动手改代码试试。
> 学习率 0.1 下损失会瞬间爆炸成 nan：x 的量纲太大 → 梯度巨大 → 一步跨过山谷冲上对面山坡 → 越荡越高。
> 把 lr 缩小到 1e-5 左右虽然不再爆炸，但收敛慢得令人发指。这正是「损失面又细又长」的直观体验——归一化把损失面整形成圆润的碗，同一个学习率就能又快又稳。**特征尺度是梯度下降的第一杀手**，记住这个教训比记任何公式都值钱。

> [!question]- 3. 两种方法结果完全一致，那深度学习为什么不直接用最小二乘公式？
> 因为闭式解只在「损失是参数的二次函数」这种温柔场景下存在。神经网络层层嵌套非线性激活（sigmoid 等），损失面变成亿维空间里的崎岖山地，**根本没有通用公式**能一步写出最优解。
> 梯度下降虽然笨——只能一步步走——但它只需要「当前点的坡度」，对山的形状没有任何要求。**通用性 > 优雅性**，这是深度学习时代最重要的工程哲学之一。

> [!question]- 4. 有人用你训练好的模型预测了一栋 500㎡ 的房子，输出 450 万，被客户骂天价。哪里出了问题？
> 训练数据的面积范围是 50~150㎡，500㎡ 远在训练分布之外——这叫**外推（extrapolation）**，线性模型会机械地延伸直线给出不可靠的结果（别墅、商业地产的定价逻辑和普通住宅完全不同）。
> 正确做法：要么拒绝超出数据范围的预测，要么补充大面积房源重新训练。**模型只在见过的世界里可靠**——这句话 ML9 评估和 ML4 过拟合还会反复出现。
