## 生活场景切入

第 1 章我们说过：机器学习就像教小孩认猫——给例子、给纠正，孩子自己悟出「猫的规律」。

现在把这个故事讲得更精确一点。「学习」这件事可以拆成三种玩法：

| 玩法     | 你提供什么          | 孩子学会什么     | 生活原型             |
| -------- | ------------------- | ---------------- | -------------------- |
| 有人教   | 题目 **+ 标准答案** | 做题的规律       | 刷带答案的习题册     |
| 自己琢磨 | 只有题目，没有答案  | 把相似的东西归堆 | 整理乱糟糟的衣柜     |
| 试错奖惩 | 没有题目，只有奖惩  | 什么行为有好处   | 摸黑找房里的电灯开关 |

对应到术语：**监督学习、无监督学习、强化学习**。记住这张表，你已经能对市面上八成 AI 应用分类了。

## 核心概念拆解

### 概念 1：机器学习的正式定义

1998 年 Tom Mitchell 给出被广泛引用的定义：

```text
如果一个程序在任务 T 上的表现（指标 P）随着经验 E 的增加而提升，
我们就说它在「学习」。
```

翻译成人话：**垃圾邮件过滤器读的邮件越多（E），识别垃圾邮件（T）的准确率（P）越高——它在学习**。三个要素缺一不可：没有 E 是死规则，没有 T 是瞎转悠，没有 P 就不知道学得怎么样。

### 概念 2：监督学习 —— 有标准答案的刷题

数据长这样：每个样本都有**输入 X 和标签 Y** 成对出现。

```text
(房屋面积 80㎡, 价格 115 万)   ← 一条训练样本
(房屋面积 120㎡, 价格 148 万)
...

任务：学会 X → Y 的映射，然后给新的 X 预测 Y
```

两大子类：

| 子类 | 输出是什么 | 典型任务                     | 你已经见过的词   |
| ---- | ---------- | ---------------------------- | ---------------- |
| 回归 | 连续数值   | 房价预测、气温预测、销量预估 | M2 的方程求解    |
| 分类 | 离散类别   | 垃圾邮件识别、猫狗分类、诊断 | sigmoid 概率输出 |

**判断技巧**：问自己「答案是一个数还是一个选项？」是数→回归；是选项→分类。

最小可运行示例——**K 近邻（KNN）**，监督学习里最直白的算法：「新样本长什么样，就看它周围 k 个邻居多数是什么」：

```python
train = [([1,1],"A"),([1,2],"A"),([2,2],"A"),
         ([6,5],"B"),([7,6],"B"),([6,7],"B")]

def knn(p, k=3):
    ds = sorted(((p[0]-t[0][0])**2 + (p[1]-t[0][1])**2, t[1]) for t in train)
    top = [lab for _, lab in ds[:k]]
    return max(set(top), key=top.count)

print(knn([1.5, 1.5]))   # A —— 落在 A 簇里
print(knn([6.5, 5.5]))   # B —— 落在 B 簇里
```

（真实运行结果，Python 3.13。）KNN 没有任何「训练过程」——它把全部数据背下来现场比对，恰好说明监督学习的本质是「参照已知答案做判断」。

### 概念 3：无监督学习 —— 没有答案的自己琢磨

数据只有 X 没有 Y。算法要自己发现结构。

最经典的任务是**聚类（Clustering）**：把相似的样本自动归堆。一维 K-means 两行核心逻辑就能跑：

```python
import random
random.seed(9)

xs = ([random.gauss(10, 1) for _ in range(20)]
      + [random.gauss(25, 1) for _ in range(20)])   # 两团数据混在一起

cents = [12, 22]                                     # 随便猜两个中心
for _ in range(15):
    cl = [[], []]
    for x in xs:
        cl[0 if abs(x-cents[0]) < abs(x-cents[1]) else 1].append(x)
    cents = [sum(c)/len(c) for c in cl]              # 中心移到簇平均位置

print(f"找到的两簇中心: {cents[0]:.2f}, {cents[1]:.2f}")
# 找到的两簇中心: 9.95, 25.05 —— 与真实生成参数 (10, 25) 几乎一致！
```

没人告诉它有几类、每类是什么，它自己把两团分了出来。其他无监督任务还有降维（压缩特征数量）、异常检测（找出不合群的点）等，ML7 会展开。

**应用直觉**：电商「猜你喜欢」的用户分群、天文数据的自动归类，都是「不知道答案先分组再看每组有什么规律」的思路。

### 概念 4：强化学习 —— 试错与奖惩

既没有标准答案也没有现成数据，只有一个**环境**：你做出动作，环境给你奖励或惩罚。

多臂老虎机（三台老虎机，吐钱概率不同但你看不到）是强化学习最小的原型：

```python
import random
random.seed(9)

true_rewards = [0.3, 0.6, 0.45]        # 三台机器的真实吐钱率（玩家不可见）
est = [0.0]*3; counts = [0]*3; eps = 0.1

for t in range(5000):
    if random.random() < eps:
        a = random.randrange(3)                 # 10% 时间随机探索
    else:
        a = est.index(max(est))                 # 90% 时间拉当前最优
    r = 1 if random.random() < true_rewards[a] else 0
    counts[a] += 1
    est[a] += (r - est[a]) / counts[a]          # 增量更新估计值

print(f"估计值: {[round(e,3) for e in est]}")
print(f"各臂尝试次数: {counts}")
# 估计值: [0.353, 0.604, 0.463]
# 各臂尝试次数: [150, 4591, 259] —— 绝大多数筹码押给了真正最好的 2 号机
```

注意它自己发现了「2 号机最好」，而且学会了**平衡探索与利用**（偶尔试试别的，防止错过更好的选择）。AlphaGo、机器人控制、大模型的 RLHF 对齐，都是这个循环的高维放大版。

### 概念 5：训练的通用骨架 —— 三种范式共用一台引擎

不管哪种范式，「学习」都归结为同一个循环（M3/M6/M7 的知识在这里合体）：

```text
① 模型：一台带旋钮（参数 w）的机器          —— M3 函数
② 目标：衡量「好坏」的一个数                —— 监督=损失函数 / 聚类=紧密度 / 强化=累计奖励
③ 优化：调旋钮让目标变好                    —— M7 梯度下降（可导时）或其他搜索
```

所以当你听说任何新算法，先问三个问题：它的**模型**是什么形状？它的**目标函数**是什么？它怎么**优化**？三问过后，再花哨的名词都会现出原形。

```text
本板块路线预告：
  ML2 线性回归      —— 最简单的模型 + 第一个损失函数（回归）
  ML3 逻辑回归      —— 用概率做分类 + 交叉熵损失
  ML4 过拟合与欠拟合 —— 「学得太死板 vs 学得太死记」的分寸（最重要概念）
  ML5 决策树/随机森林 —— 像 20 个问题游戏的非数学流派
  ML6 SVM           —— 找最宽分界线的几何流派
  ML7 聚类          —— 无监督主场
  ML8 特征工程      —— 数据决定上限
  ML9 模型评估      —— 怎么知道它真的学会了
  ML10 项目实战     —— 完整走一遍流程
```

## 自测一下

> [!question]- 1. 把下面的应用分别放进监督/无监督/强化三个抽屉：(a) 相册自动人脸分组 (b) 信用卡欺诈检测（历史交易已标注是否欺诈）(c) 下棋 AI 自我对弈进步 (d) 新闻自动分成体育/财经/科技（未标注）
> (a) **无监督**（聚类）：没人标注过「这是同一张脸」，算法自己按相似度归堆。
> (b) **监督**（分类）：有历史标签当标准答案。
> (c) **强化**：自我对弈的输赢就是奖励信号。
> (d) **无监督**（聚类）：题目说「未标注」。若新闻预先有人工分类好的样本，则变成监督的分类任务——条件一变范式就变。

> [!question]- 2. 「预测明天某股票的收盘价」和「判断明天某股票涨还是跌」分别是回归还是分类？
> 收盘价是一个连续数值 → **回归**。
> 涨/跌是二选一的类别 → **分类**。
> 同一份 underlying 数据，问题表述不同就落在不同子类——实际项目中经常两者都做，再用「预测价 > 今日价」把回归结果转成分类结论。

> [!question]- 3. 用「模型 / 目标 / 优化」三问拆解 KNN：它的模型是什么？目标是显式的吗？
> **模型**：把全部训练样本原样存下来，预测时取 k 个最近邻投票——「模型」就是数据本身，没有可调参数。
> **目标**：KNN 没有 显式的训练损失——这也是它被称为「惰性学习（lazy learning）」的原因。
> **优化**：不存在训练阶段的优化；计算量被推迟到了每次预测。
> 这题说明三问框架也能帮你发现「有些算法刻意省掉了某一环」，理解更立体。

> [!question]- 4. 多臂老虎机示例里，为什么还要留 10% 的时间随机探索？永远拉当前最优的机器不行吗？
> 只利用不探索会陷入「赢者通吃」的陷阱：如果前几次随机抽中了次优机器并把它估得很高，之后再也没有机会纠正。
> 保留 ε 的探索率保证每台机器都被持续采样，估计值最终收敛到真实值——这就是经典的**探索-利用权衡（exploration-exploitation tradeoff）**，也是强化学习的核心难题之一。
