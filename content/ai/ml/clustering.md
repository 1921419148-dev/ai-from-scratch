## 生活场景切入

搬进新城市，你对餐厅一无所知。打开地图把收藏的两百家店标出来，肉眼一看：有几团扎在写字楼附近、几团沿大学城分布、还有一团在居民区。

没人给你发过「餐厅分类标签」——你是**根据位置相似性自己看出群来的**。这就是聚类：数据自带结构，算法把它显影出来。

与监督学习的根本区别一句话：

```text
分类：先有答案后学习   「这 1000 封邮件已标注垃圾/正常，学着点」
聚类：根本没有答案     「这 1000 封邮件自己分分组看看」
```

## 核心概念拆解

### 概念 1：K-Means —— 最经典的聚类三步舞

给定数据和簇数 K，算法只有三个动作：

```text
① 初始化：随便放 K 个中心点
② 分配：每个样本归给离它最近的中心
③ 更新：每个中心挪到自己那堆样本的平均位置

重复 ②③ 直到不再变化
```

为什么能收敛？②③ 两步都在让「所有点到自己中心的距离总和」（术语叫惯性 WCSS）下降——单调下降必有尽头。M7 梯度下降是「沿坡走」，K-Means 是「分堆-挪心」，优化思路不同，收敛精神一致。

### 概念 2：完整实战 —— 三团数据自动归位

生成三个高斯团，看 K-Means 能否找回（Python 实际运行结果）：

```python
import random
random.seed(11)

# ① 数据：三个中心 (0,0) (5,5) (0,5)，各撒 30 个点
pts = ([(random.gauss(0, .5), random.gauss(0, .5)) for _ in range(30)]
     + [(random.gauss(5, .5), random.gauss(5, .5)) for _ in range(30)]
     + [(random.gauss(0, .5), random.gauss(5, .5)) for _ in range(30)])

# ② K-Means 主循环
def kmeans(pts, k=3, iters=20):
    cents = random.sample(pts, k)
    clusters = None
    for _ in range(iters):
        clusters = [[] for _ in range(k)]
        for p in pts:
            d = [(p[0]-c[0])**2 + (p[1]-c[1])**2 for c in cents]
            clusters[d.index(min(d))].append(p)
        cents = [(sum(p[0] for p in cl)/len(cl),
                  sum(p[1] for p in cl)/len(cl)) if cl else c
                 for cl, c in zip(clusters, cents)]
    return cents, clusters

cents, clusters = kmeans(pts)
for i, (c, cl) in enumerate(zip(cents, clusters)):
    print(f"簇{i}: 中心=({c[0]:.2f}, {c[1]:.2f})  样本数={len(cl)}")
# 簇0: 中心=(0.04, 5.02)   样本数=30
# 簇1: 中心=(0.13, -0.04)  样本数=30
# 簇2: 中心=(5.21, 5.14)   样本数=30
```

完美复原：三个真实生成中心 (0,0)(5,5)(0,5) 全部被找回，每团恰好 30 个点一个不多。注意算法**从不知道**这些真值——它只是执行了「就近归堆、挪向平均」两条朴素规则。

### 概念 3：怎么选 K？—— 肘部法则

K 是人工指定的超参数。选大了会把一坨硬拆成几瓣，选小了会把两团捏成一坨。最常用的诊断工具是**肘部法则**：

```text
对每个候选 K 算 WCSS（所有点到自己中心的距离平方和），画折线找「手肘」
```

实测（两团数据）：

```python
for k in [1, 2, 3, 4]:
    print(f"K={k}: WCSS={kmeans(pts[:60], k)[0]:.1f}")
# K=1: WCSS=817.4
# K=2: WCSS=27.4    ← 从 817 骤降到 27！
# K=3: WCSS=21.9    ← 之后改善微弱
# K=4: WCSS=19.8
```

解读：K 从 1 到 2 时 WCSS 断崖式下跌——因为第二簇的存在被真正捕捉到了；之后继续加 K 只是锦上添花。曲线像一条手臂，「肘部拐点」K=2 就是答案。**肘部不明显时**（真实数据常如此），再配合轮廓系数（衡量「簇内紧、簇间远」程度，取值 −1~1 越大越好）交叉判断。

### 概念 4：聚类的哲学 —— 算法分堆，人类命名

这是本课最重要的一句话：

> **聚类只能告诉你「有这么几堆」，永远无法告诉你「这几堆叫什么」。**

电商把用户聚成 5 簇后，得由分析师看着每簇的消费特征说：「这簇叫价格敏感型，那簇叫品质型」。同一份数据换个视角，簇的含义可以完全不同。所以聚类的产出是**假设生成器**而非结论本身——它替你发现值得研究的群体，解释权始终在人。

顺带两个工程提醒：

- **量纲又来了**：K-Means 基于距离，特征必须先标准化（M8/M10 的老规矩）
- **初始化敏感**：起点不同可能收敛到不同的局部解，实用工具都内置多次重启取最优（sklearn 默认 n_init=10）

### 概念 5：聚类还能干什么

| 场景     | 聚出的簇可能是                 |
| -------- | ------------------------------ |
| 用户运营 | 高价值/沉睡/流失风险用户       |
| 图像压缩 | 把 1600 万种颜色聚成 16 种主色 |
| 天文数据 | 新型天体类别                   |
| 异常检测 | 归不进任何簇的点 = 可疑        |
| 文档整理 | 主题相近的文章群               |

共同套路：**先无监督地发现结构，再让人赋予意义或采取行动。**

## 自测一下

> [!question]- 1. K-Means 的两个步骤分别对应什么目标？为什么交替进行就能收敛？
> 「分配」步固定中心、把每个样本划给最近中心——这一步使 WCSS 在当前中心下达到最小；「更新」步固定分配、把中心移到均值——均值恰好是该簇距离平方和的最小点。
> 于是每一步都让 WCSS 单调不增，而有界函数的单调序列必收敛——所以一定停机。
> 注意它保证收敛到**局部**最优：初始位置不好会卡进歪解，这就是实用中要多重启几次的原因。

> [!question]- 2. 对「身高体重（厘米、千克）」直接跑 K-Means 会出什么问题？
> 体重的数值范围（40~120）比身高换算后的方差贡献小得多时还好，但反过来如果用毫米做身高单位，身高的数值会大到完全主导欧氏距离——聚类实际上只按身高分组，体重形同虚设。
> 解法照旧：先标准化（减均值除以标准差），让两个特征在距离计算中平权。**凡是基于距离的算法，第一步永远是查量纲**——这条纪律在本板块已经第三次出现了。

> [!question]- 3. 聚类结果发现「簇 A 用户月均消费 3000 元」，可以直接对外宣称「簇 A 是高价值客户」吗？
> 数字部分（3000 元）没问题，但「高价值客户」这个**命名和定性是人的判断**，不是算法输出。
> 需要先确认：3000 元在整体里确实算高（对比全体均值/中位数）；这个簇的其他特征（活跃度、留存率）也支持「有价值」的判断；而不是碰巧消费高但全是薅羊毛党。**算法提供事实结构，业务含义必须由人论证**——跳过论证直接命名是数据分析最常见的翻车姿势之一。

> [!question]- 4. 为什么说 K-Means 只擅长「圆形」的簇？遇到两个细长条交错的簇会发生什么？
> K-Means 用「到中心的直线距离」定义归属，天然偏爱大小相近的球状簇。
> 面对细长条（比如两个月牙交错），中心落在条带的中间空隙附近，靠近对方中心的那半段会被错误吸走——结果把月牙拦腰截断。
> 这暴露了「基于质心+欧氏距离」的方法论天花板。处理任意形状要用 **DBSCAN**（按密度连通性扩展成簇，形状自由）等密度聚类方法——记住这个分工即可，细节可等需要时再学。
