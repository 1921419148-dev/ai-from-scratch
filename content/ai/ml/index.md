> [!abstract] 本板块解决
> 机器学习是整个 AI 大厦的地基。这里你将学到：机器如何从数据中学出规律？如何判断学得好不好？以及最经典的十来种算法——每一个都配生活化类比和可视化演示。

## 学习顺序

| #    | 课程                         | 内容                           | 状态 |
| ---- | ---------------------------- | ------------------------------ | ---- |
| ML1  | 什么是机器学习？             | 三大数据范式：监督/无监督/强化 | 🚧   |
| ML2  | 线性回归：画一条最合适的线   | 最简单的模型 + 损失函数        | 🚧   |
| ML3  | 分类问题与逻辑回归           | 「是不是」的判断               | 🚧   |
| ML4  | 过拟合与欠拟合：学习的分寸   | **最重要的概念之一**           | 🚧   |
| ML5  | 决策树与随机森林             | 像 20 个问题游戏一样决策       | 🚧   |
| ML6  | 支持向量机 SVM               | 找最宽的分界线                 | 🚧   |
| ML7  | 聚类：没有标签怎么分组       | 无监督学习入门                 | 🚧   |
| ML8  | 特征工程：喂给模型什么很重要 | 数据决定上限                   | 🚧   |
| ML9  | 模型评估：怎么知道它学得好   | 准确率的陷阱、交叉验证         | 🚧   |
| ML10 | 项目实战：预测房价           | 完整走一遍流程                 | 🚧   |
