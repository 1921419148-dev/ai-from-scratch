> [!abstract] 本课将学到
>
> - **过拟合（Overfitting）**：训练成绩满分，考试一塌糊涂——「背题」而非「学会」
> - **欠拟合（Underfitting）**：模型太简单，连训练数据都学不明白
> - **训练集 / 测试集**：为什么要藏起一部分数据当「考卷」
> - **泛化（Generalization）**：机器学习的终极目标
> - 对抗过拟合的四件武器，附真实数值实验

## 生活场景切入

两个学生备考同一份数学卷：

- 小背把题库每道题的答案**一字不差**背了下来。模拟考（原题）100 分；正式考试换了数字，只考了 40 分。
- 小懒上课没听，只会套「见大数就选 C」。模拟考 45 分；正式考试还是 45 分。

小背的问题叫**过拟合**：把训练材料的噪声细节也当成了规律。小懒的问题叫**欠拟合**：模型太糙，连基本规律都没抓住。机器学习模型每天都在这两个陷阱之间走钢丝——而**判断模型到底在哪个陷阱里，靠的不是感觉，是两份不同的成绩单**。

## 核心概念拆解

### 概念 1：训练集与测试集 —— 一份用来学，一份用来考

```text
全部数据 ──┬── 训练集 (如 80%) ：给模型学习
           └── 测试集 (如 20%) ：藏起来，最后才拿出来考一次
```

铁律只有一条：

> **测试数据绝不能参与训练。** 拿考过的题再考一遍，测的是记性不是能力。

模型在训练集上的误差叫**训练误差**，在测试集上的叫**测试误差**。诊断表格（背下来）：

| 训练误差 | 测试误差 | 诊断                 | 药方                         |
| -------- | -------- | -------------------- | ---------------------------- |
| 低       | 高       | **过拟合**（背题）   | 更多数据 / 正则化 / 简化模型 |
| 高       | 高       | **欠拟合**（没学会） | 加特征 / 加深模型 / 训练更久 |

### 概念 2：亲手制造一次过拟合

用带噪声的正弦曲线做实验：16 个训练点，三种复杂度的多项式去拟合（`y = sin(4.5x)/3 + 噪声`，噪声底为 0.0025；以下均为实际运行结果）：

```python
import numpy as np
import random
random.seed(21); np.random.seed(21)

xs = np.array(sorted(random.uniform(0, 1) for _ in range(16)))
ys = np.sin(4.5*xs)/3 + np.random.normal(0, 0.05, len(xs))
rng = np.random.default_rng(42)
xs_t = np.array(sorted(rng.uniform(0, 1) for _ in range(80)))   # 测试集
ys_t = np.sin(4.5*xs_t)/3 + np.random.normal(0, 0.05, len(xs_t))

def poly(x, d):                       # x 的 0~d 次幂当特征
    return np.column_stack([x**i for i in range(d+1)])

for d in [1, 3, 10]:
    X, Xt = poly(xs, d), poly(xs_t, d)
    theta = np.linalg.lstsq(X, ys, rcond=None)[0]
    tr = ((ys - X@theta)**2).mean()
    te = ((ys_t - Xt@theta)**2).mean()
    print(f"degree={d:2d}: train={tr:.4f} test={te:.4f}")
```

结果：

| 多项式次数 | 训练 MSE   | 测试 MSE   | 诊断                       |
| ---------- | ---------- | ---------- | -------------------------- |
| 1（直线）  | 0.0204     | 0.0245     | 欠拟合：两头都差           |
| **3**      | 0.0015     | **0.0078** | ✅ 刚刚好                  |
| 10         | **0.0011** | 0.0313     | 过拟合：训练最好，测试翻车 |

读懂数字背后的故事：

- **degree=10 的训练误差全场最低**（0.0011），但测试误差是 degree=3 的四倍——它把噪声也拟合进去了（16 个点足够一条 10 次曲线精确穿过每一个）
- **degree=3 接近噪声底 0.0025**：它抓住了真规律（sin 曲线本身就能被低次多项式近似），对噪声免疫
- 这就是「学习的分寸」：**目标是测试误差最小，不是训练误差为零**

### 概念 3：泛化 —— 机器学习的终极 KPI

```text
泛化（Generalization）= 模型在没见过的新数据上的表现
```

训练好不算好，泛化好才是真的好。这句话反过来解释了为什么大公司愿意花千万级算力训练一个模型：他们赌的就是模型从海量样本里提炼的规律能泛化到未来的新请求上。ChatGPT 能回答从没见过的问题，就是泛化的极致展示。

三条经验规律值得内化：

1. **数据越多越难过拟合**——16 个点可以被 10 次曲线穿过，16000 个就穿不过了，只能老老实实抓规律
2. **模型越复杂越容易过拟合**——旋钮越多，「死记硬背」的容量越大
3. 数据少又不得不用复杂模型时 → 正则化登场

### 概念 4：对抗过拟合的四件武器

**① 更多的数据**（最有效，最贵）。上面已解释，略。

**② 正则化（Regularization）**——给损失函数加「复杂度税」：

```text
新损失 = 原损失 + λ × Σ wᵢ²          （L2 正则，λ 是税率）
```

参数越大，模型行为越「拧巴」（剧烈弯折去穿每个点）；对大参数收税，逼着模型选平滑的解。还是刚才 degree=10 的实验，加一行代码：

```python
# L2 正则：求解 (XᵀX + λI)θ = Xᵀy  代替普通最小二乘
for lam in [0, 1e-3]:
    I = np.eye(11); I[0,0] = 0                    # 不惩罚截距
    theta = np.linalg.solve(X.T@X + lam*I, X.T@ys)
    te = ((ys_t - Xt@theta)**2).mean()
    print(f"lambda={lam}: test={te:.4f}")
# lambda=0:      test=0.0313   ← 裸奔，过拟合
# lambda=0.001:  test=0.0104   ← 测试误差砍掉三分之二！
```

训练误差略微上升（0.0011→0.0016），换来测试误差大幅下降——**主动放弃部分训练精度，换取泛化**，这是本课最反直觉也最重要的一笔交易。

**③ 早停（Early Stopping）**——盯着验证集损失，一旦开始回升立刻刹车。M2 不等式 `loss ≥ best_loss` 在此上岗。

**④ Dropout / 集成**——神经网络专属（随机屏蔽一部分神经元防止合谋背题）和 ML5 随机森林（多模型投票互相纠错），后续课程展开。

### 概念 5：验证集 —— 调参不能动用考卷

实践中其实要切成三份：

```text
训练集 (60%) ：喂给模型
验证集 (20%) ：调超参数（比如试 degree=1/3/10 选哪个、λ 取多少）
测试集 (20%) ：最终考核，一年只动一次
```

为什么调参不能用测试集？因为**你反复根据测试集挑方案，等于变相把测试信息泄露给了选择过程**——选出来的「最优」会高估真实水平。这和考试前拿往年真题反复刷、最后模拟分虚高的道理一模一样。ML9 交叉验证会把这套流程工程化。

## 自测一下

> [!question]- 1. 训练误差 0.9%、测试误差 8%；另一模型训练误差 4%、测试误差 5%。哪个更可能是你要部署的？各处于什么状态？
> 选后者。
> 前者训练 0.9% vs 测试 8%——差距近十倍，典型**过拟合**（背题高手）；后者训练测试接近且都不高，泛化健康。
> 注意前者训练误差更低不代表更好——**比较模型的唯一标准是测试表现**。若想拯救前者：减模型容量、加正则、或收集更多训练数据。

> [!question]- 2. 为什么「增加数据量」排在药方第一位？用一个极端例子说明。
> 极端例子：用 10 次多项式拟合 11 个点可以完美穿过（训练误差 0），因为未知数个数 ≥ 方程个数，纯靠记忆就能解题；但给它 100 万个点，方程远多于未知数，模型被迫放弃「逐点背诵」，只能抓真正的趋势。
> 数据是约束模型想象力的物理手段——其他所有药方（正则化、简化模型）本质上都是在模拟「数据不够多」时的替代约束。

> [!question]- 3. L2 正则化为什么「不惩罚截距 b」？
> 权重 w 决定曲线的形状复杂度——w 大意味着剧烈弯折，是需要抑制的「过度表达」。
> 截距 b 只是整条曲线上下平移，不影响任何弯曲程度，惩罚它只会白白限制模型贴合数据的整体水平，没有任何防过拟合收益。
> （类比：罚款应该罚「超速」而不是罚「开车」。）

> [!question]- 4. 同学甲说：「我把测试集也拿来调参了，反正最后测试准确率高达 95%！」他的 95% 可信吗？
> 不可信，存在**选择偏差泄露**：每次根据测试成绩挑选方案，都是一次向测试集「打探答案」。反复多次后，选出的方案已经过拟合于测试集的特殊性，其 95% 是乐观估计。
> 真实水平要用一份从未参与任何决策的新数据来估（这就是验证集/测试集分离的全部意义）。补救办法：重新收集一批全新数据再测一次，或用 ML9 的交叉验证获得无偏估计。
