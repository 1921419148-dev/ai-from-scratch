> [!abstract] 本课将学到
>
> - **分类（Classification）**：输出是类别而不是数值的预测任务
> - **逻辑回归（Logistic Regression）**：名字带「回归」，干的却是分类——线性回归 + sigmoid 一站式改装
> - **决策边界（Decision Boundary）**：模型划下的那条「楚河汉界」
> - **交叉熵损失**：为什么「自信地答错」要重罚
> - 完整实战：二维两类数据的分类器，从零手写

## 生活场景切入

医生看化验单：「这个指标 0.87——**87% 可能是阳性**。」

注意这句话的结构：输入是各种检查数据，输出不是数值而是一个**概率**，再由概率做出**判断**（收不收治）。这就是分类任务的标准流程：

```text
输入特征 → 算出一个分数 → 压成 0~1 的概率 → 按阈值拍板
```

垃圾邮件过滤、人脸识别、疾病筛查、贷款审批……全是这条流水线。

## 核心概念拆解

### 概念 1：从回归到分类 —— 只差一步挤压

ML2 的线性回归输出是任意大的数，没法直接当概率用。改装方案简单到离谱：**套一层 sigmoid**（M3 认识的老朋友）：

```text
线性回归：  z = w₁x₁ + w₂x₂ + b          输出任意实数
逻辑回归：  p = σ(z) = 1/(1+e^(−z))      输出压进 (0,1) ← 概率！
```

sigmoid 的三个关键性质正好满足概率的要求：

| z    | σ(z) | 含义           |
| ---- | ---- | -------------- |
| 很负 | ≈ 0  | 几乎肯定「否」 |
| 0    | 0.5  | 五五开         |
| 很正 | ≈ 1  | 几乎肯定「是」 |

```python
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

for z in [-10, -1, 0, 1, 10]:
    print(f"σ({z:+d}) = {sigmoid(z):.4f}")
# σ(-10) = 0.0000 | σ(-1)=0.2689 | σ(0)=0.5000 | σ(1)=0.7311 | σ(+10)=1.0000
```

最后拍板只需一个阈值（通常取 0.5）：`p ≥ 0.5 → 判为正类`。

### 概念 2：决策边界 —— 楚河汉界画在哪

令 `p = 0.5` 的位置就是 sigmoid 输入 z=0 的位置，即：

```text
w₁x₁ + w₂x₂ + b = 0        ← 二维平面上的一条直线！
```

这条线叫**决策边界**：线的一侧全部判正类，另一侧全部判负类。训练的过程，本质就是把这条线挪到正负样本中间最合适的位置。

```text
 x₂
  │   ○ ○                ● = 正类
  │  ○ ○ ○    ┊          ○ = 负类
  │   ○ ○    ┊┆┊← 决策边界
  │         ┊┆●●
  │        ┊ ● ● ●
  └──────────────────── x₁
```

**局限也一目了然**：逻辑回归的边界是直线，只能切分「线性可分」的数据。数据若围成一圈（内圈一类外圈一类），直线怎么摆都切不开——那时需要 ML6 的 SVM 配核技巧或深度学习。但别小看它：特征工程得当（M8）时，逻辑回归至今仍是工业界的主力基线模型。

### 概念 3：交叉熵损失 —— 重罚自信的错误

训练依然走「损失 → 梯度下降」老路，但 MSE 在这里水土不服。分类任务的标配是**交叉熵（Cross-Entropy）**：

```text
L = −[y·log(p) + (1−y)·log(1−p)]

y=1 时简化为 L = −log(p)：真实为正类，预测概率越低罚得越狠
y=0 时简化为 L = −log(1−p)：对称同理
```

感受一下它与 MSE 的区别（真实标签 y=1，代码实测）：

```python
import math

for p in [0.9, 0.5, 0.1, 0.01]:
    ce  = -math.log(p)
    mse = (1 - p)**2
    print(f"预测 p={p:<5}: 交叉熵={ce:.3f}   MSE={mse:.4f}")
# 预测 p=0.9  : 交叉熵=0.105   MSE=0.0100
# 预测 p=0.5  : 交叉熵=0.693   MSE=0.2500
# 预测 p=0.1  : 交叉熵=2.303   MSE=0.8100
# 预测 p=0.01 : 交叉熵=4.605   MSE=0.9801
```

看出门道了吗？当模型把正类预测成 0.01（几乎全错的自信），交叉熵飙到 **4.6**，而 MSE 才 0.98——交叉熵对「自信的错误」惩罚呈指数级加重。这正是我们想要的：错可以，但不能错得理直气壮。（M4 信息熵一节的伏笔在此兑现：`−log p` 就是「惊讶度」。）

另一个技术理由：sigmoid + MSE 组合的损失面坑坑洼洼（非凸），梯度下降容易卡进烂解；换成交叉熵后损失面变成光滑的碗——数学上恰好抵掉了 sigmoid 导数的麻烦。**损失函数选对，训练就成功了一半。**

### 概念 4：完整实战 —— 手写二维分类器

生成两团可分的数据点，让逻辑回归自己找出分界线（数字均为实际运行结果）：

```python
import random, math
random.seed(7)

def sigmoid(z): return 1/(1 + math.exp(-z))

# ① 数据：A 团中心 (2,2)，B 团中心 (-2,-2)
data = []
for _ in range(60):
    data.append(([random.gauss(2,1), random.gauss(2,1)], 1))
    data.append(([random.gauss(-2,1), random.gauss(-2,1)], 0))

# ② 训练：梯度下降最小化交叉熵
w1 = w2 = b = 0.0; lr = 0.1
for epoch in range(3000):
    gw1 = gw2 = gb = 0.0
    for (x, t) in data:
        p = sigmoid(w1*x[0] + w2*x[1] + b)
        gw1 += (p - t)*x[0]          # 交叉熵对参数的梯度恰好是 (p−t)×输入
        gw2 += (p - t)*x[1]
        gb  += (p - t)
    n = len(data)
    w1 -= lr*gw1/n; w2 -= lr*gw2/n; b -= lr*gb/n

print(f"w1={w1:.3f} w2={w2:.3f} b={b:.3f}")
# w1=2.470 w2=2.262 b=0.978

# ③ 评估训练准确率
correct = sum(1 for x, t in data if (sigmoid(w1*x[0]+w2*x[1]+b) > 0.5) == bool(t))
print(f"训练准确率: {correct/len(data):.1%}")     # 训练准确率: 100.0%

# ④ 预测新样本
for pt in [[3, 3], [-3, -2], [0, 0]]:
    p = sigmoid(w1*pt[0] + w2*pt[1] + b)
    print(f"{pt} → 属于 A 类概率 {p:.4f}")
# [3, 3] → 1.0000 | [-3,-2] → 0.0000 | [0,0] → 0.7267
```

逐段解读：

- 学到的权重 `w1≈w2≈2.3~2.5`：两个方向同等重要——因为两团是对角分布的
- `[3,3]` 给出概率 1.0：深深入正类腹地；`[-3,-2]` 反之
- `[0,0]` 这个骑墙点给出 **0.73**——模型不仅给答案，还给置信度。原点其实略偏 A 侧（决策边界在 x₂ ≈ −0.43 处），这个细节只有概率能告诉你

### 概念 5：名字的由来与「回归」的误会

为什么叫「逻辑**回归**」却做分类？历史包袱：它确实在「回归」一个东西——**回归到对数几率**。定义 `log(p/(1−p))` 叫 logit（对数几率），逻辑回归实际上是在拟合 `logit = wx+b` 的线性关系。「对几率的回归」→ 逻辑回归。知道这一点即可，日常交流直接把它当分类模型。

## 自测一下

> [!question]- 1. 医疗诊断场景该不该把阈值从 0.5 调低（比如 0.2）？
> 应该调低。漏诊（把病人判健康）的代价远大于误报（健康人多做一次复查），降低阈值意味着宁可错杀不可放过——召回率上升。
> 反过来垃圾邮件过滤应调高阈值（宁漏放不误杀重要邮件）。**阈值是业务决策而非数学决策**——同一个模型，换个场景就该换个阈值，ML9 会把这个思想正式化成精确率/召回率的权衡曲线。

> [!question]- 2. 为什么说「sigmoid 把 z>0 判正类」和「决策边界是 wx+b=0 这条直线」是一回事？
> sigmoid 是严格递增函数：σ(z)>0.5 当且仅当 z>0。
> 所以「p≥0.5 判正」等价于「wx+b≥0 判正」，而 `wx+b=0` 恰好是平面上的直线方程。
> 一个是概率语言，一个是几何语言，描述的是同一条边界。这也是为什么逻辑回归又叫「线性分类器」。

> [!question]- 3. 用三问框架拆解逻辑回归的梯度来源：交叉熵 + sigmoid 的组合下，梯度为什么恰好等于 (p − t)?
> 数学上：交叉熵的导数是 (1−p)/p 或 −1/(1−p)（按 y 取向），sigmoid 的导数是 p(1−p)；两者相乘时 p(1−p) 恰好约掉分母，剩下干净的 (p−t)。
> 直觉上：(p−t) 就是「预测与真相的差距」——预测准（p≈t）时梯度趋近 0，模型不再乱动；错得离谱时梯度最大，纠正力度最强。这种优雅的化简正是「交叉熵是分类天选损失」的第二个证据（第一个是重罚自信错误）。

> [!question]- 4. 如果两类数据一个围在圆心、一个围在外环（同心圆分布），逻辑回归还有救吗？
> 直接喂原始坐标 (x₁,x₂)：没救——任何直线都切不开同心圆。
> 但加一步特征工程就有救：新增特征 `r² = x₁²+x₂²`（到圆心的距离平方），在新特征空间里两类瞬间变成「r 小 vs r 大」，一条直线轻松切开。
> 这个例子预告了两个大主题：**M8 特征工程**（换坐标系救直线）和 ML6 核技巧/SVM（自动完成这种升维）。深度学习则更进一步——让网络自己学出需要的变换。
