> [!abstract] 本板块解决
> 语言是人类智能的核心，也让机器理解语言成了 AI 最难也最迷人的方向之一。本板块沿着技术演化的主线（词向量 → RNN → Transformer → BERT → GPT），讲清「机器是怎么读懂话的」。

## 学习顺序

| #    | 课程                           | 内容                      | 状态 |
| ---- | ------------------------------ | ------------------------- | ---- |
| NLP1 | 机器如何「读」文字：分词与表示 | 文字的数字化              | 🚧   |
| NLP2 | 词向量 Word Embedding          | 国王 - 男人 ≈ 女王 - 女人 | 🚧   |
| NLP3 | 文本分类实战                   | 情感分析：好评还是差评    | 🚧   |
| NLP4 | 序列标注与命名实体识别         | 谁是人名、地名、机构名    | 🚧   |
| NLP5 | 机器翻译的演化                 | 从规则到统计到神经网络    | 🚧   |
| NLP6 | 预训练语言模型 BERT            | 完形填空学出来的理解力    | 🚧   |
| NLP7 | GPT 家族：从 GPT-1 到现在      | 预测下一个词的暴力美学    | 🚧   |
| NLP8 | 提示词工程 Prompt Engineering  | 和大模型高效对话的艺术    | 🚧   |
