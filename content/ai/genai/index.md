> [!abstract] 本板块解决
> 生成式 AI 不只是「判断」，而是「创造」——写文章、画插画、写代码、做视频。本板块讲清它的原理（语言模型、扩散模型）、应用范式（RAG、Agent）以及如何安全负责任地使用它。

## 学习顺序

| #   | 课程                       | 内容                           | 状态 |
| --- | -------------------------- | ------------------------------ | ---- |
| G1  | 什么是生成式 AI？          | 判别 vs 生成：一字之差天壤之别 | 🚧   |
| G2  | 语言模型原理               | 下一个词的概率是怎么算出来的   | 🚧   |
| G3  | RAG 检索增强生成           | 让大模型「开卷考试」           | 🚧   |
| G4  | AI Agent 智能体            | 会用工具、能规划的 AI 助手     | 🚧   |
| G5  | 扩散模型与图像生成         | 从噪点里「雕」出一张画         | 🚧   |
| G6  | 多模态：看图说话与看话画图 | 文字、图像、语音的统一         | 🚧   |
| G7  | 微调与本地部署             | 打造你自己的专属模型           | 🚧   |
| G8  | 安全、伦理与幻觉           | 能力越大，责任越大             | 🚧   |
