## 生活场景切入

人类从不把世界拆开处理——看到「禁止通行」的红色标志，你同时处理了颜色、形状、文字和语境；朋友发来一张梗图加一句「懂的都懂」，你秒懂。

而传统 AI 是严重的偏科生：视觉模型看不懂字，语言模型看不见图。**多模态 AI 要做的就是打通感官**——让同一个模型能看图说话、看话画图、听声辨意。

这个方向有多重要？Sora 生成视频、GPT-4V 看图答题、语音对话的数字人……当前最惊艳的应用几乎全是多模态的。

## 核心概念拆解

### 概念 1：CLIP —— 在两种语言之间修一座桥

OpenAI 2021 年的 CLIP（Contrastive Language-Image Pre-training）是多模态的奠基之作。它的训练数据是互联网上亿级的**图文对**（图片+配文），训练目标朴素到极致：

```text
一批 (图片, 文字) 配对中，把正确配对挑出来

猫的照片 ↔ "一只猫"     → 拉近向量距离 ✓
猫的照片 ↔ "一辆卡车"   → 推远向量距离 ✗
```

训练完成后发生了一件神奇的事：**图像编码器和文本编码器的输出落在同一个语义空间里**——「一张猫照片」的向量和文字「猫」的向量余弦相似度很高，尽管它们来自两个完全不同的网络。

这座桥的价值立刻兑现为两大能力：

```text
① 零样本分类：想识别新类别？不用训练！
   把类别名写成文字（"一张X的照片"），算图与各文字的相似度即可
② 为文生图提供导航：Stable Diffusion 的文本条件就是 CLIP 式编码器
   （G5 的 cross-attention 引导正是借这座桥）
```

### 概念 2：让语言模型长出眼睛 —— 三条路线

GPT-4V 这类「能看图的聊天模型」是怎么造的？三条主流路线：

| 路线              | 做法                                          | 代表         |
| ----------------- | --------------------------------------------- | ------------ |
| 视觉编码器+适配层 | 图像过 ViT → 特征投影成「外语 token」塞给 LLM | LLaVA/GPT-4V |
| 统一 token 化     | 图像切成小块当普通 token 处理                 | Gemini/Fuyu  |
| 工具外挂          | 语言模型调用独立的视觉模型                    | 早期方案     |

路线一目前最流行，机制值得细品：**把图像特征翻译成语言模型的「方言」**——视觉编码器输出的向量序列被当作一串特殊的「图像词」插在文字前面，语言模型原有的注意力机制无缝地同时对文字和「图像词」做交互。对模型来说，「看见」就是「读到一种新的文字」。

### 概念 3：「看图说话」的能力从哪来

一个有趣的追问：LLM 本来只读过文字，怎么突然会描述图片了？

答案藏在两阶段训练里：

```text
阶段一：预训练对齐（如 CLIP 式）→ 视觉特征与语言空间挂钩
阶段二：指令微调（DL10 范式）→ 用「(图， 问， 答)」三元组教模型
        「看到这种图像词时该用哪种语言回应」

关键洞察：语言知识本来就在 LLM 里！
多模态训练只需要学「翻译」——把视觉信号接到已有的语言能力上，
而不是从零教它认识世界。
```

这再次印证 DL10 迁移学习的威力：底座越强，桥越好搭。这也解释了为什么多模态爆发紧跟着大语言模型成熟——**先有强大的语言大脑，才有值得接入的眼睛**。

### 概念 4：输出侧的多模态 —— 统一生成的野心

输入侧打通后，输出侧也在统一。两条技术路线：

```text
① 自回归画像素/音频片段：把生成任务也变成「预测下一 token」
   （图像 token 化 → GPT 直接「写」出图像；音乐同理）
   代表：Gemini 原生多模态、Chameleon

② 外挂专用生成器：语言模型理解意图 → 调用扩散模型画图（G5）
   （当前更常见的产品形态）
```

长期看路线①更优雅——**万物皆 token，一切生成都是序列预测**，整个 AI 收敛回 NLP7 那个朴素的任务。届时本站从神经元讲到这里的全部内容，就是同一个故事的不同章节。

### 概念 5：多模态的独特风险

每种新模态带来新的攻击面：

- **图像幻觉**：看图问答时一本正经地描述图中不存在的细节
- **OCR 类错误放大**：图中文字识别错误被下游任务当成事实
- **跨模态注入**：图片里藏一行指令文字（「忽略以上所有指示…」）骗过模型——提示词攻击的图像版
- **隐私新维度**：截图/照片可能携带元数据与人脸等敏感信息

原则依旧：**模态越多，攻击面越大；能力越强，验证越重要**（G8 展开正面防线）。

## 自测一下

> [!question]- 1. CLIP 的对比训练为什么能让「图片」和「文字」可比？两个网络输出明明是完全不同的东西。
> 关键在于训练目标强制它们**可对齐**而非同源：每张图的向量必须靠近其配对文字的向量、远离不配对的——数十亿次这样的拉近推远后，两个网络被迫学会把各自的输出折叠到同一个语义坐标系。
> 打个比方：两个从未谋面的译者各自翻译同一本书，只要读者要求「同一页码必须讲同一件事」，他们的译文结构就会被逼趋同。**对齐不是天生的，是被目标函数雕刻出来的**。

> [!question]- 2. 「零样本分类不用训练就能识别新类别」——它与微调的分类器相比牺牲了什么？
> 牺牲的是精度上限与细粒度控制：零样本靠类名文字的语义泛化，适合粗粒度常见概念；但专业领域（医学影像分型、工业缺陷细分）的类名缺乏足够的语义锚点，准确率明显低于用几百条标注微调的专用模型。
> 实践策略分层：原型验证用零样本快速试（五分钟）；正式上线用少标注微调或两者结合（零样本打底 + 微调精修）——又是「基线先行，迁移提效」的组合拳。

> [!question]- 3. 为什么说「先有强语言底座，才有多模态爆发」？反过来行得通吗？
> 正向逻辑：多模态训练的核心是把视觉信号「翻译」给语言系统并让它合理作答——语言能力越强，同样的视觉接入能兑现的理解深度越深（GPT-4V 强不仅是看得清，更是答得好）。
> 反过来（早期视觉模型+弱语言头）确实试过：能识别却说不利索，应用价值有限。
> 更深一层：语言是人类知识的最高密度载体，语言底座相当于自带全部常识先验——视觉分支只需学习「接线」，不必重修「世界观」。这也是为什么多模态竞赛的入场券是一张顶配语言模型的门票。

> [!question]- 4. 设计一个「上传发票图片自动记账」的多模态功能，列出技术要点与三个必须防御的风险。
> 技术要点：① 视觉模型抽取关键字段（日期/金额/商户/税号）用结构化输出约束格式（NLP8）；② 低置信字段标记人工复核而非硬猜；③ 金额计算交给确定性代码而非模型口算（G4 工具分工原则）。
> 必须防御：
> ① **注入风险**——发票图片内嵌诱导文字（真实攻击已有先例），需对 OCR 内容做隔离处理；
> ② **隐私合规**——发票含个人与企业敏感信息，数据留存与脱敏要过法务；
> ③ **静默错误**——金额识别错误直接入账的财务后果严重，必须有抽样审计与用户确认环节。
> 思维框架照旧：**能力设计之外，攻击面与容错先行**。
