> [!abstract] 这页解决什么
> 学完全站课程后，「接下来学什么」成了新的迷茫。这页按**四个目标**分流推荐：想做项目 / 想读论文 / 想找工作 / 想追前沿。所有推荐基于公开口碑与稳定性，标注免费/付费与语言。
>
> ⚠️ 编写说明（2026-08-23）：基于模型内置知识整理，无法实时联网复核链接有效性；资源本身评价长期稳定，但具体 URL 请以搜索验证为准。


## 自测一下

> [!question]- 1. 「想做大模型应用但数学一般」的同学，最优路线组合是什么？
> 推荐：**Hugging Face Course + full stack deep learning + G 板块复习**。
> 理由：大模型应用岗的核心是「用好现成模型」（RAG/Agent/Prompt 工程），数学门槛集中在理解原理层面而非推导层面——本站 GenAI 板块已覆盖必要概念，HF 补工具链，FSDL 补工程化。数学可以边做项目边按需回补（M 板块当字典用）。
> 反例警告：不要因为「数学焦虑」去从头啃数学系教材——那是研究岗的路线，与应用岗的目标错位。

> [!question]- 2. Papers with Code 为什么对「读论文」路线的人价值极高？说出两个使用场景。
> 场景① **按任务找 SOTA**：想知道图像分类现在最好成绩是什么 → 打开排行榜看 top 方法与论文链接，避免读到过时工作；
> 场景② **论文配代码验证可信度**：有官方实现的论文优先读——能跑通的论文可信度远高于只有数字的（也呼应 G8 的可核验原则）。
> 附赠用法：找研究空白——某任务排行榜半年没更新，可能就是值得攻的方向。

> [!question]- 3. 有同学说「我把吴恩达的课都刷完了但还是不会做项目」。诊断问题并给出解法。
> 诊断：**输入输出比例失衡**——视频课程全是输入（被动接收），项目需要输出（主动构造），两者是不同技能。刷课产生的「我懂了」错觉在动手瞬间破灭。
> 解法三步：① 立刻停新课，选一个小项目（如 Kaggle Titanic）；② 强制只允许查资料不允许再看系统性课程（逼出检索式学习）；③ 完成后写复盘（哪三步卡最久=真实薄弱点，针对性回补）。
> 元规律呼应：DL12 固定种子的实验纪律、ML10 的流程总装——本站一直强调「跑通 > 听懂」。

> [!question]- 4. 追前沿信息时，「关注研究员而非媒体号」的理由是什么？
> 信息衰减链条：研究员发推（一手：刚发现的实验细节/未发表的思考）→ 技术博主整理（二手：加了解读但有滞后与转译损耗）→ 媒体号加工（三手：标题党+简化失真+情绪放大）。
> 关注一手源 = 更早获知 + 更少失真；且研究员的讨论串里常有同行质疑与作者回应——**争论过程本身就是最好的技术辨析材料**。代价是需要英文阅读力（E 板块的价值再次兑现）与筛选耐心。
